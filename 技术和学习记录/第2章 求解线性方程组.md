## 2.1 向量与线性方程组

### 两种几何视角

线性代数的中心问题是求解**线性方程组**。同一个方程组可以从两个互补视角理解：

- **行图（Row picture）**：每个方程代表一个平面（二维时是直线）。m 个方程产生 m 个在 x 处交会的平面，交点即方程组的解。当 b = 0，所有平面都经过原点 x = (0,0,…,0)。
- **列图（Column picture）**：把方程组写成向量方程 Ax = x₁a₁ + x₂a₂ + … + xₙaₙ = b。问题转化为：**A 的列向量的线性组合能否产生 b？** 正确的组合系数即方程组的解。

> 关键洞察：本书始终把 Ax 视为「A 的列的组合」，这是理解列空间、线性无关、秩等概念的基础。

### 矩阵形式 Ax = b

把 n 个方程的系数排成 m×n 矩阵 A，未知数排成列向量 x，右侧排成列向量 b：

- **按行乘**：Ax 来自点积，每个「行·x」给出一个方程分量。
- **按列乘**：Ax 是列向量的组合 x₁a₁ + … + xₙaₙ。

### 单位矩阵与基本运算

- **单位矩阵 I**：对角线为 1、其余为 0 的方阵，Ix = x（对向量无影响）。
- **纯量乘法**：cv 的分量是 cv₁, cv₂, …，是线性代数两个基本运算之一。
- **向量加法**：分量逐一相加。

### 理解消元法的四步框架（贯穿全章）

1. 借由一系列矩阵步骤 Eᵢⱼ，消元法把 A 变成上三角 U。
2. 三角系统用**反向代入法**求解：由底部往顶端工作。
3. 用矩阵语言说，A 分解成 **LU =（下三角）（上三角）**。
4. 若 A 可逆，消元法才能成功（但可能需要交换行）。

> 预告：对 m×n 矩阵，Ax = b 可能有多解，这些解构成向量空间，A 的**秩(rank)**即该空间的维度——第三章讨论。

## 2.2 消元法的概念

### 消元法流程

消元法（高斯消元法）把方程组系统化为**上三角系统**，再由底部向上求解。

**核心运算**：从第 i 个方程减去 lᵢⱼ 乘第 j 个方程（把 xⱼ 从方程 i 消除）。

- **主元（pivot）**：每一步消元时，位于角落的系数 aⱼⱼ 是主元。
- **乘数（multiplier）**：lᵢⱼ = aᵢⱼ / aⱼⱼ，即要消去的比值。
- **反向代入法（back substitution）**：消元得到上三角后，先解最后一个未知数，逐层回代。可应用于任意大小的上三角系统。

### 消元的崩溃与补救

- 如果零出现在主元位置，消元法**崩溃**。
- **交换两个方程式**（行交换）可能解救——这就是 2.7 排列矩阵的由来。

### 三个要点

1. 前向消元：从 A 到 U，一列接一列消去主对角线下方的非零元。
2. 消元成功 ⟺ 存在一整组 n 个非零主元（允许行交换）。
3. 上三角 Ux = c 用反向代入求解。

## 2.3 使用矩阵消元

### 消元步骤即矩阵乘法

每一步消元都可写成一次矩阵乘法：

- **消元矩阵 Eᵢⱼ**：在单位矩阵 I 的 (i, j) 位置减去乘数 lᵢⱼ 得到。Eᵢⱼ 作用于 A 时，会把 (i, j) 位置变成 0。
- 第一步：E₂₁Ax = E₂₁b，使 E₂₁A 在 (2,1) 处为 0。
- 消元顺序：先消第 1 列（E₂₁, E₃₁, …, Eₙ₁），再消第 2 列（E₃₂, …, Eₙ₂），以此类推。

### 增广矩阵

消元同时作用于 A 和 b，因此写成**增广矩阵 [A b]** = [a₁ … aₙ b]：E[A b] = [EA Eb]。

### 行交换矩阵

- **行交换矩阵 Pᵢⱼ**：把 I 的第 i 行与第 j 行交换得到（注意：它不是 Eᵢⱼ）。
- Pᵢⱼ 乘矩阵时交换其第 i、j 两行。

### 从 Eᵢⱼ 到 L 的思路预告

- 单个 Eᵢⱼ 太多太碎，可合并成整体消元矩阵 **E**（E 把 A 变成 U）。
- 更简洁的做法是合并所有**逆矩阵 Eᵢⱼ⁻¹**，得到下三角矩阵 **L = E⁻¹**（从 U 反向恢复 A）。
- L 的特殊性质：所有乘数 lᵢⱼ 在 L 中井然有序（在 E 中却混乱不堪）。这是 2.6 节 A = LU 的来源。

## 2.4 矩阵运算规则

### 矩阵乘法

- A 为 m×n、B 为 n×p 时，乘积 **C = AB 是 m×p** 矩阵。
- 每个单元都是点积：**Cᵢⱼ = (A 的行 i)·(B 的列 j)**。
- 每个点积需 n 次乘法，故计算 AB 共需约 **n³** 次乘法（n=100 时约 100 万次）。

### 四种计算 AB 的方式

1. **行乘列**：Cᵢⱼ = 行 i · 列 j（标准定义）。
2. **A 乘 B 的列**：AB 的第 j 列 = A × (B 的第 j 列)。
3. **A 的行乘 B**：AB 的第 i 行 = (A 的第 i 行) × B。
4. **列乘行**：A 的列 × B 的行，得到若干秩一矩阵之和。

### 关键规则

- **结合律**：(AB)C = A(BC)，(AB)x = A(Bx)——这保证消元步骤可合并。
- **不可交换**：AB ≠ BA 通常成立，A 与 B 一般不能交换。
- **分块乘法**：A = [A₁ A₂] 乘 B = [B₁; B₂] 得 A₁B₁ + A₂B₂，规则与普通乘法一致。

### 矩阵加法与纯量乘

- 形状相同的矩阵可逐项相加；任意矩阵可乘常数 c。

## 2.5 逆矩阵

### 定义与判据

若 A⁻¹ 存在使 **A⁻¹A = I 且 AA⁻¹ = I**（双边逆），则 A 可逆。关于 A⁻¹ 的六条注释：

1. **消元法判据**：A 可逆 ⟺ 消元法得到 n 个主元（允许行交换）。求解 Ax = b 时无需显式算 A⁻¹。
2. **唯一性**：左逆 = 右逆。若 BA = I 且 AC = I，则 B = C（括号证明法：B(AC) = (BA)C）。
3. **求唯一解**：若 A 可逆，Ax = b 的唯一解是 **x = A⁻¹b**。
4. **零空间判据**：若存在非零 x 使 Ax = 0，则 A 不可逆（无法从 0 反推 x）。A 可逆 ⟺ Ax = 0 只有零解。
5. **2×2 判据**：A = [[a,b],[c,d]] 可逆 ⟺ **ad − bc ≠ 0**（即行列式非零）。逆矩阵 = (1/(ad−bc)) × [[d,−b],[−c,a]]。
6. **对角矩阵**：对角元全非零的对角矩阵可逆，逆为各对角元取倒数。

### 乘积的逆（反序法则）

若 A、B 均可逆，则 AB 可逆，且：

$$(AB)^{-1} = B^{-1}A^{-1}$$

> 直觉类比：先穿袜子再穿鞋，反过来要先脱鞋再脱袜子。三个矩阵同理：(ABC)⁻¹ = C⁻¹B⁻¹A⁻¹。
> 注意：A + B 的可逆性难以一般化讨论（两数之和不一定可逆），但乘积 AB 的可逆性等价于 A、B 各自可逆。

### 高斯-若尔当消元法（计算 A⁻¹）

- 核心思想：A⁻¹ 的第 j 列 xⱼ 满足 Axⱼ = eⱼ（I 的第 j 列）。
- 同时求解这 n 个方程：对增广矩阵 **[A | I]** 施行行消元，把它变成 **[I | A⁻¹]**。
- 与高斯消元的区别：高斯到上三角就用反向代入；若尔当继续消元，一路走到**简化阶梯形式**，最后把每行除以主元使主元全为 1。
- **成本**：计算 A⁻¹ 需约 **n³** 次乘法/减法；而求解单个 Ax = b 只需 n³/3（见 2.6 节）。因此实际中一般不显式求逆。

> 可逆性小结：消元法提供了完整判据——A 有 n 个主元时 A⁻¹ 确实存在。本书最后一页列出方形矩阵 A 可逆的 **14 种等效条件**。

## 2.6 消元 = 分解：A = LU

### 核心思想

消元法最重要的产物是**矩阵分解**：原始矩阵 A 变成两个特殊三角矩阵的乘积。

$$A = LU = (\text{下三角})(\text{上三角})$$

- **U**：上三角矩阵，主元在对角线上，由前向消元 A → U 得到。
- **L**：下三角矩阵，对角线为 1，其 (i, j) 单元恰好是乘数 **lᵢⱼ**（从行 i 减去的倍数）。

### 为何用 L 而非 E

- 前向消元的整体矩阵 E = Eₙₙ₋₁…E₃₂E₂₁ 把 A 变成 U，但 E 中的乘数 lᵢⱼ 系混乱（因后消元的步骤会改写前面已写入的位置）。
- 取逆 L = E⁻¹ = E₂₁⁻¹E₃₂⁻¹…（逆序），乘数 lᵢⱼ 在 L 中**井然有序**——反向步骤天然避免了混乱。

### 求解流程

1. 对 Ax = b 施行消元，得 Ux = c（c = E b）。
2. 用反向代入求解上三角 Ux = c。

### 计算成本

| 操作 | 成本（乘法/减法） |
|------|------------------|
| 反向代入求解三角系统 | 约 n²/2 |
| 消元法得到 U | 约 **n³/3** |
| 计算 A⁻¹（高斯-若尔当） | 约 n³ |

> n³/3 是线性代数中最经典的成本数字。矩阵乘法的理论下界研究已把 n³ 降到约 n²·³⁷⁶，但常规科学计算仍按 n³ 计。

## 2.7 转置与排列

### 转置的定义与规则

- **转置 Aᵀ**：把 A 的行写成 Aᵀ 的列，即 (Aᵀ)ᵢⱼ = Aⱼᵢ。A 为 m×n 时 Aᵀ 为 n×m。
- 下三角的转置是上三角；Aᵀ 的转置仍是 A。

**运算规则**：

$$(A+B)^T = A^T + B^T, \quad (AB)^T = B^T A^T, \quad (A^{-1})^T = (A^T)^{-1}$$

### 内积与外积

- **内积（点积）**：x·y = **xᵀy**，结果是一个数，即 (1×n)(n×1) = 1×1。
- **外积**：**xyᵀ** = 列乘行，结果是 n×n 矩阵（秩为 1），即 (n×1)(1×n)。

### 转置的深层意义

Aᵀ 是使得下列两个内积相等的唯一矩阵（对任意 x、y）：

$$(Ax)^T y = x^T (A^T y) \quad\Longleftrightarrow\quad Ax \cdot y = x \cdot A^T y$$

> 应用直觉：力学中功 = (位移)ᵀ(力)；电路热损失 = (压降)ᵀ(电流)；经济学收入 = (数量)ᵀ(价格)。

### 对称矩阵 S

- 定义：**Sᵀ = S**，即 sⱼᵢ = sᵢⱼ，沿主对角线翻转不变。
- 对称矩阵的逆仍对称：(S⁻¹)ᵀ = (Sᵀ)⁻¹ = S⁻¹。
- **ATA 与 AAᵀ 永远对称**：因 (AᵀA)ᵀ = Aᵀ(Aᵀ)ᵀ = AᵀA。这是科学计算中对称矩阵最常见来源。
  - AᵀA 是 n×n，AAᵀ 是 m×m，两者一般不等；对角线恒为正数。
- **对称分解**：对称矩阵的 LDU 分解也是对称的，**S = LDLᵀ**（U 变成 Lᵀ）。对称性使消元只需处理半边矩阵，更高效。

### 正交矩阵 Q

- 定义：**Qᵀ = Q⁻¹**，即 Q 的列是正交单位向量。

### 排列矩阵 P

- 定义：P 有单位矩阵 I 的行，但以**任意顺序**排列——每行每列恰有一个 1。
- 阶数 n 有 **n! 个**排列矩阵（3 阶 6 个，4 阶 24 个，5 阶 120 个）。其中一半为偶排列（sign=+1），一半为奇排列（sign=−1）。
- 关键性质：**P⁻¹ 永远等于 Pᵀ**（因 PPᵀ = I）。P⁻¹ 也是排列矩阵。
- 行交换 Pᵢⱼ 是最简单的排列矩阵（交换 I 的两行），它是自己的转置也是自己的逆。

### 带行交换的分解 PA = LU

- 若 A 可逆，排列矩阵 P 会把 A 的行重排到正确顺序，使得 **PA = LU** 无需再交换。
- 实际代码（如 MATLAB 的 `lu`）通常使用**部分主元法（partial pivoting）**：每列选绝对值最大的主元以降低舍入误差（详见 11.1 节）。
- 数学上可接受任何非零主元，但数值计算必须选大主元。
- 教学代码 `splu(A)` 分解 PA = LU；若某列找不到主元则 A 不可逆。

## 核心观念复习（全章要点）

1. **行图/列图**：行图是平面交点，列图是列向量的组合产生 b。
2. **消元法**：用乘数 lᵢⱼ 把 A 化为上三角 U，主元在对角线，零主元时需行交换。
3. **消元 = 矩阵乘法**：每步消元是 Eᵢⱼ 乘 [A b]，行交换是 Pᵢⱼ。
4. **矩阵乘法**：AB 的 (i,j) 元 = 行 i · 列 j；满足结合律但不满足交换律；可分块。
5. **逆矩阵**：A⁻¹A = I；判据为 n 个主元 / det A ≠ 0 / Ax=0 只有零解；(AB)⁻¹ = B⁻¹A⁻¹。
6. **高斯-若尔当**：[A | I] → [I | A⁻¹]，成本 n³。
7. **A = LU 分解**：L 装载乘数 lᵢⱼ，消元成本 n³/3，反向代入 n²/2。
8. **转置**：(AB)ᵀ = BᵀAᵀ；内积 xᵀy，外积 xyᵀ；(Ax)ᵀy = xᵀ(Aᵀy)。
9. **对称矩阵**：Sᵀ = S；AᵀA 恒对称；对称分解 S = LDLᵀ。
10. **排列矩阵**：Pᵀ = P⁻¹，共 n! 个；可逆 A 满足 PA = LU。
