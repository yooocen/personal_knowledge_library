# 向量空间

## 核心直觉：从"集合"到"空间"

**向量空间**就是对**加法和数乘封闭**的向量集合。

> 所谓"封闭"：你在空间里随便拿两个向量相加、或者给任意向量乘一个数，结果**还在同一个空间里**。

| 是集合，但不是空间                | 为什么？                            |
| ------------------------ | ------------------------------- |
| 两个向量 $\{(1,0),\,(0,1)\}$ | $(1,0)+(0,1)=(1,1)$ 不在集合里       |
| 直线 $x+y=1$（不过原点）         | $(0,1)+(0,1)=(0,2)$，$0+2\neq 1$ |
| 整数向量 $\mathbb{Z}^2$      | $0.5\cdot(1,0)=(0.5,0)$ 不是整数向量（首分量 $0.5$ 不是整数）  |
| 单位圆上的点                   | $(-1,0)+(1,0)=(0,0)$ 不在圆上       |

| 是向量空间 | 原因 |
|-----------|------|
| $\mathbb{R}^2$ 整个平面 | 随便加、随便乘，结果还在平面里 |
| 过原点的直线 $\{(x,2x)\mid x\in\mathbb{R}\}$ | $(a,2a)+(b,2b)=(a+b,2(a+b))$，仍在线上 |
| 过原点的平面 $\{(x,y,0)\mid x,y\in\mathbb{R}\}$ | 加法数乘后 $z$ 仍为 $0$ |
| 零向量 $\{0\}$ 自己 | $0+0=0$，$c\cdot 0=0$ |

**判断捷径**：一个向量集合是不是空间，**看它是否包含零向量**，且零向量处在这个集合的"内部"——不过这只是必要条件，真正要验证还是加法和数乘两条。

---

## 严格定义

一个集合 $V$ 是**向量空间**（vector space），需满足：

### 加法封闭
$$
\forall \mathbf{v}, \mathbf{w} \in V: \mathbf{v} + \mathbf{w} \in V
$$

### 数乘封闭
$$
\forall \mathbf{v} \in V,\; \forall c \in \mathbb{R}: c\mathbf{v} \in V
$$

再加上几条常规性质（结合律、交换律、分配律、零元、负元等），但这些在 $\mathbb{R}^n$ 里自然成立，不是重点。

---

## 子空间（Subspace）

**子空间** = 一个向量空间的子集，且它自己也是一个向量空间。

> 直白理解：在一个大空间里，切出一块"也满足封闭性"的小空间。

### 子空间的三个来源（对应 [[线性代数绪论]] 核心）

| 来源                                              | 子空间                      | 属于             |
| ----------------------------------------------- | ------------------------ | -------------- |
| 矩阵 $A$ 的所有行的线性组合                                | **行空间**（Row Space）       | $\mathbb{R}^n$ |
| 矩阵 $A$ 的所有列的线性组合                                | **列空间**（Column Space）    | $\mathbb{R}^m$ |
| 所有满足 $A\mathbf{x}=0$ 的 $\mathbf{x}$             | **零空间**（Nullspace）       | $\mathbb{R}^n$ |
| 所有满足 $A^{\mathsf T}\mathbf{y}=0$ 的 $\mathbf{y}$ | **左零空间**（Left Nullspace） | $\mathbb{R}^m$ |

### $\mathbb{R}^3$ 中所有可能的子空间

```
              ╱
            ╱   (3D) 整个空间
          ╱        ── 过原点的平面 (2D)
        ╱              ── 过原点的直线 (1D)
      ╱                    ── 零向量 (0D)
```

$\mathbb{R}^3$ 的子空间只有这 **4 种**：零向量、过原点的直线、过原点的平面、整个空间。

---

## 常见误区

### ❌ "子空间不必过原点"
**✅ 错。** 子空间**必须**包含零向量。因为数乘封闭要求 $0\cdot\mathbf{v} = \mathbf{0}$ 必须在空间里。所以不过原点的直线/平面都不是子空间（它们叫**仿射子空间**）。

### ❌ "$\mathbb{R}^2$ 中一条直线就是子空间"
**✅ 只有过原点的才是。** 不过原点的叫**仿射子空间**（affine subspace）——是子空间平移了一下。

### ❌ "行空间就是矩阵的行"
**✅ 行空间是那些行**张成**的空间，而不是那几行本身。比如：
$$
A = \begin{bmatrix}1&0\\2&0\end{bmatrix}
$$
行是 $(1,0)$ 和 $(2,0)$，但它们的行空间只是 $x$ 轴——一条直线，不是整个 $\mathbb{R}^2$。

## 张成（Span）——"空间是怎么造出来的"

给定一组向量 $\mathbf{v}_1, \dots, \mathbf{v}_k$，它们的**张成空间**是：

$$
\text{span}\{\mathbf{v}_1,\dots,\mathbf{v}_k\} = \{c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k \mid c_i \in \mathbb{R}\}
$$

> 取尽所有线性组合，得到的就是一个向量空间。

### 例子
- $\text{span}\{(1,0)\}$ = $x$ 轴（一维）
- $\text{span}\{(1,0), (0,1)\}$ = 整个 $\mathbb{R}^2$（二维）
- $\text{span}\{(1,0), (2,0)\}$ = 还是 $x$ 轴（一维，因为第二个向量是冗余的）

冗余与否看**线性无关**——[[线性代数绪论]] 里说的秩（rank）就是张成空间的有效维度。

---

## 与 [[线性代数绪论]] 的衔接

你笔记里 Strang 说"取得一组向量的全部线性组合"——这就是 **span** 的定义。

整本书的本质就是在做一件事：

$$
\boxed{\text{用子空间的语言理解 } A\mathbf{x} = \mathbf{b}}
$$

| 概念 | 子空间视角 |
|------|-----------|
| $A\mathbf{x} = \mathbf{b}$ 有解 | $\mathbf{b}$ 在 $A$ 的**列空间**中 |
| 解是否唯一 | 取决于**零空间**是否只含 $0$ |
| 消元找什么 | 找到列空间/行空间的一组**基** |
| 最小二乘 | 当 $\mathbf{b}$ 不在列空间时，投影到列空间 |

---

## 一句话总结

> **向量空间 = 对加法和数乘封闭的向量集合。**
> **子空间 = 大空间里取一块，自己也是一个向量空间。**
> 线性代数就是"用空间的语言"来描述和理解线性方程组。
