## 详细技巧总结（NotebookLM 整理）

### 视图控制

- **鼠标三键视图控制**（1.2，[02:39]-[02:49]）：按住**鼠标中键**拖拽可旋转视角，按住 **`Shift` + 鼠标中键** 拖拽可平移视图，滚动**鼠标中滑轮**可缩放视图。
- **无中键导航按钮**（1.2，[02:52]-[03:07]）：点击并拖拽右侧导航栏的**小手图标**可平移视图；拖拽**小轮盘图标**可旋转视角；拖拽**放大镜图标**可缩放视图。
- **摄像机视图切换**（1.2，[03:10]、[11:24]）：点击右侧导航栏的**摄像机图标**，或按下数字小键盘 **`0`** 键，可快速进入或退出摄像机视图（即最终渲染看到的画面）。
- **正交与透视视图切换**（1.2，[03:22]、[11:17]）：点击导航栏网格/手掌下方按钮，或按下数字小键盘 **`5`** 键，可在正交视图与透视视图之间切换。
- **导航罗盘正交视角**（1.2，[09:52]-[10:04]）：点击右侧导航 Gizmo 上的 X、Y、Z 轴圈，可快速切换到对应的右视图、后视图或顶视图。
- **三维轴向空间定位**（1.2，[10:18]-[10:26]）：红轴为 X 轴（正 X 为右侧），绿轴为 Y 轴（负 Y 为正面方向），蓝轴为 Z 轴（正 Z 为上方，负 Z 为下方）。
- **数字小键盘视角快捷键**（1.2，[10:43]-[11:01]）：
  - **`1`**：正视图（Front View）；
  - **`3`**：右视图（Right View）；
  - **`7`**：顶视图（Top View）；
  - **`9`**：反转当前视图视角（例如顶视图反转为底视图，正视图反转为后视图）；
  - **`2` / `4` / `6` / `8`**：向上下左右方向微调旋转视角，每按一次旋转 15 度。
- **无小键盘的视角派菜单**（1.2，[12:14]-[12:30]）：按键盘左上角波浪号 **`~`** 键呼出派菜单（Pie Menu），用鼠标点击选择顶视图、底视图、左视图或右视图。
- **Alt+中键快速视角切换**（1.2，[12:34]）：按住 **`Alt`** 键拖拽鼠标中键，可快速切到上下左右对应的正交视图。
- **聚焦定位到选中物体**（1.2，[11:30]-[11:48]）：选中目标模型后，按下数字小键盘的小数点 **`.`** 键（Numpad Del），视图会自动平移并将该模型放大推到屏幕正中央。

### 物体变换（移动/旋转/缩放）

- **移动物体（Grab）**（1.2，[05:08]-[05:24]）：选中物体按 **`G`** 键进入移动模式，移动鼠标调节位置，点击**鼠标左键**确认定位，点击**鼠标右键**取消移动并恢复原位。
- **轴向限定移动**（1.2，[05:28]-[05:33]）：按 `G` 进入移动模式后，按下 **`X`** / **`Y`** / **`Z`** 键，可限制模型仅沿着指定的单轴方向移动。
- **旋转物体（Rotate）**（1.2，[06:04]-[06:29]）：选中物体按 **`R`** 键进入旋转模式，默认垂直于当前视图方向旋转；按 `R` 后接 **`X`** / **`Y`** / **`Z`** 键可限定围绕单轴旋转；点击**鼠标右键**取消旋转。
- **缩放物体（Scale）**（1.2，[05:41]-[05:57]）：选中物体按 **`S`** 键进入缩放模式，移动鼠标调节大小，按 `S` 后接 **`X`** / **`Y`** / **`Z`** 键可限定单轴向缩放；点击**鼠标左键**确认，**鼠标右键**取消。
- **清除/重置变换**（1.2，[06:41]-[06:47]）：
  - **`Alt + G`**：清除移动，恢复到新建时的初始位置；
  - **`Alt + R`**：清除旋转，重置旋转角度；
  - **`Alt + S`**：清除缩放，重置物体初始比例。
- **工具栏变换手柄**（1.2，[03:39]-[04:05]、[06:56]）：点击左侧工具栏的移动、旋转或缩放图标，可在物体上调出红(X)、绿(Y)、蓝(Z)三色 Gizmo 控制手柄进行拖拽控制；也可点击变换三合一按钮集中显示。

### 选择工具

- **框选工具 (Box Select)**（1.2，[08:29]-[08:39]）：Blender 默认的选择工具，长按左侧顶部选择图标切换；按住鼠标拖拽框选模型，该模式无法直接移动模型，可防止误操作。
- **调整工具 (Tweak)**（1.2，[08:48]-[08:56]）：在选择工具菜单中切换为调整工具后，点击物体可直接自由拖拽移动。
- **刷选工具 (Circle Select)**（1.2，[09:02]）：快捷键为 **`C`** 键，长按或拖动鼠标像刷子涂抹一样，刷过的模型区域均会被选中。
- **套索选择 (Lasso Select)**（1.2，[09:14]）：长按选择工具图标选择套索，按住鼠标手绘闭合线条，自由圈选目标区域。

### 隐藏/显示

- **隐藏选中物体**（1.2，[07:14]-[07:23]）：选中目标物体后按快捷键 **`H`** 键，或在大纲视图（Outliner）中点击该物体旁边的**小眼睛图标**隐藏模型。
- **显示所有隐藏物体**（1.2，[07:28]）：按快捷键 **`Alt + H`**，解除场景中所有隐藏物体的遮挡并重新显示。
- **独显选中项**（1.2，[07:31]）：选中目标物体后按快捷键 **`Shift + H`**，快速隐藏除当前选中项以外的所有其他物体。

### 复制

- **移动并复制物体**（1.2，[07:56]-[08:16]）：选中物体后按 **`Shift + D`** 进行复制。Blender 的 `Shift + D` 机制是“复制并直接随鼠标移动”；如果需要原地复制，按完 `Shift + D` 后需立即点击**鼠标右键**取消移动，新副本即停留在原始位置。

### 删除与新建

- **新建物体**（1.2，[04:35]-[04:44]；1.3，[00:16]）：按快捷键 **`Shift + A`** 呼出添加菜单，在“网格”分类中点击选择几何体（如立方体、锥体、猴头等）。新建物体会自动生成在 **3D 游标当前所在的位置**。
- **删除物体**（1.2，[04:23]-[04:30]）：选中物体后直接按 **`Delete`** 键删除；或按 **`X`** 键呼出弹出确认框，点击确认删除。
- **撤销操作**（1.2，[04:25]）：按快捷键 **`Ctrl + Z`** 撤销上一步操作。

### 游标（3D Cursor）

- **游标的概念与作用**（1.2，[03:32]；1.3，[04:59]-[05:08]）：场景中红白相间的小圆圈称为 3D 游标。主要有两大作用：1) 新建物体生成位置的落脚点；2) 作为模型变换与对齐的轴心点基准。
- **移动与定位游标**（1.3，[05:12]-[05:31]）：切换左侧“游标工具”后在视图中点击；或在选择工具下按快捷键 **`Shift + 鼠标右键`**，快速将游标精准定位到点击位置。
- **吸附派菜单定位模型**（1.3，[05:47]-[05:56]）：按快捷键 **`Shift + S`** 呼出吸附定位菜单，选择“选中项到游标 (Selection to Cursor)”，可将选中的模型快速移动对齐到游标位置。
- **重置游标至世界原点**（1.3，[06:11]）：按快捷键 **`Shift + C`**，快速将 3D 游标归位回世界坐标系中心原点 (0, 0, 0)。
- **游标吸附至模型**（1.3，[06:34]）：按 **`Shift + S`** 选择“游标到选中项 (Cursor to Selected)”，游标会自动吸附移动到选中物体的中心位置。
- **游标作为变换轴心**（1.3，[07:00]）：在顶部变换轴心点菜单中切换为 3D 游标后，按 `R` 旋转时模型会围绕 3D 游标公转。

### 原点（Origin）

- **原点的概念与本质**（1.3，[07:15]-[07:42]）：物体上的**黄色圆点**即为原点，相当于物体的“核心/CPU”，记录着物理数据信息；计算机变换模型时只识别原点位置。
- **单独修改原点位置**（1.3，[08:15]-[08:33]）：
  1. 点击界面右上角 **`选项 (Options)`** 菜单，勾选 **`仅影响原点 (Affect Only Origins)`** 复选框；
  2. 按 `G` 移动原点到指定位置（如立方体底面中心）；
  3. **重要提示**：修改完毕后**必须回到选项中关闭“仅影响原点”**，否则后续无法正常移动模型本身。
- **原点对缩放与移动的影响**（1.3，[08:35]-[08:43]）：将原点移至底部后，按 `Alt + G` 会以新原点归位世界中心；按 `S` 缩放时模型会围绕底部新原点向上或向下延伸生长。

### 轴心点（Pivot Point）

- **轴心点的概念**（1.3，[11:06]-[11:10]）：界面顶部中间的变换轴心点菜单，用于指定旋转或缩放操作时围绕哪个参考中心点进行。
- **常用轴心点类型**（1.3，[11:28]-[13:45]）：
  - **边界框中心 (Bounding Box Center)**：以所选物体集合的最外层几何包围框中心作为变换轴心；
  - **质心点 (Median Point)**：以多选物体的整体物理重心位置作为变换轴心；
  - **各自的原点 (Individual Origins)**：多选物体时，每个物体分别围绕各自自身的黄色原点独立进行旋转或缩放；
  - **活动元素 (Active Element)**：多选物体时，以最后按 `Shift` 加选的亮黄色“活动物体”的原点作为整体变换的轴心。

### 坐标系（Transform Orientations）

- **全局与局部坐标系概念**（1.3，[14:05]-[14:27]）：
  - **全局坐标系 (Global)**：即世界坐标系，X（左右）、Y（前后）、Z（上下）方向始终固定不变；
  - **局部坐标系 (Local)**：物体自带的固有坐标系，坐标轴方向随物体的旋转而相应旋转。
- **快捷键双按切换坐标轴**（1.3，[15:05]-[15:41]）：
  - 变换操作时，按一次轴向字母（如 `G + Z`）代表在当前默认模式的轴向上操作；
  - **连按两次轴向字母**（如 **`G + Z + Z`** 或 **`S + Z + Z`**），可在全局坐标系与局部坐标系轴向之间快速自由切换。

### 界面偏好设置

- **窗口面板类型切换**（1.3，[01:43]-[02:14]）：主界面由 4 大主要窗口构成分割；点击任意窗口面板左上角的小图标，可在 3D 视图、图像编辑器、大纲视图、属性栏等不同编辑器类型间自由转换。
- **工作区标签页 (Workspace Tabs)**（1.3，[02:39]-[02:50]）：顶部 Layout、Modeling、Sculpting 等标签页本质上是预置了不同窗口组合与编辑模式的视图配置。
- **窗口面板拆分与合并操作**（1.3，[03:13]-[04:05]）：
  - 将鼠标移至窗口角落直到出现加号光标；
  - **拖拽规则**：往**当前窗口内部方向拉**为**拆分**出新窗口；往**邻近窗口方向拉**为**合并**窗口；
  - 也可在分界线上右键选择分割/合并窗口。
- **界面乱掉后的重置恢复**（1.3，[04:19]-[04:38]）：点击顶部布局标签页旁的 `+` 号新建常规 Layout 布局，并将原先乱掉的布局删除，即可恢复全新界面。
- **窗口最大化与还原**（1.3，[04:40]）：按快捷键 **`Ctrl + Space`** 可将当前鼠标悬停的窗口面板最大化全屏显示，再按一次恢复原始布局。
- ★ **【新手重要偏好设置建议 1】按鼠标位置缩放 (Zoom to Mouse Position)**（1.3，[09:50]-[10:14]）：
  - **设置路径**：顶部菜单 `编辑 (Edit)` -> `偏好设置 (Preferences)` -> `视图/导航 (Navigation)` -> 勾选 **`缩放至鼠标位置 (Zoom to Mouse Position)`**；
  - **重要性说明**：**强烈推荐新手开启！** 开启后滚轮拉近/拉远视图将直接以鼠标指针所停留的位置为中心缩放，大幅提升观察与定位效率。
- ★ **【新手重要偏好设置建议 2】围绕选择物体旋转 (Rotate Around Selection)**（1.3，[10:38]-[10:54]）：
  - **设置路径**：顶部菜单 `编辑 (Edit)` -> `偏好设置 (Preferences)` -> `视图/导航 (Navigation)` -> 勾选 **`围绕选择物体旋转 (Rotate Around Selection)`**；
  - **重要性说明**：**强烈推荐新手开启！** 开启后按住鼠标中键旋转视角时，始终以当前选中的模型为中心进行旋转，彻底避免视角飘飞脱离目标。

### 其他

- **时间轴面板高度调整**（1.2，[01:25]-[01:31]）：将鼠标悬停在底部分界线上（变双箭头）向上拖动，可展示时间轴面板。
- **硬件配置建议**（1.2，[12:06]）：使用无小键盘笔记本电脑的新手，建议购买独立蓝牙小键盘，这能极大方便视角快捷键（1/3/7/0/.）的操作。
- **3D 创作基本工作流程**（1.3，[00:30]-[00:41]）：最基本的 3D 工作流为 **建模 -> 材质 -> 渲染**（其中打光与材质调整相互影响配合）。
- **第一性原理与学习心态建议**（1.3，[00:53]-[01:05]、[15:56]-[16:03]）：当觉得软件概念或案例复杂时，学会回归事物最朴素的第一性原理进行拆解；学习时给自己留出耐心，先掌握基础工具逻辑，后续结合实际案例练习即可自然理解掌握。
