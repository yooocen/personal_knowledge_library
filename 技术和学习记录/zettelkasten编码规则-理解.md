# zettelkasten 编码规则的理解

继续探讨 [[我的zettelkasten编码规则（非官方）.md]]（2/2），把编码语法整理成可执行的形式。
核心结论：这套编码记录的是**思维路径**，不是知识分类。

## 编码语法

- **数字**：顺着思路继续（分支推进）
- **字母**：卡片级思维跳转，拐到题外相关话题
- **字母后接数字**：在题外话题上继续推进

## 路径示例

```
2                主题标号
├── 2/1           第一个探讨
│   ├── 2/11      承接 2/1 第 1 分支
│   │   └── 2/111   承接 2/11 继续（递归叠加）
│   ├── 2/12      承接 2/1 第 2 分支
│   └── 2/1a      从 2/1 跳出的题外话
│       └── 2/1a1   基于题外话继续
└── 2/2           另一角度（与 2/1 平行）
    └── 2/21      承接 2/2 继续 ← 本卡
```

## 关键语义

- 斜杠后的数字串 = 思维路径：`2/112` 读作「2 → 1 → 1 → 2」，每步都是分支推进
- `2/12` 与 `2/2` 之间**没有任何层级关系**：前者是「2/1 的第二分支」，后者是「主题 2 的第二角度」
- 官方编码回答「这张卡在知识结构里的位置」，本规则回答「我当时是怎么从那张卡想到这张卡的」

## 与官方编码的对比

| 维度 | 官方（卢曼） | 本规则（非官方） |
|---|---|---|
| 结构 | 命题推导树 | 思维流动轨迹 |
| 关系 | 2 → 2/1 → 2/2 是逻辑演绎 | 2/2 与 2/11 可毫无关系 |
| 强调 | 命题的推断关系 | 思考过程 |

## 已确认细则

- 递归写法：`2/111`（数字叠加，无斜杠分隔）
- 字母插入位置：卡片级（如 `2/1a`）
- `2/2` 是主题下的独立新角度；`2/12` 是从 `2/1` 延伸的第二分支
- 字母后接数字：`2/1a1`（数字直接叠加）
- 字母嵌套：`2/1ab`（题外话的题外话）允许，可多级嵌套
