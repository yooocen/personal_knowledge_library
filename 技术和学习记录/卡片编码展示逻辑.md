规则：

- **规则1**：同一水平线的卡片代表讨论的是同一个话题，**聚焦卡片所在水平线**的最左端是讨论的话题：例子1 聚焦 `1/3`，`1/3` 所在水平线（主行）最左端是 `1`，讨论话题 `1`；例子5 聚焦 `1/4b`，`1/4b` 所在水平线最左端是 `1/4b`，讨论话题 `1/4b`
- **规则2**：如果卡片有 下一个字母卡片，比如 1/4有 1/4a ，1/4a是1/4的题外话，如果当前在查看的是1/3，那么1/4这个话题展示一个下竖线，代表1/4有题外话，但是讨论的是话题1，所以不展示相关的题外话
- **规则3**：如果卡片有 下一个数字卡片，比如 1/4有 1/41 ，1/41是1/4这个话题的继续，如果当前在查看的是1/3，那么1/4这个话题展示一个上竖线，代表1/4有单独的话题继续讨论，但是讨论的是话题1，所以不展示相关的继续讨论
- **规则4**：编码约定：`1/41`、`1/4a` 都是 `1/4` 的下一级；后缀为数字（`/41`）表示"继续"，后缀为字母（`/4a`）表示"题外话"；`1/4a1`、`1/4a2` 是 `1/4a` 的下一级数字继续；多层嵌套时编码逐级追加，如 `1/11` 是 `1/1` 的数字继续、`1/111` 是 `1/11` 的数字继续、`1/111a` 是 `1/111` 的字母题外话、`1/11a` 是 `1/11` 的字母题外话
- **规则5**：查看某话题卡片本身时（如正在查看 `1/4`）：该话题的下一级分支全部完整展开，数字继续链展示在主行上方（如 `1/4 -- 1/41 -- 1/42`），字母分支（题外话）展示在主行下方（如 `1/4a`、`1/4b`），竖线从短指示器延伸为连接展开内容的长连接线；但分支的下级分支（如 `1/4a` 的子级 `1/4a1`）在此视图下不展开
- **规则6**：术语：**主行**指聚焦卡片所在的同一水平线，**来源行**指父话题/来源所在水平线。当正在查看的卡片位于某个分支内时（如 `1/4a`、`1/4b`、`1/41`）：父话题（如 `1/4`）仍保留在来源行原位，与前面的卡片（如 `1/3`）在同一水平线上，父话题是分支的根但位置不动；聚焦卡片所在的主行从父话题向下（字母题外话）或向上（数字继续）延伸；来源行保留到父话题（含父话题本身，即 `1` → `1/4`），父话题之后的内容（如 `1/5`）不再展示（用线段暗示后续讨论仍然存在）。聚焦主行上的卡片（如 `1/3`、`1/4`）时，主行与来源行重合
- **规则7**：分支行结构为 `父话题 → 当前卡片 → 当前卡片沿分支方向的后代卡片`：查看 `1/4a` 时显示 `1/4 -- 1/4a -- 1/4a1 -- 1/4a2`，查看 `1/41` 时显示 `1/4 -- 1/41 -- 1/42`；当前卡片之后只跟随当前分支的内部路线
- **规则8**：数字分支（继续讨论）的分支行位于来源行上方，字母分支（题外话）的分支行位于来源行下方；分支行与来源行之间在父话题位置用竖线相连，竖线方向与分支类型一致（数字分支向上、字母分支向下），竖线线型也与分支类型对应（数字继续=实线、题外话=虚线）；父话题后方的内容末尾以 `--` 收尾表示后续讨论仍然存在（如话题 `1` 的 `1/5`）但不展示出来
- **规则9**：竖线连接到具体卡片代表该分支已展开；竖线不连接到卡片（或连接后继续延长）代表对应分支隐藏、仅提示存在。查看分支内卡片时，父话题上"还存在其他分支"的竖线标记仍然保留：查看 `1/4a` 时，`1/4` 下方的虚线连接到展开的 `1/4a`，并延长提示还存在其他题外话（`1/4b`）未展示；查看数字分支时同理保留上方实线提示。一条竖线可同时承担连接（展开）和延长（提示隐藏）两种功能
- **规则10**：分支行内不展示并行但未被查看的兄弟分支的**后代内容**：查看 `1/4a` 时不展示 `1/4b` 及其后代，查看 `1/4b` 时不展示 `1/4a` 的后代；但**前序兄弟节点本身**（如查看 `1/4b` 时的 `1/4a`）作为来源链的一部分可以展示（见规则12）
- **规则11**：多层嵌套分支：当查看的卡片位于多层嵌套分支内时（如 `1/111a` 是 `1/111` 的字母题外话，而 `1/111` 又是 `1/11` 的数字继续，`1/11` 又是 `1/1` 的数字继续），只展示最近一个层级的来源行（即直接父话题，如 `1/111`），不展示更远的祖先链（`1/11`、`1/1`）；聚焦卡片在主行，直接父话题在来源行，位置方向由该级分支类型决定（字母题外话→当前卡片在父话题下方、数字继续→当前卡片在父话题上方）；父话题上"还存在其他分支"的竖线标记保留


- **规则12**：当前展示的卡片，需要支持展示到来源和后续（后续讨论，题外话）两个维度的水平线出来即可，更深层次的水平线可以忽略展示
- **规则13**：前序来源节点放在当前聚焦卡片的上方，体现"来源在上、当前在下"：如例子5 查看 `1/4b` 时，前序题外话 `1/4a` 作为来源画在 `1/4b` 上方，父话题 `1/4` 在更上方的主行
- **规则14**：当更远的来源（祖先）隐藏不展示时，在直接父话题旁边用折线暗示来源方向隐藏：如嵌套例子2 查看 `1/11a` 时，直接父话题 `1/11` 在来源行展示，`1/11` 左边的折线暗示更远的来源 `1/1` 隐藏。与"竖线/`--`暗示后续隐藏"对称——折线暗示来源方向隐藏，竖线/`--`暗示后续方向隐藏
