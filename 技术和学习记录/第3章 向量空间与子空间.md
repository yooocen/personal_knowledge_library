# 第三章 向量空间与子空间

> 本章标志着学习从**数字计算**提升到**空间几何**的层次。围绕「子空间」这一核心概念，引入列空间 $C(A)$、零空间 $N(A)$、行空间与左零空间，最终以**线性代数的基础定理（第一部分）**收尾——秩 r 同时决定四个子空间的维度。本章是全书最重要的概念章，后续正交、最小二乘、特征值全部建立在此之上。

## 3.1 向量空间

### 向量空间的定义

**标准 n 维空间** $\mathbb{R}^n$：包含全部具有 n 个分量的实数列向量。

- $\mathbb{R}^2$ 是平常的 xy 平面，$\mathbb{R}^3$ 对应三维空间点 (x, y, z)，$\mathbb{R}^1$ 是一条直线
- 线性代数最容易处理 5 维空间：不需要画图，只需要 n 个数字

**向量空间 = 封闭的向量集合**：若 $\vec{v}$ 与 $\vec{w}$ 在向量空间 S 中，则所有组合 $c\vec{v} + d\vec{w}$ 也必须在 S 中。

> 「在向量空间中」表示「结果还停留在空间里面」。

**八个条件**（向量加法的 4 条 + 纯量乘法的 4 条）：
- (1) 交换律 $\vec{x} + \vec{y} = \vec{y} + \vec{x}$
- (2) 结合律 $\vec{x} + (\vec{y} + \vec{z}) = (\vec{x} + \vec{y}) + \vec{z}$
- (3) 唯一零向量 $\vec{x} + \vec{0} = \vec{x}$
- (4) 唯一负向量 $\vec{x} + (-\vec{x}) = \vec{0}$
- (5) $1\vec{x} = \vec{x}$
- (6) $(c_1c_2)\vec{x} = c_1(c_2\vec{x})$
- (7) $c(\vec{x} + \vec{y}) = c\vec{x} + c\vec{y}$
- (8) $(c_1 + c_2)\vec{x} = c_1\vec{x} + c_2\vec{x}$

### $\mathbb{R}^n$ 之外的三个向量空间

| 空间 | 内容 | 特点 |
|------|------|------|
| M | 所有实数 2×2 矩阵 | 「向量」是矩阵 |
| F | 所有实数函数 f(x) | 「向量」是函数 |
| Z | 只有一个零向量 | 最小向量空间，维度为 0 |

函数空间 F 是无限维；较小的空间 $P_n$ 包含所有 n 次多项式 $a_0 + a_1x + \cdots + a_nx^n$。

### 子空间

**定义**：向量空间的子空间是一个**包含零向量**的向量集合，且满足：
- (i) $\vec{v} + \vec{w}$ 在子空间中
- (ii) $c\vec{v}$ 在子空间中

> **合并规则**：一个包含 $\vec{v}$ 与 $\vec{w}$ 的子空间，必须包含所有的线性组合 $c\vec{v} + d\vec{w}$。

**关键**：
- 每个子空间都包含零向量（取 c = 0）
- **不包含原点的平面不是子空间**（必须通过原点 (0,0,0)）
- $\mathbb{R}^3$ 的子空间只有四种：通过原点的直线 (L)、通过原点的平面 (P)、整个 $\mathbb{R}^3$、Z = {(0,0,0)}
- 四分之一平面不是子空间（乘 c = -1 违反规则 ii）；两个四分之一平面之和失败（违反规则 i）

### 列空间 C(A)

**定义**：列空间包含 A 的列的所有线性组合，即所有可能的 $A\vec{x}$，构成 $C(A)$。

$$
\boxed{A\vec{x} = \vec{b} \text{ 有解} \iff \vec{b} \in C(A)}
$$

- A 是 m×n 矩阵时，列有 m 个分量，$C(A)$ 是 $\mathbb{R}^m$（不是 $\mathbb{R}^n$）的子空间
- 3×2 矩阵的列空间是 $\mathbb{R}^3$ 中的一个平面（两个列张成）
- $C(A)$ 通过原点，$\vec{0}$ 一定在其中

### 生成（span）

从向量集合 S 出发取所有线性组合，得到的一定是子空间 SS：

$$
SS = \text{span}(S) = \{c_1\vec{v}_1 + \cdots + c_N\vec{v}_N\}
$$

- SS 永远是**包含 S 的最小子空间**
- 当 S 是 A 的列集合，SS 就是列空间 C(A)
- 当 S 只有一个非零向量 $\vec{v}$，SS 是穿过 $\vec{v}$ 的直线

> 两个描述空间的通用方式：「____的所有组合」与「方程式 ____的所有解」。

## 3.2 A 的零空间：求解 Ax = 0 与 Rx = 0

### 零空间定义

**零空间 N(A)**：包含所有 $A\vec{x} = \vec{0}$ 的解 $\vec{x}$（$\vec{x} \in \mathbb{R}^n$）。

- 验证是子空间：$A(\vec{x} + \vec{y}) = \vec{0} + \vec{0}$，$A(c\vec{x}) = c\vec{0}$，封闭
- 零空间是 $\mathbb{R}^n$ 的子空间，列空间是 $\mathbb{R}^m$ 的子空间

### 消元法不改变零空间

$$
\boxed{N(A) = N(U) = N(R)}
$$

消元法（A → U → R）只做行运算，不改变方程组的解。

### 主元列与自由列

- **主元列**：有主元的列（主元变量）
- **自由列**：没有主元的列（自由变量）

**特殊解（special solution）**：每个自由列对应一个特殊解——令该自由变量为 1，其余自由变量为 0，再由 $R\vec{x} = \vec{0}$ 解出主元变量。

> 零空间 = 特殊解的所有组合。译者注：special solution 译为「特殊解」，与 3.3 的 particular solution「特解」区分。

**范例**：A = [1 2 3]，$x + 2y + 3z = 0$ 是平面。自由变量 y、z：
- $\vec{s}_1 = (-2, 1, 0)$，$\vec{s}_2 = (-3, 0, 1)$
- 平面上的所有向量都是 $\vec{s}_1$ 与 $\vec{s}_2$ 的组合

### 简化行阶梯形式 R = rref(A)

消元法在矩形矩阵上不停止于上三角 U，继续两步：
1. 在主元**上方**产生 0（利用主元行往上消元）
2. 在主元产生 1（整个主元行除以主元）

得到 R 后，主元列包含单位矩阵 I，零空间一目了然：**对每个自由列，把符号反过来即得特殊解**。

### 秩（rank）

$$
\boxed{\text{秩 } r = \text{主元的个数} = R \text{ 的非零行个数}}
$$

- 有 $n - r$ 个自由列
- **矮宽矩阵定理**：若 $n > m$（列比行多），$A\vec{x} = \vec{0}$ 必有非零解（至少 $n - m$ 个自由变量）
- 零空间维度 = 自由变量个数

### 秩一矩阵 A = uv^T

- 秩一矩阵只有一个主元，所有行是主元行的倍数，所有列是主元列的倍数
- 特殊形式：$A = \vec{u}\vec{v}^T$（列乘行）
- $A\vec{x} = \vec{u}(\vec{v}^T\vec{x}) = \vec{0}$ ⟹ $\vec{v}^T\vec{x} = 0$：零空间 = 与 $\vec{v}$ 垂直的平面（r = 1 时，行空间 = 直线，零空间 = 垂直平面）

## 3.3 Ax = b 的完整解

### 核心公式

$$
\boxed{\vec{x}_{\text{完整}} = \vec{x}_p + \vec{x}_n}
$$

**一个特解（particular solution）** + **零空间的任意向量**。

- 增广矩阵 $[A\ \vec{b}]$ 行简化得 $[R\ \vec{d}]$，$A\vec{x} = \vec{b}$ 等价于 $R\vec{x} = \vec{d}$
- **可解性条件**：R 的全零行对应的 d 分量也必须是 0（即 $\vec{b}$ 必须满足列空间条件）
- 范例：行 3 = 行 1 + 行 2 时，需要 $b_1 + b_2 = b_3$

### 求特解 xp 的标准做法

**令自由变量全部为 0**，主元变量直接从 $\vec{d}$ 读出。这个做法永远有效。

（例：自由变量 $x_2 = x_4 = 0$，主元变量 $x_1 = 1, x_3 = 6$ ⟹ $\vec{x}_p = (1, 0, 6, 0)$）

> 特解不能乘任意常数；只有零空间的特殊解才需要常数。

### 满秩的四种情形

| 情形 | 秩的条件 | 形状 | Ax = b 的解 |
|------|---------|------|------------|
| 1 | r = m = n | 方形可逆 | 恰好 1 个解 |
| 2 | r = m < n | 矮且宽 | 无限多解 |
| 3 | r = n < m | 高且瘦 | 0 个或 1 个解 |
| 4 | r < m, r < n | 非满秩 | 0 个或无限多解 |

**满列秩 r = n**（高且瘦，m ≥ n）：
1. 所有列都是主元列
2. 没有自由变量或特殊解
3. 零空间 N(A) = {零向量}（列线性无关）
4. 若 $A\vec{x} = \vec{b}$ 有解，则解唯一

> 满列秩时 R = [I; 0]，有 m - n 个零行，对应 b 的 m - n 个可解性条件。

**满行秩 r = m**（矮且宽，m ≤ n）：
1. 所有行都有主元，R 没有零行
2. 对**任何** $\vec{b}$，$A\vec{x} = \vec{b}$ 都有解
3. 列空间是整个 $\mathbb{R}^m$
4. 零空间有 n - m 个特殊解

> 几何直觉（满行秩范例）：两个平面交于一条直线，特解是直线上一点，加上零空间向量沿直线移动，$\vec{x}_p + \vec{x}_n$ 得到整条线。

## 3.4 无关、基底与维度

本章的四个核心观念：

```
1. 无关向量   （没有额外向量）
2. 生成空间   （足够的向量产生剩余向量）
3. 基底       （不太多也不太少）
4. 维度       （基底中向量的个数）
```

### 线性无关

**定义（矩阵版）**：当 $A\vec{x} = \vec{0}$ 的唯一解是 $\vec{x} = \vec{0}$ 时，A 的列线性无关。

**定义（向量序列版）**：$c_1\vec{v}_1 + \cdots + c_n\vec{v}_n = \vec{0}$ 只在所有 $c_i$ 全为 0 时成立。

关键结论：
- 一个向量序列非相关即无关，关键问题是「什么组合可以得到零向量」
- 若其中一个 $\vec{v}$ 是零向量，则必然相关
- **若 n > m，$\mathbb{R}^m$ 中任意 n 个向量必然相关**（主元数 ≤ m）
- 若 n ≤ m，可能相关也可能无关；消元法得到 r 个主元列，这 r 个主元列无关

> 语言注意：「向量序列是线性无关」✓；「向量是无关」可接受；「矩阵是无关」✗。
> 相关 ⟺ 某个向量是其他向量的组合。但定义用「组合得零」更优：所有列等同对待，不必选出一个「罪恶」向量。

### 生成（span）与行空间

- 若向量集合的线性组合填满一个空间，则向量集合**生成**这个空间
- 列生成列空间；**行生成行空间**
- 行空间 = $C(A^T)$（A 的转置的列空间），是 $\mathbb{R}^n$ 的子空间

### 基底（basis）

**定义**：一组基底是由线性无关且生成空间的向量组成。

- **空间中的每个向量都是基底向量的唯一组合**（唯一性来自无关性）
- I 的列是 $\mathbb{R}^n$ 的标准基底（i, j, k…）
- **每个可逆 n×n 矩阵的列都是 $\mathbb{R}^n$ 的一组基底**（⟹ $\mathbb{R}^n$ 有无穷多基底）
- 主元列是列空间的一组基底，主元行是行空间的一组基底
- 零空间的基底：n - r 个特殊解

> 求「5 个向量生成的空间的基底」：
> - 方法一：作为行 → 消元法 → R 的非零行
> - 方法二：作为列 → 消元法 → A 的主元列（不是 R 的！）

### 维度（dimension）

$$
\boxed{\text{空间的维度} = \text{每组基底中向量的个数}}
$$

- 所有基底都有相同向量数（证明：两组基底 v 与 w，若 n > m，则 W = VA 中 A 是矮宽矩阵必有非零解 Ax = 0 ⟹ Wx = 0，矛盾）
- 穿过 $\vec{v} = (1, 5, 2)$ 的直线维度 1；垂直平面 $x + 5y + 2z = 0$ 维度 2（基底 $(-5, 1, 0)$ 与 $(-2, 0, 1)$ 就是特殊解！）

### 矩阵空间与函数空间的维度

| 空间 | 维度 |
|------|------|
| 所有 n×n 矩阵 | $n^2$ |
| 上三角矩阵 | $n^2/2 + n/2$ |
| 对角矩阵 | n |
| 对称矩阵 | $n^2/2 + n/2$ |
| 微分方程 $y'' = 0$ 的解 | 2（基底 x 与 1）|
| $y'' = -y$ 的解 | 2（基底 sinx 与 cosx）|

> $y'' = 2$ 的解不是子空间（b ≠ 0）；完整解是特解 $x^2$ + 零空间函数 $cx + d$。线性微分方程 = 矩阵方程 $A\vec{x} = \vec{b}$，只是用微积分求解。
> Z（仅零向量）的维度是 0，基底是空集合。

## 3.5 四个子空间的维度

### 四个基础子空间

| # | 子空间 | 记号 | 所在空间 | 维度 |
|---|--------|------|---------|------|
| 1 | 行空间 | $C(A^T)$ | $\mathbb{R}^n$ | r |
| 2 | 列空间 | $C(A)$ | $\mathbb{R}^m$ | r |
| 3 | 零空间 | $N(A)$ | $\mathbb{R}^n$ | n - r |
| 4 | 左零空间 | $N(A^T)$ | $\mathbb{R}^m$ | m - r |

**左零空间（left nullspace）**：求解 $A^T\vec{y} = \vec{0}$，改写为 $\vec{y}^TA = \vec{0}^T$——$\vec{y}$ 出现在 A 的**左侧**，故得名。

### 线性代数的基础定理（第一部分）

$$
\boxed{\dim C(A) = \dim C(A^T) = r \qquad (\text{秩定理：列秩 = 行秩})}
$$

$$
\boxed{\dim N(A) = n - r, \qquad \dim N(A^T) = m - r}
$$

**计数定理**：
- 在 $\mathbb{R}^n$：$r + (n - r) = n$（行空间 + 零空间）
- 在 $\mathbb{R}^m$：$r + (m - r) = m$（列空间 + 左零空间）

### R 的四个子空间（3×5，秩 r = 2 范例）

R = rref(A) 的特殊形状让四个子空间一目了然：

1. **行空间**：R 的前 r 个非零行（主元行）是一组基底，维度 r
2. **列空间**：R 的主元列（以 r×r 单位矩阵开头）是基底，维度 r
3. **零空间**：n - r 个特殊解是基底（自由变量行包含单位矩阵，保证无关），维度 n - r
4. **左零空间**：R 尾端 m - r 个零行——行组合得零 ⟹ $\vec{y} = (0, \ldots, 0, y_{r+1}, \ldots, y_m)$，维度 m - r

### A 与 R 的关系（重要！）

| 子空间 | A 与 R | 原因 |
|--------|--------|------|
| 行空间 | **相同**（同基底）| 行运算不改变行的组合关系 |
| 零空间 | **相同**（同基底）| 消元法不改变解 |
| 列空间 | 维度相同，**空间不同**（C(A) ≠ C(R)）| R 的列常以 0 结尾，A 的列不是 |
| 左零空间 | 维度相同 | 列秩 = 行秩 |

**错误理由**：「A 与 R 有相同的列空间」是错的。正确理由：相同的列组合对 A 与 R 都为零（或非零），在 A 中相关 ⟺ 在 R 中相关。

> 结论：A 的主元列是 C(A) 的基底（不是 R 的）。

### 秩一与秩二矩阵的分解

**秩一**：$A = \vec{u}\vec{v}^T$，列空间基底是 $\vec{u}$，行空间基底是 $\vec{v}$，零空间 = 与 $\vec{v}$ 垂直的平面。

**秩二 = 秩一 + 秩一**：

$$
A = \vec{u}_1\vec{v}_1^T + \vec{u}_2\vec{v}_2^T
$$

其中 $\vec{u}_1, \vec{u}_2$ 是 A 的主元列（C(A) 的基底），$\vec{v}_1^T, \vec{v}_2^T$ 是 R 的非零行（行空间的基底）。

> **推广**：每个秩 r 的矩阵 = r 个秩一矩阵之和（主元列乘 R 的非零行）。

### 入射矩阵范例（图论应用）

图 G（4 节点 5 边）的入射矩阵 A（5×4，每行一个 1 一个 -1）：

- **零空间** N(A)：解是 $\vec{x} = (c, c, c, c)$（所有节点电压相等），维度 1，基底 (1, 1, 1, 1) ⟹ 秩 r = 4 - 1 = 3
- **列空间** C(A)：A 的列 1, 2, 3 无关（树），是基底，维度 3
- **行空间**：行 1, 2, 4 无关（树），是基底；行 1, 2, 3 相关（构成回圈）
- **左零空间** N(A^T)：回圈对应 y = (1, -1, 1, 0, 0) 与 (0, 0, -1, 1, 1)，维度 5 - 3 = 2

> 图论洞察：**回圈（cycle）⟹ 相关行；树（tree）⟹ 无关行**。
> 物理意义：$A\vec{x} = \vec{b}$ 是节点电压方程，$A^T\vec{y} = \vec{0}$ 是基尔霍夫电流定律（平衡方程式）——「流进节点的量 = 流出的量」。

### 补充：秩的不等式

- 秩(AB) ≤ 秩(B)（AB 的行是 B 的行的组合）
- 秩(AB) ≤ 秩(A)（AB 的列是 A 的列的组合）
- 左乘或右乘**可逆矩阵**不改变秩

## 全章要点复习

1. **向量空间** = 对加法与纯量乘法封闭的向量集合；**子空间** = 含零向量且封闭的子集（通过原点的直线/平面）。
2. **列空间 C(A)** = A 的列的所有组合；$A\vec{x} = \vec{b}$ 有解 ⟺ $\vec{b} \in C(A)$。
3. **零空间 N(A)** = 所有 $A\vec{x} = \vec{0}$ 的解；消元法不改变它：N(A) = N(U) = N(R)。
4. **特殊解**：每个自由列一个——自由变量设 1（其余 0），主元变量解出；零空间 = 特殊解的组合。
5. **秩 r** = 主元数 = R 的非零行数；有 n - r 个自由变量。
6. **矮宽矩阵**（n > m）的零空间必有非零向量。
7. **完整解**：$A\vec{x} = \vec{b}$ 的解 = 特解 $\vec{x}_p$（自由变量=0）+ 零空间 $\vec{x}_n$。
8. **满列秩 r = n**：零空间只有零向量，解唯一（若存在）；**满行秩 r = m**：任何 b 都有解。
9. **无关**：$A\vec{x} = \vec{0}$ 唯一解 $\vec{x} = \vec{0}$；n > m 时 $\mathbb{R}^m$ 中 n 个向量必相关。
10. **基底** = 无关 + 生成；**维度** = 基底向量数；主元列是列空间基底，主元行是行空间基底，特殊解是零空间基底。
11. **基础定理（第一部分）**：$\dim C(A) = \dim C(A^T) = r$，$\dim N(A) = n - r$，$\dim N(A^T) = m - r$。
12. **秩一矩阵** $A = \vec{u}\vec{v}^T$：列空间基底 $\vec{u}$、行空间基底 $\vec{v}$；秩 r 矩阵 = r 个秩一矩阵之和。

```
空间看封闭           ← 加法和纯量乘法不出界
子空间必过原点       ← 不通过原点的平面不是子空间
列空间装 b           ← b ∈ C(A) ⟺ Ax=b 有解
零空间装解           ← N(A) = 所有 Ax=0 的解
消元不变零空间       ← N(A) = N(U) = N(R)
特殊解自由变量       ← 自由列各得一个，其余为 0
秩 = 主元个数        ← 也 = R 非零行数 = 列空间维度
解 = 特解 + 零空间   ← xp（自由变量=0）+ xn
满列秩唯一           ← r=n：零空间只剩 0
满行秩恒有解         ← r=m：列空间占满 R^m
无关唯一零组合       ← 零空间只有 0 ⟺ 列无关
基底无关且生成       ← 每个向量唯一组合
维度=基底个数        ← 所有基底个数相同
四子空间两两配对     ← C(A)与C(A^T)同维度 r；N 补足 n-r, m-r
秩一 = 列乘行         ← A = uv^T；秩 r = r 个秩一之和
```
