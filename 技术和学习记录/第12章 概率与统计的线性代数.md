## 1. 12.1 平均值，方差与概率 (Mean, Variance, and Probability)

### 1.1 核心概念与三个维度的数学表达

在概率、统计学与机器学习的交叉领域，“平均值”与“方差”是描述数据分布特征的最基础统计量。作为贯穿本书的核心思想，我们必须严密区分**来自完整试验的实际测量结果（样本经验值）**与**基于概率模型的理论期望结果（总体期望值）**。

#### 三个维度的对比与严格数学定义

为了建立清晰的代数直觉，我们将统计量置于三个递进的观察维度下进行对比：

```
[维度 1: 样本数据] ──(大数法则 N → ∞)──> [维度 2: 离散概率分布] ──(连续化极限)──> [维度 3: 连续概率密度]
  样本均值 m / S²                          离散期望 E[x] / σ²                        密度积分 ∫ x p(x)dx / σ²
```

1. **样本表达（经验值 / 实际观察维度）**
   * **样本平均值 $m$（或记为 $m_{\text{sample}}$）**：来自 $N$ 个已知观察样本 $x_1, x_2, \dots, x_N$ 的算术平均值：
     $$m = \frac{1}{N}(x_1 + x_2 + \dots + x_N) = \frac{1}{N}\sum_{i=1}^N x_i $$
   * **样本无偏方差 $S^2$**：衡量实际观察样本偏离样本平均值 $m$ 的二次离散程度：
     $$S^2 = \frac{1}{N-1} \sum_{i=1}^N (x_i - m)^2 $$
   * **自由度损失与无偏估计（Unbiased Estimator）**：
     在计算样本方差时，分母必须使用自由度 $N-1$ 而非样本总数 $N$。其根本原因在于：计算 $S^2$ 之前，我们必须先用这 $N$ 个数据计算出样本均值 $m$。这建立了一个线性约束条件 $\sum_{i=1}^N (x_i - m) = 0$，使得 $N$ 个残差项 $(x_i - m)$ 中仅有 $N-1$ 个可以自由变化（即消耗了 $1$ 个自由度）。若分母仍使用 $N$，其期望值会产生系统性偏差（$E[S_{\text{biased}}^2] = \frac{N-1}{N}\sigma^2$）；而除以 $N-1$ 则能精确纠正这一偏差，使 $E[S^2] = \sigma^2$，从而得到总体方差 $\sigma^2$ 的**无偏估计量**。

2. **离散型概率分布（期望值 / 概率加权维度）**
   * **离散期望值 $E[x]$（总体均值 $\mu_{\text{pop}}$）**：设随机变量 $x$ 具有 $n$ 个可能出现的离散值 $x_1, \dots, x_n$，对应概率分别为 $p_1, \dots, p_n$（满足 $p_i \ge 0$ 且 $\sum p_i = 1$）。期望值定义为概率向量 $\boldsymbol{p}$ 与数值向量 $\boldsymbol{x}$ 的内积：
     $$m = E[x] = \mu_{\text{pop}} = p_1 x_1 + p_2 x_2 + \dots + p_n x_n = \sum_{i=1}^n p_i x_i = \boldsymbol{p} \cdot \boldsymbol{x} $$
     *符号辨析*：样本均值 $m$ 告诉我们“实际观察得到了什么”；而期望值 $E[x]$ 告诉我们“基于理论概率预期得到什么”。
   * **总体方差 $\sigma^2$**：可能离散结果偏离总体均值 $m$ 的加权二次偏离程度：
     $$\sigma^2 = E[(x - m)^2] = \sum_{i=1}^n p_i (x_i - m)^2 $$
   * **大数法则（Law of Large Numbers, LLN）及收敛性**：
     大数法则指出，当独立重复试验的样本量 $N \to \infty$ 时，样本平均值 $m = \frac{1}{N}\sum x_i$ 收敛于总体理论期望值 $E[x]$。这里有两种强度不同的收敛（注意不要混用）：

* **弱大数定律（Khinchin）**：$m_N \xrightarrow{P} E[x]$，即**依概率收敛**。
* **强大数定律（Kolmogorov）**：在 i.i.d. 且 $E|x| < \infty$ 的条件下，$m_N \xrightarrow{\text{a.s.}} E[x]$，即**几乎必然收敛**（也叫"以概率 1 收敛"）。

"以概率 1"和"依概率"是两种**不等价**的收敛模式，不能叠在一起说。本节后续用方差 $\sigma_N^2 = \sigma^2/N$ 配合切比雪夫不等式，走的正是**弱**大数定律的路线。例如抛掷公平硬币（$p_0=1/2$ 表示反面，$p_1=1/2$ 表示正面），期望值 $E[x] = \frac{1}{2}(0) + \frac{1}{2}(1) = 1/2$；在 $N$ 次独立投掷中，正面出现的比例在 $N \to \infty$ 时极限逼近 $1/2$。

3. **连续型概率分布（密度函数积分维度）**
   * **累积分布函数（CDF）与概率密度函数（PDF）**：
     当随机变量的可能取值扩展到连续实数区间（如测量学生精确年龄介于 $17$ 至 $20$ 岁），任意单点精确值（如恰好 $17.1000\dots$ 岁）的概率为 $0$。因此，必须通过**累积分布函数（CDF）** $F(x) = P(X \le x)$ 描述随机变量落在 $(-\infty, x]$ 范围内的概率。
     对 $F(x)$ 求导即可得到**概率密度函数（PDF）** $p(x) = \frac{dF(x)}{dx}$。连续随机变量落在区间 $[a, b]$ 内的概率为密度函数的定积分：
     $$P(a \le x \le b) = F(b) - F(a) = \int_a^b p(x) dx $$
   * **连续型期望值 $m$ 与总体方差 $\sigma^2$**：
     $$m = E[x] = \int_{-\infty}^{\infty} x p(x) dx$$
     $$\sigma^2 = E[(x - m)^2] = \int_{-\infty}^{\infty} (x - m)^2 p(x) dx $$

#### 关键恒等式推导

在实际计算样本方差与总体方差时，直接应用二次项展开恒等式可以极大简化代数运算。

##### 样本方差展开恒等式推导：
$$\begin{aligned}
\sum_{i=1}^N (x_i - m)^2 &= \sum_{i=1}^N (x_i^2 - 2m x_i + m^2) \\
&= \sum_{i=1}^N x_i^2 - 2m \sum_{i=1}^N x_i + \sum_{i=1}^N m^2
\end{aligned}$$
代入样本均值定义 $m = \frac{1}{N}\sum_{i=1}^N x_i$，即 $\sum_{i=1}^N x_i = N m$；同时 $m^2$ 对 $i$ 累加 $N$ 次得到 $N m^2$：
$$\sum_{i=1}^N (x_i - m)^2 = \left( \sum_{i=1}^N x_i^2 \right) - 2m(N m) + N m^2 = \left( \sum_{i=1}^N x_i^2 \right) - N m^2 $$
同理，离散总体方差亦可展开为 $\sigma^2 = E[x^2] - m^2 = \left( \sum_{i=1}^n p_i x_i^2 \right) - m^2$。

#### 条件与失效场景

* **大数法则成立的充分条件**：i.i.d.（相互独立且同分布）且期望值 $E[x]$ 有限，是**充分而非必要**的条件。弱大数定律其实只需要"两两不相关 + 方差一致有界"——由切比雪夫不等式 $P(|m_N - E[x]| \ge k\sigma_N) \le \frac{1}{k^2}$ 即可得到，甚至不要求同分布。所以不要把 i.i.d. 说成"必须"。
* **柯西分布（Cauchy Distribution）失效场景**：
  若随机变量服从柯西分布，其概率密度函数为 $p(x) = \frac{1}{\pi (1 + x^2)}$。尝试计算其理论期望值：
  $$E[x] = \int_{-\infty}^{\infty} \frac{x}{\pi (1 + x^2)} dx$$
  该积分的主值虽为 $0$，但广义积分绝对不收敛（发散）。由于柯西分布不存在有限的期望值和方差（具有长尾/重尾特性），**大数法则在此彻底失效**。无论增加多少样本量 $N$，样本均值 $m$ 都会极度不稳定地剧烈跳变，不会收敛到任何固定数值；此时样本方差 $S^2$ 也会随着 $N$ 的增加趋于无穷大。

#### 经典例题走流程：大一新生年龄例题

* **流程一：离散样本值计算**
  已知 $N=5$ 个大一新生的实际采样年龄：$\{18, 17, 18, 19, 17\}$。
  1. 样本均值：$m = \frac{18 + 17 + 18 + 19 + 17}{5} = \frac{89}{5} = 17.8$。
  2. 偏差平方和：$(18-17.8)^2 + (17-17.8)^2 + (18-17.8)^2 + (19-17.8)^2 + (17-17.8)^2 = 0.04 + 0.64 + 0.04 + 1.44 + 0.64 = 2.8$。
  3. 样本无偏方差：$S^2 = \frac{1}{5-1}(2.8) = \frac{2.8}{4} = 0.7$。

* **流程二：离散概率分布计算**
  已知总体大一新生班级的理论概率分布为：$P(X=17)=0.2$, $P(X=18)=0.5$, $P(X=19)=0.3$。
  1. 理论期望值：$m = E[x] = (0.2)(17) + (0.5)(18) + (0.3)(19) = 3.4 + 9.0 + 5.7 = 18.1$。
  2. 总体方差：
     $$\begin{aligned}
     \sigma^2 &= (0.2)(17 - 18.1)^2 + (0.5)(18 - 18.1)^2 + (0.3)(19 - 18.1)^2 \\
     &= (0.2)(-1.1)^2 + (0.5)(-0.1)^2 + (0.3)(0.9)^2 \\
     &= (0.2)(1.21) + (0.5)(0.01) + (0.3)(0.81) = 0.242 + 0.005 + 0.243 = 0.49
     \end{aligned}$$
  3. 总体标准差：$\sigma = \sqrt{0.49} = 0.7$。

#### 🤖 在 AI / 机器学习中的深度应用

##### 1. Batch Normalization (批量归一化)
在深度神经网络的训练中，第 $l$ 层的激活值 $\boldsymbol{x}$ 会受到前层参数更新的影响（内部 covariate shift）。Batch Normalization 在每个 mini-batch（大小为 $B$）上计算样本均值与样本方差：
$$\mu_B = \frac{1}{B}\sum_{i=1}^B x_i, \quad \sigma_B^2 = \frac{1}{B}\sum_{i=1}^B (x_i - \mu_B)^2$$
并在训练过程中维护全局的滑动平均均值（Running Mean）与滑动平均方差（Running Variance），以确保推理（Inference）阶段能使用稳定的总体估计。

##### 2. 特征工程：Z-score Normalization (StandardScaler)
在输入特征送入支持向量机（SVM）、线性回归或神经网络之前，若特征缩放不一致，会导致梯度下降呈椭圆锯齿状收敛。通过标准化变换：
$$\hat{x}_i = \frac{x_i - m}{S}$$
使得重构后的特征集满足样本均值为 $0$，样本方差为 $1$，彻底优化了目标函数的条件数（Condition Number）。

##### 3. 经验风险最小化（ERM）与期望风险（Expected Risk）
机器学习的核心目标是最小化未知真实分布 $p(\boldsymbol{x}, y)$ 下的**期望风险**：
$$R(\theta) = E_{(\boldsymbol{x}, y) \sim p}[L(f_\theta(\boldsymbol{x}), y)] = \iint L(f_\theta(\boldsymbol{x}), y) p(\boldsymbol{x}, y) d\boldsymbol{x} dy$$
由于真实分布 $p$ 不可知，算法使用包含 $N$ 个独立同分布样本的训练集，将目标替换为可计算的**经验风险**（Empirical Risk Minimization, ERM）：
$$R_{\text{emp}}(\theta) = \frac{1}{N}\sum_{i=1}^N L(f_\theta(\boldsymbol{x}_i), y_i)$$
根据大数法则，当训练样本量 $N \to \infty$ 时，经验风险 $R_{\text{emp}}(\theta)$ 依概率收敛于期望风险 $R(\theta)$。

### 1.2 两种经典连续分布：均匀分布与正态分布

#### 均匀分布（Uniform Distribution）

假定随机变量 $x$ 在区间 $[0, a]$ 上均匀分布（$U(0, a)$），代表区间内任意微小等长子区间发生的概率完全相等。

* **概率密度（PDF）与累积分布（CDF）**：
  * $p(x) = \begin{cases} \frac{1}{a}, & 0 \le x \le a \\ 0, & \text{其他} \end{cases}$
  * $F(x) = \int_0^x \frac{1}{a} dt = \frac{x}{a} \quad (0 \le x \le a)$
* **均值与方差推导**：
  * 均值 $m = E[x] = \int_0^a x \left(\frac{1}{a}\right) dx = \left[ \frac{x^2}{2a} \right]_0^a = \frac{a}{2} $
  * 方差 $\sigma^2$ 的积分推导（应用平移技巧）：
    $$\sigma^2 = \int_0^a \frac{1}{a} \left(x - \frac{a}{2}\right)^2 dx$$
    引入变量替换 $u = x - \frac{a}{2}$，积分区间平移至 $\left[-\frac{a}{2}, \frac{a}{2}\right]$：
    $$\sigma^2 = \frac{1}{a} \int_{-a/2}^{a/2} u^2 du = \frac{1}{a} \left[ \frac{u^3}{3} \right]_{-a/2}^{a/2} = \frac{1}{a} \left( \frac{a^3}{24} - \left(-\frac{a^3}{24}\right) \right) = \frac{a^2}{12} $$
* **典型推论**：
  在 $[0, 1]$ 上均匀生成的随机数（如 MATLAB `rand(1)`），均值 $m = 1/2$，方差 $\sigma^2 = 1/12$。

#### 高斯 / 正态分布（Normal Distribution）

正态分布是概率论与线性代数中最核心的连续分布。

* **标准正态分布 $N(0, 1)$**：
  * 概率密度函数：
    $$p(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2} $$
  * **三大标准事实与奇偶性证明**：
    1. **全概率归一化**：$\int_{-\infty}^{\infty} \frac{1}{\sqrt{2\pi}} e^{-x^2/2} dx = 1$（证明见自测题 12 极坐标变换）。
    2. **均值为 0**：$m = \int_{-\infty}^{\infty} x p(x) dx = 0$。证明：被积函数 $g(x) = x e^{-x^2/2}$ 满足 $g(-x) = -g(x)$，为奇函数。在对称区间 $(-\infty, \infty)$ 上，正负两侧积分严格抵消，故积分结果必定为 $0$。
    3. **单位方差**：$\sigma^2 = \int_{-\infty}^{\infty} (x-0)^2 \frac{1}{\sqrt{2\pi}} e^{-x^2/2} dx = 1$。
* **一般正态分布 $N(m, \sigma)$**：
  对标准正态变量进行平移（平移量 $m$）和缩放（缩放因子 $\sigma$），其密度函数为：
  $$p(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{(x-m)^2}{2\sigma^2}} $$
* **经验区间规则（Empirical Rule）**：
  * $1\sigma$ 区间：$P(m - \sigma \le X \le m + \sigma) \approx 68.3\%$（约 $2/3$ 的概率体落在此区间）。
  * $2\sigma$ 区间：$P(m - 2\sigma \le X \le m + 2\sigma) \approx 95.4\%$。若观测事件偏离均值超过 $2\sigma$，其随机发生的概率小于 $5\%$。
  * 物理学标准：粒子物理学（如 Higgs 玻色子的发现）采用极其严格的 **$5\sigma$** 标准（偶然概率仅约 $3 \times 10^{-7}$）。

#### 🤖 在 AI / 机器学习中的深度应用

##### 1. 权重初始化（Xavier / He Initialization）
在深度神经网络中，前向传播时若权重方差控制不当，激活值会逐层爆炸或消失。
* **Xavier Uniform 初始化**：若前层输入维度为 $n_{\text{in}}$，后层输出维度为 $n_{\text{out}}$，权重 $W$ 从均匀分布 $U(-a, a)$ 中采样，其中 $a = \sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}}$。根据公式 $\sigma^2 = \frac{(2a)^2}{12} = \frac{a^2}{3}$，可确保权重方差为 $\text{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}}$，精准维持了前后层信号方差的一致性。

##### 2. 变分自编码器（VAE）的隐空间先验
在 VAE 中，编码器推断出隐变量的后验分布 $q_\phi(z|x) = N(\mu_\theta(x), \Sigma_\theta(x))$。为了使隐空间具备连续性与可采样性，极小化其与标准高斯先验 $p(z) \sim N(\mathbf{0}, \boldsymbol{I})$ 之间的 KL 散度（KL-Divergence），确保隐空间向量平滑分布。

##### 3. 高斯过程（Gaussian Processes, GP）与卡尔曼滤波（Kalman Filter）
高斯分布具有高度优美的数据代数封闭性：高斯分布的边缘分布与条件分布依然是高斯分布。这一性质使得卡尔曼滤波与高斯过程能够以闭式解（Closed-form Solution）实时更新线性动态系统的状态均值与协方差。

### 1.3 独立重复试验、线性变换与中央极限定理

#### 随机变量的线性变换性质

若对随机变量进行线性缩放与平移变换 $x_{\text{new}} = a x_{\text{old}} + b$（$a, b$ 为实常数），其统计量推导如下：
* **均值变换**：$m_{\text{new}} = E[a x_{\text{old}} + b] = a E[x_{\text{old}}] + b = a m_{\text{old}} + b$
* **方差变换**：
  $$\sigma^2_{\text{new}} = E[(x_{\text{new}} - m_{\text{new}})^2] = E[((a x_{\text{old}} + b) - (a m_{\text{old}} + b))^2] = E[a^2 (x_{\text{old}} - m_{\text{old}})^2] = a^2 \sigma^2_{\text{old}} $$

#### $N$ 次独立重复试验总和与平均值的统计量

设 $x_1, x_2, \dots, x_N$ 为 $N$ 个独立同分布（i.i.d.）随机变量，单次试验均值为 $m$，方差为 $\sigma^2$。定义样本均值 $A_N = \frac{1}{N}\sum_{i=1}^N x_i$。
* $A_N$ 的期望值：$E[A_N] = \frac{1}{N} \sum_{i=1}^N E[x_i] = \frac{N m}{N} = m$。
* $A_N$ 的方差衰减律：由于各样本相互独立，协方差项为 $0$，方差满足加性：
  $$\sigma_N^2 = \text{Var}(A_N) = \text{Var}\left( \frac{1}{N} \sum_{i=1}^N x_i \right) = \frac{1}{N^2} \sum_{i=1}^N \text{Var}(x_i) = \frac{N \sigma^2}{N^2} = \frac{\sigma^2}{N} $$
  对于单次试验结果为 $x \in \{0, 1\}$ 的硬币投掷（单次 $\sigma^2 = 1/4$），$N$ 次投掷平均值 $A_N$ 的方差为 $\sigma_N^2 = \frac{1}{4N}$。

#### 中心化与标准化（Normalization / Standardization）

对 $N$ 次投掷硬币中正面总次数 $x = N A_N$（均值为 $N/2$，方差为 $N/4$，标准差为 $\sqrt{N}/2$）构造标准正态变量 $X$：
$$X = \frac{x - m}{\sigma_N} = \frac{x - N/2}{\sqrt{N}/2}$$
* **中心化（Centralization）**：减去均值 $m = N/2$，消除趋势项，使新变量期望值为 $0$。
* **标准化（Standardization）**：除以标准差 $\sigma_N = \sqrt{N}/2$，使得新变量的方差严格等于 $1$。

#### 中央极限定理（CLT）与 Stirling 公式严密推导

**中央极限定理**：设 $x_1, x_2, \dots, x_N$ 为独立同分布且具有有限均值 $m$ 与有限方差 $\sigma^2$ 的随机变量，当 $N \to \infty$ 时，其中心标准化变量 $X$ 的累积分布函数收敛于标准正态分布 $N(0, 1)$。

##### 基于 Stirling 公式的中心峰值拟合严格推导：
在 $N$ 次硬币投掷（$N$ 为偶数）中，出现恰好 $N/2$ 次正面的二项概率为：
$$p_{N/2} = \frac{1}{2^N} \binom{N}{N/2} = \frac{1}{2^N} \frac{N!}{(N/2)! (N/2)!}$$
当 $N$ 极大时，应用 Stirling 阶乘近似公式 $N! \approx \sqrt{2\pi N} \left(\frac{N}{e}\right)^N$ 展开：
$$p_{N/2} \approx \frac{1}{2^N} \frac{\sqrt{2\pi N} (N/e)^N}{\left[ \sqrt{2\pi (N/2)} (N/2e)^{N/2} \right]^2} = \frac{1}{2^N} \frac{\sqrt{2\pi N} (N/e)^N}{\pi N (N / 2e)^N} = \sqrt{\frac{2}{\pi N}} $$
将二项分布的标准差 $\sigma_N = \sqrt{N}/2$（即 $\sqrt{N} = 2\sigma_N$）代入上式，得：
$$p_{N/2} \approx \frac{\sqrt{2}}{\sqrt{\pi} (2\sigma_N)} = \frac{1}{\sqrt{2\pi} \sigma_N}$$
注意到标准正态密度函数 $p_{N(0,1)}(X) = \frac{1}{\sqrt{2\pi}} e^{-X^2/2}$ 在中心点 $X=0$ 处的密度高度为 $\frac{1}{\sqrt{2\pi}}$，由于变量缩放因子为 $\sigma_N$，故原变量中心高度完全拟合高斯密度高度 $\frac{1}{\sqrt{2\pi} \sigma_N}$。**这说明二项分布在中心点处的密度量级与高斯完全吻合**——它满足局部极限定理在单点上的必要条件，但"单点高度吻合"**还不足以**证明整个分布收敛于高斯（完整证明需要 de Moivre–Laplace 局部极限定理对区间内所有 $k$ 成立，或改用特征函数法）。

#### CLT 的失效场景

1. **重尾/长尾分布（Heavy-tailed Distributions）**：如帕累托分布（Pareto Distribution）或柯西分布，当总体方差不存在（发散为无穷大）时，CLT 的前提条件破坏，样本均值不收敛于正态分布。
2. **相依结构导致方差不再线性增长**：CLT 失效的关键不是"相关性强"，而是 $\mathrm{Var}\big(\sum_{i=1}^{N}x_i\big)$ **不再按 $N$ 一阶增长**、即 $\mathrm{Var}(A_N)$ 不再按 $1/N$ 衰减。典型情形：所有 $x_i$ 完全相同（方差按 $N^2$ 增长）、长记忆过程、非混合过程——此时中心标准化变量或收敛到非高斯稳定律，或根本没有极限。反过来说，**弱相依不会破坏 CLT**：$m$-依赖序列、$\alpha$-混合序列（如 AR(1)、MA 过程）只要相依足够弱，CLT 依然成立。
3. **样本量 $N$ 过小**：在微观小样本下（如 $N=4$），分布仍呈现显著的离散柱状，无法使用连续正态分布精确近似。

#### 🤖 在 AI / 机器学习中的深度应用

##### 1. 深度学习中残差与噪声的高斯假设
在回归问题及扩散模型中，通常假设测量噪声 $\epsilon \sim N(0, \sigma^2 \boldsymbol{I})$。CLT 解释了这一假设的合理性：自然界与复杂系统中的观察误差往往由大量微小且独立的随机扰动累加而成，根据 CLT，这些扰动的总和必然趋近高斯分布。

##### 2. 随机梯度下降（SGD）Mini-batch 梯度的正态近似
在训练深度网络时，全量梯度被大小为 $B$ 的 Mini-batch 估计梯度 $\boldsymbol{g}_B = \frac{1}{B}\sum_{i=1}^B \nabla_\theta L(f_\theta(\boldsymbol{x}_i), y_i)$ 所替代。根据 CLT，Mini-batch 梯度的噪声 $\boldsymbol{g}_B - \nabla_\theta R(\theta)$ 在概率上逼近高斯分布 $N(\mathbf{0}, \frac{1}{B}\boldsymbol{\Sigma})$，为随机梯度 Langevin 动力学（SGLD）与隐式正则化理论提供了理论支柱。

### 1.4 蒙特卡罗估计与多阶层蒙特卡罗（MLMC）

在许多高维概率计算、贝叶斯后验推断或复杂偏微分方程不确定性量化中，总体解析概率密度 $p(x)$ 难以获得。蒙特卡罗（Monte Carlo, MC）方法通过大量采样求均值来拟合理论期望。

#### 标准蒙特卡罗方法（Monte Carlo Method）

* **估计公式**：独立采样数据点 $b_1, \dots, b_N$，计算对应的昂贵目标输出 $x_k = x(b_k)$，取样本平均：
  $$E[x] \approx \frac{1}{N} \sum_{k=1}^N x_k$$
* **收敛性与误差**：估计量的方差按 $\sigma^2 / N$ 衰减，其标准误差阶数为 $O(1/\sqrt{N})$。这意味着欲将精度提高一位（误差缩小为原来的 $1/10$），必须将样本量 $N$ 扩大 **$100$ 倍**，计算成本随精度要求呈二次方暴涨。

#### 多阶层蒙特卡罗（Multilevel Monte Carlo, MLMC）

由 Michael Giles (2015) 提出的 MLMC 方法，通过将粗糙/低成本拟合与精细/高成本拟合进行组合，实现了计算成本的飞跃性降低。

##### 两阶层蒙特卡罗（2-Level MC）推导与拉格朗日乘子法优化：
设目标高精度变量为 $x$（单次采样计算成本为昂贵的 $C^*$），构造一个低精度的便宜近似变量 $y$（单次采样计算成本为低廉的 $C$）。利用恒等式 $E[x] = E[y] + E[x - y]$，构建估计量：
$$E[x] \approx \frac{1}{N}\sum_{k=1}^N y(b_k) + \frac{1}{N^*}\sum_{k=1}^{N^*} [x(b_k) - y(b_k)]$$
设 $y$ 的方差为 $\sigma^2$，残差 $x - y$ 的方差为 $(\sigma^*)^2$。由于 $y$ 与 $x$ 极度接近，残差方差远小于原方差（$(\sigma^*)^2 \ll \sigma^2$）。
总体估计方差为 $\text{Var}_{\text{total}} = \frac{\sigma^2}{N} + \frac{(\sigma^*)^2}{N^*}$，总计算成本为 $C_{\text{total}} = N C + N^* C^*$。

##### 最佳样本比率的拉格朗日乘子法严格推导：
我们的目标是在固定总预算 $C_{\text{total}}$ 的条件下，最小化总体方差 $\text{Var}_{\text{total}}$。构造拉格朗日函数：
$$\mathcal{L}(N, N^*, \lambda) = \left( \frac{\sigma^2}{N} + \frac{(\sigma^*)^2}{N^*} \right) + \lambda (N C + N^* C^* - C_{\text{total}})$$
分别对 $N$ 与 $N^*$ 求偏导数并令其等于 $0$：
$$\frac{\partial \mathcal{L}}{\partial N} = -\frac{\sigma^2}{N^2} + \lambda C = 0 \implies N = \frac{\sigma}{\sqrt{\lambda C}}$$
$$\frac{\partial \mathcal{L}}{\partial N^*} = -\frac{(\sigma^*)^2}{(N^*)^2} + \lambda C^* = 0 \implies N^* = \frac{\sigma^*}{\sqrt{\lambda C^*}}$$
两式相除，成功消除拉格朗日乘子 $\lambda$，得到最佳采样比率：
$$\frac{N}{N^*} = \frac{\sigma}{\sigma^*} \sqrt{\frac{C^*}{C}} \quad \implies \quad \frac{N^*}{N} = \frac{\sigma^*}{\sigma} \sqrt{\frac{C}{C^*}}$$

#### 🤖 在 AI / 机器学习中的深度应用

##### 1. 强化学习（Reinforcement Learning）中的 MC 策略评估
在 Model-free 强化学习中，策略评估通过 Monte Carlo 方法沿轨迹采样状态-动作对，利用累计折扣回报的样本均值作为状态价值函数 $V^\pi(s)$ 的无偏估计。

##### 2. 扩散模型（Diffusion Models）中的轨迹采样
生成扩散模型（DDPM / SDE）在前向与反向随机微分方程求解中，通过蒙特卡罗轨迹采样估计得分函数（Score Function）与高维概率流，实现高质量图像生成。

##### 3. 马尔可夫链蒙特卡罗（MCMC）与贝叶斯神经网络（BNN）
在贝叶斯深度学习中，神经网络权重 $\boldsymbol{w}$ 的后验分布 $p(\boldsymbol{w}|\mathcal{D})$ 难以闭式求解。MCMC（如 Stochastic Gradient HMC）通过在权重空间采样，利用蒙特卡罗均值估计预测分布 $p(y|\boldsymbol{x}, \mathcal{D}) \approx \frac{1}{S}\sum_{s=1}^S p(y|\boldsymbol{x}, \boldsymbol{w}^{(s)})$。

## 2. 12.2 协方差矩阵与联合概率 (Covariance Matrix and Joint Probability)

### 2.1 联合概率分布与协方差的严格定义

当观察从单一变量扩展至 $M$ 个变量（如同时测量儿童的年龄 $a$、身高 $h$、体重 $w$，$M=3$）时，随机变量表示为向量 $\boldsymbol{X} = [X_1, X_2, \dots, X_M]^T$，其均值为向量 $\boldsymbol{m} = E[\boldsymbol{X}] = [m_1, m_2, \dots, m_M]^T$。

#### 联合概率与边际概率

* **联合概率（Joint Probability） $p_{ij}$**：试验 1 获得离散值 $x_i$ 且试验 2 获得离散值 $y_j$ 的概率。满足全局概率归一化约束：
  $$\sum_i \sum_j p_{ij} = 1 $$
* **边际概率（Marginal Probability）**：联合概率矩阵 $P$ 的行和与列和：
  * 行和（试验 1 得到 $x_i$ 的边际概率）：$p_i = \sum_{j=1}^n p_{ij} $
  * 列和（试验 2 得到 $y_j$ 的边际概率）：$P_j = \sum_{i=1}^m p_{ij}$

#### 协方差 $\sigma_{12}$（或 $\sigma_{xy}$）的严格定义

衡量两变量间线性关联方向与精度的统计量定义为：
$$\sigma_{12} = E[(x - m_1)(y - m_2)] = \sum_i \sum_j p_{ij} (x_i - m_1)(y_j - m_2) $$

#### 变量独立（Uncorrelated）推导 $\sigma_{12} = 0$

若试验 1 与试验 2 相互独立，则联合概率严格等于边际概率之积：$p_{ij} = p_i P_j$。
将此条件代入协方差定义式中：
$$\begin{aligned}
\sigma_{12} &= \sum_i \sum_j (p_i P_j) (x_i - m_1)(y_j - m_2) \\
&= \left[ \sum_i p_i (x_i - m_1) \right] \cdot \left[ \sum_j P_j (y_j - m_2) \right]
\end{aligned}$$
由边际均值定义 $\sum_i p_i x_i = m_1$ 且 $\sum_i p_i = 1$，展开第一项得 $\sum_i p_i x_i - m_1 \sum_i p_i = m_1 - m_1 = 0$。同理第二项亦为 $0$。因此：
$$\sigma_{12} = [0] \cdot [0] = 0 $$
**结论：两独立随机变量的协方差必定为零。**

#### 经典例题对比

* **例 1（独立投掷两枚硬币）**：
  两硬币完全独立，四种结果 $(1,1), (1,0), (0,1), (0,0)$ 的概率均等于 $1/4$。
  联合概率矩阵为 $P = \begin{bmatrix} 1/4 & 1/4 \\ 1/4 & 1/4 \end{bmatrix}$。边际概率为 $p_1=1/2, p_2=1/2; P_1=1/2, P_2=1/2$。
  代入计算得协方差 $\sigma_{12} = 0$，其协方差矩阵为对角矩阵 $V = \begin{bmatrix} \sigma_1^2 & 0 \\ 0 & \sigma_2^2 \end{bmatrix} = \begin{bmatrix} 1/4 & 0 \\ 0 & 1/4 \end{bmatrix}$。

* **例 2（粘合硬币 / 完全相关）**：
  两硬币粘合在一起，朝向严格一致。可能结果仅为 $(1,1)$ 与 $(0,0)$，概率各为 $1/2$；错配结果 $(1,0)$ 与 $(0,1)$ 的概率为 $0$。
  联合概率矩阵为 $P = \begin{bmatrix} 1/2 & 0 \\ 0 & 1/2 \end{bmatrix}$。均值 $m_1 = 1/2, m_2 = 1/2$。
  代入协方差定义式计算：
  $$\begin{aligned}
  \sigma_{12} &= \frac{1}{2}\left(1 - \frac{1}{2}\right)\left(1 - \frac{1}{2}\right) + 0 + 0 + \frac{1}{2}\left(0 - \frac{1}{2}\right)\left(0 - \frac{1}{2}\right) \\
  &= \frac{1}{8} + \frac{1}{8} = \frac{1}{4}
  \end{aligned}$$
  此时协方差达到了理论极值 $\sigma_{12} = \sigma_1 \sigma_2 = 1/4$。协方差矩阵为 $V = \begin{bmatrix} 1/4 & 1/4 \\ 1/4 & 1/4 \end{bmatrix}$，行列式 $\det(V) = 0$，矩阵退化为奇异矩阵。

#### 🤖 在 AI / 机器学习中的深度应用

##### 1. 贝叶斯网络（Bayesian Networks）中的条件独立性
在概率图模型中，通过联合概率分布的因子化分解 $p(x_1, \dots, x_M) = \prod p(x_i | \text{Parents}(x_i))$，利用变量间的条件独立性将极高维度的联合概率矩阵大幅稀疏化。

##### 2. 自回归语言模型（GPT 系列）的链式概率分解
大语言模型基于概率乘法链式法则，将文本序列 $(w_1, w_2, \dots, w_T)$ 的联合概率转换为边际条件概率的连乘：
$$P(w_1, w_2, \dots, w_T) = \prod_{t=1}^T P(w_t | w_1, w_2, \dots, w_{t-1})$$
这种分解将高维联合概率预测简化为单步 Next-token 预测问题。

### 2.2 协方差矩阵 $V$ 的构造及其代数性质

对于包含 $M$ 个分量的随机向量 $\boldsymbol{X} = [X_1, X_2, \dots, X_M]^T$，其期望向量为 $\bar{\boldsymbol{X}} = E[\boldsymbol{X}]$。

#### 总体与样本协方差矩阵的形式

* **总体协方差矩阵 $V$**：维度为 $M \times M$，定义为偏移列向量与行向量外积的期望：
  $$V = E[(\boldsymbol{X} - \bar{\boldsymbol{X}})(\boldsymbol{X} - \bar{\boldsymbol{X}})^T] = \sum p_{ij\dots} \boldsymbol{U} \boldsymbol{U}^T $$
  其中偏移向量 $\boldsymbol{U} = \boldsymbol{X} - \bar{\boldsymbol{X}}$。对于连续型分布，$V = \iiint p(x, y, z) \boldsymbol{U} \boldsymbol{U}^T dx dy dz$。
* **样本协方差矩阵 $S$**：基于 $N$ 个观测样本向量 $\boldsymbol{X}_1, \dots, \boldsymbol{X}_N$ 计算：
  $$S = \frac{1}{N-1} \sum_{k=1}^N (\boldsymbol{X}_k - \bar{\boldsymbol{X}})(\boldsymbol{X}_k - \bar{\boldsymbol{X}})^T $$

#### 协方差矩阵正半定性（Positive Semidefiniteness）严格证明

##### 视角 1：能量测试法（Energy Test / 二次型视角）
设 $\boldsymbol{c} = [c_1, c_2, \dots, c_M]^T$ 为任意给定的非零常数向量。利用 $\boldsymbol{c}^T \boldsymbol{X}$ 构造一个标量随机变量，计算该标量随机变量的方差：
$$\begin{aligned}
\text{Var}(\boldsymbol{c}^T \boldsymbol{X}) &= E\left[ (\boldsymbol{c}^T \boldsymbol{X} - \boldsymbol{c}^T \bar{\boldsymbol{X}})(\boldsymbol{c}^T \boldsymbol{X} - \boldsymbol{c}^T \bar{\boldsymbol{X}})^T \right] \\
&= E\left[ \boldsymbol{c}^T (\boldsymbol{X} - \bar{\boldsymbol{X}})(\boldsymbol{X} - \bar{\boldsymbol{X}})^T \boldsymbol{c} \right] \\
&= \boldsymbol{c}^T E\left[ (\boldsymbol{X} - \bar{\boldsymbol{X}})(\boldsymbol{X} - \bar{\boldsymbol{X}})^T \right] \boldsymbol{c} = \boldsymbol{c}^T V \boldsymbol{c}
\end{aligned} $$
由于任何实随机变量的方差恒满足非负性（$\text{Var}(\boldsymbol{c}^T \boldsymbol{X}) \ge 0$），故对于任意非零向量 $\boldsymbol{c}$，二次型恒有：
$$\boldsymbol{c}^T V \boldsymbol{c} \ge 0$$
根据实对称矩阵的能量测试判定法则，**总体协方差矩阵 $V$ 与样本协方差矩阵 $S$ 必为实对称正半定矩阵（$V \ge 0$）**。

##### 视角 2：外积求和法（Sum of Outer Products / 几何结构视角）
展开协方差矩阵为各个离散状态外积矩阵的加权求和：
$$V = \sum_{i, j} p_{ij} \boldsymbol{U} \boldsymbol{U}^T $$
对于每一个具体的输出状态，显式外积矩阵 $\boldsymbol{U} \boldsymbol{U}^T$ 为：
$$\boldsymbol{U} \boldsymbol{U}^T = \begin{bmatrix} x_i - m_1 \\ y_j - m_2 \end{bmatrix} \begin{bmatrix} x_i - m_1 & y_j - m_2 \end{bmatrix} = \begin{bmatrix} (x_i - m_1)^2 & (x_i - m_1)(y_j - m_2) \\ (x_i - m_1)(y_j - m_2) & (y_j - m_2)^2 \end{bmatrix} $$
观察该 $2 \times 2$ 矩阵，其行列式 $\det(\boldsymbol{U} \boldsymbol{U}^T) = (x_i - m_1)^2 (y_j - m_2)^2 - [(x_i - m_1)(y_j - m_2)]^2 = 0$，且迹（Trace）为 $(x_i - m_1)^2 + (y_j - m_2)^2 \ge 0$。这证明每个外积项 $\boldsymbol{U} \boldsymbol{U}^T$ 都是秩为 $1$ 的对称正半定矩阵。因为概率权重 $p_{ij} \ge 0$，正半定矩阵的非负线性组合必定依然是正半定矩阵。

#### 性质与边界约束

* **对角线与非对角线**：$V_{ii} = \sigma_i^2$ 为各自变量的方差；$V_{ij} = \sigma_{ij}$ 为变量间的协方差。
* **柯西-施瓦茨约束（Cauchy-Schwarz Inequality）**：
  $$\sigma_{ij}^2 \le \sigma_i^2 \sigma_j^2 \quad \implies \quad -\sigma_i \sigma_j \le \sigma_{ij} \le \sigma_i \sigma_j$$
* **退化/奇异状态**：当且仅当两变量间存在确定性线性关系时（如粘合硬币），$\sigma_{12}^2 = \sigma_1^2 \sigma_2^2$，此时 $\det(V) = 0$，$V$ 退化为秩亏的奇异正半定矩阵。

#### 实对称矩阵对角化、谱分解与解耦的几何意义

依据实对称矩阵谱定理，正半定协方差矩阵 $V$ 可以进行正交对角化：
$$V = Q \Lambda Q^T $$
其中 $Q = [\boldsymbol{q}_1, \boldsymbol{q}_2, \dots, \boldsymbol{q}_M]$ 为正交矩阵，列向量 $\boldsymbol{q}_i$ 为相互正交的单位特征向量；$\Lambda = \text{diag}(\lambda_1, \lambda_2, \dots, \lambda_M)$ 为非负特征值对角矩阵（$\lambda_i \ge 0$）。

##### 解耦（Decoupling）的几何含义：
特征向量矩阵 $Q$ 构造了一个新的旋转坐标系。将原始相关变量向量 $\boldsymbol{X}$ 投影到该坐标系下：$\boldsymbol{Y} = Q^T \boldsymbol{X}$。
计算新变量 $\boldsymbol{Y}$ 的协方差矩阵：
$$V_{\boldsymbol{Y}} = E[(\boldsymbol{Y} - \bar{\boldsymbol{Y}})(\boldsymbol{Y} - \bar{\boldsymbol{Y}})^T] = E[Q^T(\boldsymbol{X} - \bar{\boldsymbol{X}})(\boldsymbol{X} - \bar{\boldsymbol{X}})^T Q] = Q^T V Q = \Lambda$$
因为 $\Lambda$ 是对角矩阵，非对角线上的协方差全部化为 $0$。这在几何上表明：**谱分解通过旋转空间坐标轴，将原始相互关联的特征组合，彻底解耦（Decouple）为一组彼此完全无相关（Uncorrelated）的主方向**。

```
原始特征空间 (存在非对角协方差 σ_ij) ──(正交矩阵 Q 旋转)──> 特征主轴空间 (对角协方差矩阵 Λ, 彻底解耦)
```

#### 🤖 在 AI / 机器学习中的深度应用

##### 1. 主成分分析（PCA）与数据白化（Whitening）
* **PCA 降维**：对数据样本协方差矩阵 $S$ 做谱分解 $S = Q \Lambda Q^T$。特征向量 $\boldsymbol{q}_i$ 指示了数据方差最大的主成分方向，特征值 $\lambda_i$ 代表数据在该方向上的方差大小。按特征值从大到小保留前 $k$ 个特征向量，即实现了最小信息损失下的线性降维。
* **PCA 白化（Whitening）**：构造变换矩阵 $W = \Lambda^{-1/2} Q^T$。对原始数据施加变换 $\boldsymbol{X}_{\text{white}} = W (\boldsymbol{X} - \bar{\boldsymbol{X}})$，可使变换后的数据协方差矩阵严格等于单位矩阵 $\boldsymbol{I}$，彻底消除特征间相关性并归一化方差。

##### 2. 多元高斯分布与马氏距离（Mahalanobis Distance）
$M$ 维多元高斯分布的概率密度函数为：
$$p(\boldsymbol{X}) = \frac{1}{(2\pi)^{M/2} \det(V)^{1/2}} \exp\left( -\frac{1}{2} (\boldsymbol{X} - \boldsymbol{\mu})^T V^{-1} (\boldsymbol{X} - \boldsymbol{\mu}) \right)$$
指数项中的二次型 $(\boldsymbol{X} - \boldsymbol{\mu})^T V^{-1} (\boldsymbol{X} - \boldsymbol{\mu})$ 即为**马氏距离的平方**。马氏距离通过协方差矩阵 $V^{-1}$ 进行变形校正，自动排除了特征间量纲不同与线性相关性的干扰，精确度量高维空间中点到中心分布的真实统计距离。

### 2.3 随机变量线性组合与和的统计量

#### 期望的线性性

不论随机变量 $x$ 与 $y$ 是否独立，两变量线性组合 $z = x + y$ 的期望值始终满足线性加法法则：
$$m_z = E[x + y] = E[x] + E[y] = m_x + m_y $$

#### 和的方差推导

推导 $z = x + y$ 的总体方差 $\sigma_z^2$：
$$\begin{aligned}
\sigma_z^2 &= E\left[ \left( (x+y) - (m_x+m_y) \right)^2 \right] \\
&= E\left[ \left( (x-m_x) + (y-m_y) \right)^2 \right] \\
&= E\left[ (x-m_x)^2 + (y-m_y)^2 + 2(x-m_x)(y-m_y) \right] \\
&= E[(x-m_x)^2] + E[(y-m_y)^2] + 2 E[(x-m_x)(y-m_y)] \\
&= \sigma_x^2 + \sigma_y^2 + 2\sigma_{xy}
\end{aligned}$$
当且仅当 $x$ 与 $y$ 无关（协方差 $\sigma_{xy} = 0$）时，和的方差等于各自方差之和：$\sigma_{x+y}^2 = \sigma_x^2 + \sigma_y^2$。

#### 🤖 在 AI / 机器学习中的深度应用

##### 残差连接（ResNet）中的方差累积与恒等映射缩放
在超深层残差网络中，残差块表示为 $\boldsymbol{x}_{l+1} = \boldsymbol{x}_l + f(\boldsymbol{x}_l)$。假设输入 $\boldsymbol{x}_l$ 与残差分支 $f(\boldsymbol{x}_l)$ 无关，且方差分别为 $\text{Var}(\boldsymbol{x}_l)$ 与 $\text{Var}(f(\boldsymbol{x}_l))$。
根据加法方差公式：
$$\text{Var}(\boldsymbol{x}_{l+1}) = \text{Var}(\boldsymbol{x}_l) + \text{Var}(f(\boldsymbol{x}_l))$$
随着网络层数 $L$ 的增加，激活值的方差会沿深度呈线性累加（$\text{Var}(\boldsymbol{x}_L) \approx \text{Var}(\boldsymbol{x}_0) + \sum \text{Var}(f)$），导致深层激活值方差爆炸。为了稳定极深网络的梯度，Modern Transformer 与 ResNet 变体引入了 LayerNorm 或缩放因子（如 Fixup 初始化中对残差分支乘以 $1/\sqrt{L}$），精确控制方差累积。

### 3.1 多元正态分布（Multivariate Normal Distribution）

#### 多元高斯分布的概率密度函数 (PDF) 与严格定义

在机器学习与高维统计建模中，一维正态分布必须推广至高维向量空间。设 $n$ 维连续随机向量 $x = [x_1, x_2, \dots, x_n]^T \in \mathbb{R}^n$，若其服从均值向量为 $\mu \in \mathbb{R}^n$、协方差矩阵为 $\Sigma \in \mathbb{R}^{n \times n}$（假设 $\Sigma$ 为正定矩阵）的多元正态分布（Multivariate Normal Distribution），记作 $x \sim \mathcal{N}(\mu, \Sigma)$。

其联合概率密度函数（Probability Density Function, PDF）的严格数学定义为：

$$p(x) = (2\pi)^{-n/2}|\Sigma|^{-1/2}\exp\!\left(-\frac{1}{2} (x-\mu)^T\Sigma^{-1}(x-\mu)\right)$$

其中 $|\Sigma|$ 表示协方差矩阵 $\Sigma$ 的行列式，$\Sigma^{-1}$ 为其逆矩阵。

```
           [各维度方差与相关性矫正]
                      │
                      ▼
p(x) = (2π)^(-n/2) |Σ|^(-1/2) exp( -1/2 (x - μ)^T Σ^(-1) (x - μ) )
       └─────────┬──────────┘        └──────────────┬──────────────┘
           高维空间体积标准化因子                   马氏距离二次型因子
```

##### 概率密度函数因子的物理与几何意义拆解：

1. **马氏距离二次型因子 $(x-\mu)^T\Sigma^{-1}(x-\mu)$**：
   在各维度相互独立且方差均为 1 的标准正态分布中，点 $x$ 偏离中心 $\mu$ 的度量使用欧氏距离平方 $\|x-\mu\|^2 = (x-\mu)^T(x-\mu)$。然而，在实际数据中，不同特征维度往往存在不同的方差（量纲不一致）以及非零的相关性（几何上的倾斜）。欧氏距离忽视了这种空间形变。

   马氏距离（Mahalanobis Distance）加权矩阵 $\Sigma^{-1}$ 充当了几何缩放与消除相关性的算子。通过将数据投影到由协方差矩阵特征向量构成的坐标轴上，并除以各轴的特征值（方差），马氏距离准确地评估了点 $x$ 相对于概率分布中心的统计偏离程度。

2. **指数衰减项 $\exp\!\left(-\frac{1}{2}(x-\mu)^T\Sigma^{-1}(x-\mu)\right)$**：
   决定了概率密度在空间中的衰减机制。马氏距离平方增加时，概率密度呈指数级衰减。这使得高斯分布的等密度面（Contour Surfaces）在 $n$ 维空间中形成一系列以 $\mu$ 为中心的同心超椭球面。

3. **归一化系数 $(2\pi)^{-n/2}|\Sigma|^{-1/2}$**：
   充当全空间体积的标准化因子。根据线性代数，协方差矩阵 $\Sigma$ 作为一个线性算子，将单位正方体/单位球体拉伸变形为高维平行多面体/超椭球体。其行列式 $|\Sigma|$ 代表该线性变换的**体积伸缩倍率**（Volume Scaling Factor）。

   在未归一化的指数核积分中，随着协方差矩阵 $\Sigma$ 的扩大（数据弥散度变大），超椭球体的体积以 $|\Sigma|^{1/2}$ 的比例线性扩张。为了满足概率论第一公理（全空间累积概率积分严格等于 1），必须在密度函数前乘以体积缩放因子的倒数 $|\Sigma|^{-1/2}$，结合 $n$ 个独立维度产生的 $(2\pi)^{-n/2}$ 因子，完成高维空间的概率密度归一化。

##### 🤖 在 AI / ML 中的对应应用：
- **变分自编码器（VAE）**：在隐空间（Latent Space）假设隐变量服从多元高斯先验 $q_\phi(z|x) \sim \mathcal{N}(\mu(x), \Sigma(x))$，并通过重参数化技巧（Reparameterization Trick）采样。
- **高斯混合模型（GMM）**：利用多个多元高斯分布的加权线性组合表达复杂的非凸多峰概率密度。
- **高斯朴素贝叶斯（Gaussian Naive Bayes）**：假设在给定类别下，连续特征向量服从协方差矩阵为对角阵（维度间条件独立）的多元高斯分布。

---

#### 归一化积分为 1 的数学推导

为了严格证明多元正态分布的密度函数在全空间 $\mathbb{R}^n$ 上的积分为 1，即：

$$I = \int_{\mathbb{R}^n} (2\pi)^{-n/2}|\Sigma|^{-1/2}\exp\!\left(-\frac{1}{2} (x-\mu)^T\Sigma^{-1}(x-\mu)\right) dx = 1$$

可利用正定矩阵的方根分解与多元微积分的雅可比（Jacobian）变量替换定理进行推导。

##### 严格推导步骤：

1. **变量替换（白化坐标变换）**：
   因为 $\Sigma$ 为实对称正定矩阵，其逆平方根矩阵 $\Sigma^{-1/2}$ 存在且亦为对称正定矩阵，满足 $\Sigma^{-1} = \Sigma^{-1/2} \Sigma^{-1/2}$。
   令新变量向量为：

   $$z = \Sigma^{-1/2}(x - \mu)$$

   反解得 $x = \Sigma^{1/2}z + \mu$。

2. **雅可比矩阵（Jacobian Matrix）与微元变换**：
   计算变换的雅可比变换矩阵 $J$：

   $$J = \frac{\partial x}{\partial z} = \Sigma^{1/2}$$

   雅可比行列式为 $|J| = \det(\Sigma^{1/2}) = |\Sigma|^{1/2}$。根据多元重积分的换元法则，体积微元满足：

   $$dx = |J| \, dz = |\Sigma|^{1/2} dz$$

3. **二次型与归一化因子的抵消**：
   将二次型代入变换表达式：

   $$(x-\mu)^T \Sigma^{-1} (x-\mu) = (\Sigma^{1/2}z)^T \Sigma^{-1} (\Sigma^{1/2}z) = z^T \Sigma^{1/2} \Sigma^{-1} \Sigma^{1/2} z = z^T z = \sum_{i=1}^n z_i^2$$

   将微元 $dx = |\Sigma|^{1/2} dz$ 代入原积分：

   $$I = \int_{\mathbb{R}^n} (2\pi)^{-n/2} |\Sigma|^{-1/2} \exp\left(-\frac{1}{2} z^T z\right) |\Sigma|^{1/2} dz$$

   注意到消因子项 $|\Sigma|^{-1/2} |\Sigma|^{1/2} = 1$，行列式成功解耦：

   $$I = (2\pi)^{-n/2} \int_{\mathbb{R}^n} \exp\left(-\frac{1}{2} \sum_{i=1}^n z_i^2\right) dz$$

4. **利用富比尼（Fubini）定理进行维度解耦**：
   指数项与积分微元可拆解为 $n$ 个独立的一维无界积分之积：

   $$I = (2\pi)^{-n/2} \prod_{i=1}^n \left( \int_{-\infty}^{\infty} e^{-z_i^2/2} dz_i \right)$$

   根据经典一维标准高斯积分公式（可由极坐标变换求出）$\int_{-\infty}^{\infty} e^{-z_i^2/2} dz_i = \sqrt{2\pi}$，代入上式得：

   $$I = (2\pi)^{-n/2} \cdot (\sqrt{2\pi})^n = (2\pi)^{-n/2} \cdot (2\pi)^{n/2} = 1$$

证毕。

##### 🤖 在 AI / ML 中的对应应用：
归一化系数的精确性保证了基于连续概率 distributions 似然函数（Likelihood）计算的自洽性。在流模型（Normalizing Flows）与扩散模型（Diffusion Models）中，概率密度的归一化使得优化对数似然上限（Log-Likelihood Bound）与采样过程（Sampling）具备严密的统计学收敛保证。

### 3.2 协方差矩阵 $\Sigma$ 的几何与代数特性

#### 协方差矩阵的基础性质

对于连续随机向量 $x = [x_1, \dots, x_n]^T \in \mathbb{R}^n$，其协方差矩阵定义为期望外积：

$$\Sigma = \mathbb{E}[(x - \mu)(x - \mu)^T] \in \mathbb{R}^{n \times n}$$

##### 代数性质：

1. **对称性（Symmetry）**：
   $\Sigma^T = \mathbb{E}\left[((x-\mu)(x-\mu)^T)^T\right] = \mathbb{E}[(x-\mu)(x-\mu)^T] = \Sigma$。
2. **半正定性（Positive Semi-Definiteness, PSD）**：
   对任意非零常数向量 $v \in \mathbb{R}^n$，标量随机变量 $v^T(x-\mu)$ 的方差为：

   $$v^T \Sigma v = v^T \mathbb{E}[(x-\mu)(x-\mu)^T] v = \mathbb{E}\left[ v^T(x-\mu)(x-\mu)^T v \right] = \mathbb{E}\left[ (v^T(x-\mu))^2 \right] \ge 0$$

   若变量间不存在完全线性依赖，则 $\mathbb{E}[(v^T(x-\mu))^2] > 0$，此时 $\Sigma$ 为正定矩阵（Positive Definite, PD），所有特征值均严格大于 0。

##### 物理与几何含义：
- **对角线元素 $\sigma_{ii} = \Sigma_{ii} = \text{Var}(x_i)$**：表示特征维度 $x_i$ 的边际方差，度量了该维度的偏离离散程度。
- **非对角线元素 $\sigma_{ij} = \Sigma_{ij} = \text{Cov}(x_i, x_j)$**：表示维度 $x_i$ 与 $x_j$ 的协同变化程度（协方差）。非零项暗示旋转坐标轴下特征间的线性相关关系。

##### 🤖 在 AI / ML 中的对应应用：
数据预处理与特征工程中，协方差矩阵（或归一化的 Pearson 相关系数矩阵）用于评估高维特征的冗余性。在线性判别分析（LDA）与多元相关分析中，协方差矩阵是构建类间/类内散度矩阵的代数基础。

---

#### 谱分解 $\Sigma = Q\Lambda Q^T$ 与 2D 高斯等高线几何

基于实对称矩阵的正交对角化定理（谱定理），正定协方差矩阵 $\Sigma$ 可分解为：

$$\Sigma = Q \Lambda Q^T = \sum_{i=1}^n \lambda_i q_i q_i^T$$

其中 $Q = [q_1, q_2, \dots, q_n]$ 为由单位正交特征向量构成的正交矩阵（满足 $Q^T Q = Q Q^T = I$），$\Lambda = \text{diag}(\lambda_1, \lambda_2, \dots, \lambda_n)$ 为由正特征值排列成的对角矩阵（$\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_n > 0$）。

其逆矩阵为 $\Sigma^{-1} = Q \Lambda^{-1} Q^T = \sum_{i=1}^n \frac{1}{\lambda_i} q_i q_i^T$。

##### 二维高斯几何剖析：

在 2D 平面（$n=2$）上，正态分布的等密度面由马氏距离平方等于常数 $c^2$ 的点集定义：

$$(x-\mu)^T \Sigma^{-1} (x-\mu) = c^2$$

将 $\Sigma^{-1} = Q \Lambda^{-1} Q^T$ 代入等高线方程：

$$(x-\mu)^T Q \Lambda^{-1} Q^T (x-\mu) = c^2$$

定义旋转坐标系下的新坐标向量 $y = [y_1, y_2]^T = Q^T(x-\mu)$。注意到正交矩阵 $Q^T$ 实现了坐标轴的正交旋转。代入对角展开：

$$[y_1, y_2] \begin{bmatrix} 1/\lambda_1 & 0 \\ 0 & 1/\lambda_2 \end{bmatrix} \begin{bmatrix} y_1 \\ y_2 \end{bmatrix} = c^2 \implies \frac{y_1^2}{\lambda_1} + \frac{y_2^2}{\lambda_2} = c^2$$

两侧同除以 $c^2$，整理为标准解析几何方程：

$$\frac{y_1^2}{(c\sqrt{\lambda_1})^2} + \frac{y_2^2}{(c\sqrt{\lambda_2})^2} = 1$$

这严格证明了二维高斯分布的等高线在平面上构成一个**椭圆**。

```
                    y_2 (特征向量 q_2 方向)
                       ^
                       |     , - ~ ~ - ,
                       |  '               '
                       | /                 \
                       | |  <--c√λ_2-->    |
    -------------------|-------------------|------------------> y_1 (特征向量 q_1 方向)
                       | |                 |
                       | \                 /
                       |  .               .
                       |    ' - _ _ _ - '
                       |     <--- c√λ_1 --->
```

##### 椭圆的几何要素：
1. **主轴方向**：椭圆的长轴与短轴方向分别沿着协方差矩阵的特征向量 $q_1$ 与 $q_2$ 的方向。
2. **主轴半轴长度**：主轴半轴的几何长度正比于特征值开平方，分别等于 $c\sqrt{\lambda_1}$ 与 $c\sqrt{\lambda_2}$。

##### 🤖 在 AI / ML 中的对应应用：
主成分分析（PCA）直接对数据的样本协方差矩阵进行特征值分解，第一个主成分（PC1）即对应最大特征值 $\lambda_1$ 的特征向量 $q_1$，即椭圆最长轴方向，代表了数据方差最大的投影方向。

---

#### 白化变换（Whitening Transform）$\Sigma^{-1/2}$

白化变换（Whitening/Sphering Transform）的代数目标是将线性相关的离散特征向量映射为均值为零、各维度不相关且方差严格为 1 的标准正态状态。

基于谱分解 $\Sigma = Q \Lambda Q^T$，严格定义协方差矩阵的平方根与逆平方根：

$$\Sigma^{1/2} = Q \Lambda^{1/2} Q^T, \quad \text{其中 } \Lambda^{1/2} = \text{diag}(\sqrt{\lambda_1}, \dots, \sqrt{\lambda_n})$$

$$\Sigma^{-1/2} = Q \Lambda^{-1/2} Q^T, \quad \text{其中 } \Lambda^{-1/2} = \text{diag}\left(\frac{1}{\sqrt{\lambda_1}}, \dots, \frac{1}{\sqrt{\lambda_n}}\right)$$

容易验证：$\Sigma^{-1/2}\Sigma^{-1/2} = Q \Lambda^{-1/2} Q^T Q \Lambda^{-1/2} Q^T = Q \Lambda^{-1} Q^T = \Sigma^{-1}$。

##### 白化变换定义：
对随机向量 $x \sim \mathcal{N}(\mu, \Sigma)$，定义白化变换向量 $z$：

$$z = \Sigma^{-1/2}(x - \mu)$$

##### 严密代数推导（证明 $\text{Cov}(z) = I$）：

1. **均值推导**：
   $$\mathbb{E}[z] = \mathbb{E}[\Sigma^{-1/2}(x - \mu)] = \Sigma^{-1/2}(\mathbb{E}[x] - \mu) = \Sigma^{-1/2}(\mu - \mu) = 0$$

2. **协方差矩阵推导**：
   $$\text{Cov}(z) = \mathbb{E}[(z - \mathbb{E}[z])(z - \mathbb{E}[z])^T] = \mathbb{E}[z z^T]$$

   代入 $z = \Sigma^{-1/2}(x - \mu)$：

   $$\text{Cov}(z) = \mathbb{E}\left[ \left(\Sigma^{-1/2}(x - \mu)\right) \left(\Sigma^{-1/2}(x - \mu)\right)^T \right]$$

   利用矩阵转置法则 $(AB)^T = B^T A^T$ 以及 $\Sigma^{-1/2}$ 的对称性 $(\Sigma^{-1/2})^T = \Sigma^{-1/2}$：

   $$\text{Cov}(z) = \mathbb{E}\left[ \Sigma^{-1/2}(x - \mu)(x - \mu)^T \Sigma^{-1/2} \right]$$

   由于线性算子 $\Sigma^{-1/2}$ 为常数矩阵，可移出期望符号：

   $$\text{Cov}(z) = \Sigma^{-1/2} \mathbb{E}\left[(x - \mu)(x - \mu)^T\right] \Sigma^{-1/2} = \Sigma^{-1/2} \Sigma \Sigma^{-1/2}$$

   代入 $\Sigma = \Sigma^{1/2} \Sigma^{1/2}$：

   $$\text{Cov}(z) = \Sigma^{-1/2} \left(\Sigma^{1/2} \Sigma^{1/2}\right) \Sigma^{-1/2} = \left(\Sigma^{-1/2} \Sigma^{1/2}\right) \left(\Sigma^{1/2} \Sigma^{-1/2}\right) = I \cdot I = I$$

证明完毕。变换后的随机向量 $z \sim \mathcal{N}(0, I)$ 表现为各向同性的标准球形高斯分布。

##### 🤖 在 AI / ML 中的对应应用：
- **PCA 白化与 ZCA 白化**：图像处理中去除相邻像素强相关性，PCA 白化为 $z_{PCA} = \Lambda^{-1/2} Q^T (x-\mu)$，ZCA 白化为 $z_{ZCA} = Q \Lambda^{-1/2} Q^T (x-\mu) = \Sigma^{-1/2}(x-\mu)$（保持图像空间结构）。
- **深度学习归一化**：批归一化（Batch Normalization）与层归一化（Layer Normalization）内部去相关与方差标准化思想的起源。

#### 具体计算示例：2×2 协方差矩阵的几何与白化

给定二维高斯分布的均值向量 $\mu = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$，协方差矩阵为：

$$\Sigma = \begin{bmatrix} 3 & 1 \\ 1 & 3 \end{bmatrix}$$

##### 1. 特征值与特征向量计算：
求解特征方程 $\det(\Sigma - \lambda I) = 0$：

$$\det \begin{bmatrix} 3-\lambda & 1 \\ 1 & 3-\lambda \end{bmatrix} = (3-\lambda)^2 - 1 = \lambda^2 - 6\lambda + 8 = 0$$

解得特征值：

$$\lambda_1 = 4, \quad \lambda_2 = 2$$

求解对应正交单位特征向量 $q_1, q_2$：
- 对于 $\lambda_1 = 4$：$(\Sigma - 4I)v = 0 \implies \begin{bmatrix} -1 & 1 \\ 1 & -1 \end{bmatrix} \begin{bmatrix} v_{11} \\ v_{12} \end{bmatrix} = 0 \implies v_{11} = v_{12}$。单位化得：
  $$q_1 = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ 1 \end{bmatrix}$$
- 对于 $\lambda_2 = 2$：$(\Sigma - 2I)v = 0 \implies \begin{bmatrix} 1 & 1 \\ 1 & 1 \end{bmatrix} \begin{bmatrix} v_{21} \\ v_{22} \end{bmatrix} = 0 \implies v_{21} = -v_{22}$。单位化得：
  $$q_2 = \frac{1}{\sqrt{2}} \begin{bmatrix} -1 \\ 1 \end{bmatrix}$$

##### 2. 椭圆等高线几何特性：
等高线椭圆的主轴方向沿着 $q_1 = \begin{bmatrix} 1/\sqrt{2} \\ 1/\sqrt{2} \end{bmatrix}$（$y=x$ 轴方向）与 $q_2 = \begin{bmatrix} -1/\sqrt{2} \\ 1/\sqrt{2} \end{bmatrix}$（$y=-x$ 轴方向）。

长短半轴长度之比等于特征值平方根之比：

$$\text{半轴比例} = \frac{\sqrt{\lambda_1}}{\sqrt{\lambda_2}} = \frac{\sqrt{4}}{\sqrt{2}} = \sqrt{2} \approx 1.414$$

##### 3. 显式计算白化矩阵 $\Sigma^{-1/2}$：
构造正交矩阵 $Q$ 与对角阵 $\Lambda^{-1/2}$：

$$Q = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 & -1 \\ 1 & 1 \end{bmatrix}, \quad \Lambda^{-1/2} = \begin{bmatrix} 1/\sqrt{\lambda_1} & 0 \\ 0 & 1/\sqrt{\lambda_2} \end{bmatrix} = \begin{bmatrix} 1/2 & 0 \\ 0 & 1/\sqrt{2} \end{bmatrix}$$

计算 $\Sigma^{-1/2} = Q \Lambda^{-1/2} Q^T$：

$$\Sigma^{-1/2} = \left( \frac{1}{\sqrt{2}} \begin{bmatrix} 1 & -1 \\ 1 & 1 \end{bmatrix} \right) \begin{bmatrix} 1/2 & 0 \\ 0 & 1/\sqrt{2} \end{bmatrix} \left( \frac{1}{\sqrt{2}} \begin{bmatrix} 1 & 1 \\ -1 & 1 \end{bmatrix} \right)$$

$$\Sigma^{-1/2} = \frac{1}{2} \begin{bmatrix} 1/2 & -1/\sqrt{2} \\ 1/2 & 1/\sqrt{2} \end{bmatrix} \begin{bmatrix} 1 & 1 \\ -1 & 1 \end{bmatrix} = \frac{1}{2} \begin{bmatrix} \frac{1}{2} + \frac{1}{\sqrt{2}} & \frac{1}{2} - \frac{1}{\sqrt{2}} \\ \frac{1}{2} - \frac{1}{\sqrt{2}} & \frac{1}{2} + \frac{1}{\sqrt{2}} \end{bmatrix} = \frac{1}{4} \begin{bmatrix} 1 + \sqrt{2} & 1 - \sqrt{2} \\ 1 - \sqrt{2} & 1 + \sqrt{2} \end{bmatrix}$$

数值约为：

$$\Sigma^{-1/2} \approx \begin{bmatrix} 0.6035 & -0.1035 \\ -0.1035 & 0.6035 \end{bmatrix}$$

### 3.3 $\Sigma$ 的极端情形与退化分析

#### 奇异协方差矩阵（Singular $\Sigma$）与低维流形退化

当数据集维度 $n$ 极大而样本数不足，或特征维度间存在完全的线性相关（例如 $x_3 = 2x_1 - x_2$）时，协方差矩阵 $\Sigma$ 的行列式等于 0（即 $|\Sigma| = 0$），此时 $\Sigma$ 成为**奇异矩阵**（不可逆矩阵），至少存在一个特征值 $\lambda_i = 0$。

##### 概率密度函数失效剖析：
在多元高斯密度公式中：
- 归一化系数中的 $|\Sigma|^{-1/2} = \frac{1}{\sqrt{0}} \to \infty$ 发生**除零异常**。
- 马氏距离二次型项中的 $\Sigma^{-1}$ 不存在。

因此，高斯概率密度函数在原高维空间 $\mathbb{R}^n$ 上在数学上不可计算（表现为狄拉克 Dirac 冲激信号）。

##### 几何物理含义：
这种情况被称为**退化高斯分布**（Degenerate Gaussian Distribution）。概率质量在 $n$ 维空间中完全塌缩，100% 集中于维度小于 $n$ 的低维超平面或线性流形上。在低维超平面外部，概率密度处处严格为 0。

```
3D 空间中的概率分布塌缩：
  z ^                      .  :  *  .
    |                  .  *  #  *  .    <-- 概率密度全部集中在
    |                .  *  #  *  .          低维二维平面内
    |___________________/_______________> y
   /                  /
  /                 /  (平面外概率密度处处为 0)
 v x
```

##### 🤖 在 AI / ML 中的对应应用：
高维数据（如 $512 \times 512$ 高清图像）的原始数据空间维度高达 262,144，但真实数据分布集中在极低维的非线性超曲面上（**流形假设**, Manifold Hypothesis）。原始协方差矩阵必然极端奇异，这决定了必须通过 PCA、Autoencoder 或 VAE 对数据进行降维与隐空间表征。

---

#### 高条件数（Ill-conditioned $\Sigma$）与病态高斯

即便 $\Sigma$ 满足严格正定（所有 $\lambda_i > 0$），若其最大特征值与最小特征值相差悬殊，即协方差矩阵的**条件数**（Condition Number）极高：

$$\kappa(\Sigma) = \frac{\lambda_{\max}}{\lambda_{\min}} \gg 1$$

高斯分布将呈现严重畸变的极度扁平/细长椭球状（病态高斯, Ill-conditioned Gaussian）。

##### 数值不稳定性与优化困境：
1. **求逆敏感性**：矩阵求逆 $\Sigma^{-1}$ 会放大浮点舍入误差，导致数值计算失真。
2. **梯度下降震荡**：在病态高斯分布下计算负对数似然（NLL），其梯度在最小特征值（高曲率）方向剧烈震荡，而在最大特征值（平缓）方向推进极慢，导致一阶梯度下降算法极难收敛。

```
病态高斯等高线与梯度下降震荡：
       y ^
         |     |  /  \  /  \  /  |
         |     | /    \/    \/   |  <-- 沿短轴方向剧烈震荡
         |-----|-----------------|---> x
         |     | \    /\    /\   |
         |     |  \  /  \  /  \  |
```

##### 🤖 在 AI / ML 中的对应应用：
高斯混合模型（GMM）通过 EM 算法更新参数时，某个高斯组件可能因包含的样本过少或样本共线而导致 $\lambda_{\min} \to 0$。通常采用**协方差收缩/正则化**（Shrinkage/Regularization）技术，强制为对角线加上微小扰动常数：

$$\Sigma_{reg} = \Sigma + \epsilon I \quad (\epsilon \sim 10^{-6})$$

该操作强制提升了最小特征值 $\lambda_i \to \lambda_i + \epsilon$，将条件数控制在安全范围内，提高了数值稳定性和泛化性能。

### 3.4 加权最小二乘 (Weighted Least Squares, WLS)

#### 加权最小二乘的数学建模与问题陈述

设线性测量观测方程为：

$$b = Ax + e$$

其中：
- $b \in \mathbb{R}^m$ 为观测向量。
- $A \in \mathbb{R}^{m \times n}$ 为已知的设计矩阵/特征矩阵（假定 $m > n$ 且 $\text{rank}(A) = n$）。
- $x \in \mathbb{R}^n$ 为待估参数向量。
- $e \in \mathbb{R}^m$ 为高斯观测噪声向量，服从均值为零、协方差矩阵为已知正定矩阵 $V \in \mathbb{R}^{m \times m}$ 的多元高斯分布：$e \sim \mathcal{N}(0, V)$。

当噪声向量 $e$ 的各维度方差不相等（异方差性，Heteroscedasticity）或样本间存在观测相关性时（即 $V \neq \sigma^2 I$），经典的普通最小二乘法（OLS）推导出的参数估计不再是高斯-马尔可夫定理下的**最佳线性无偏估计**（BLUE）。必须引入高斯噪声协方差矩阵 $V$ 对优化目标进行加权矫正。

---

#### 严格数学推导：从极大似然估计 (MLE) 到 WLS 公式

观测向量 $b$ 条件服从多元正态分布：$b|x \sim \mathcal{N}(Ax, V)$。其似然函数 $L(x) = p(b|x)$ 为：

$$L(x) = (2\pi)^{-m/2} |V|^{-1/2} \exp\left( -\frac{1}{2} (b - Ax)^T V^{-1} (b - Ax) \right)$$

根据极大似然估计原理（MLE），参数 $\hat{x}$ 应使似然函数最大化，等价于极小化**负对数似然损失函数**（Negative Log-Likelihood, NLL）：

$$J(x) = -\ln L(x) = \frac{m}{2}\ln(2\pi) + \frac{1}{2}\ln|V| + \frac{1}{2} (b - Ax)^T V^{-1} (b - Ax)$$

剔除与参数 $x$ 无关的常数项，得到加权最小二乘的二次目标函数：

$$J(x) = \frac{1}{2} (b - Ax)^T V^{-1} (b - Ax)$$

##### 矩阵微分求解极小值：

展开二次型：

$$J(x) = \frac{1}{2} \left( b^T V^{-1} b - b^T V^{-1} A x - x^T A^T V^{-1} b + x^T A^T V^{-1} A x \right)$$

由于 $V$ 及其逆矩阵 $V^{-1}$ 为实对称矩阵，标量项 $b^T V^{-1} A x = (b^T V^{-1} A x)^T = x^T A^T V^{-1} b$，上式化简为：

$$J(x) = \frac{1}{2} b^T V^{-1} b - x^T A^T V^{-1} b + \frac{1}{2} x^T (A^T V^{-1} A) x$$

根据向量矩阵求导法则（$\nabla_x (x^T M) = M^T$，$\nabla_x (x^T N x) = 2 N x$，当 $N$ 对称时）：

$$\nabla_x J(x) = -A^T V^{-1} b + A^T V^{-1} A x$$

令梯度等于零向量 $\nabla_x J(x) = 0$（正态方程表达式）：

$$(A^T V^{-1} A) x = A^T V^{-1} b$$

由于 $A$ 列满秩且 $V^{-1}$ 正定，矩阵 $A^T V^{-1} A \in \mathbb{R}^{n \times n}$ 严格正定可逆。解得 **WLS 参数估计值公式**：

$$\hat{x} = (A^T V^{-1} A)^{-1} A^T V^{-1} b$$

##### 估算参数 $\hat{x}$ 的残差协方差矩阵 $W$ 推导：

由于 $\hat{x}$ 是观测向量 $b$ 的线性组合，根据协方差演化公式 $\text{Cov}(M b) = M \text{Cov}(b) M^T$：

取常数矩阵 $M = (A^T V^{-1} A)^{-1} A^T V^{-1}$，代入 $\text{Cov}(b) = V$：

$$W = \text{Cov}(\hat{x}) = \left[ (A^T V^{-1} A)^{-1} A^T V^{-1} \right] V \left[ (A^T V^{-1} A)^{-1} A^T V^{-1} \right]^T$$

利用矩阵转置法则以及 $V^{-1}$ 和 $(A^T V^{-1} A)^{-1}$ 的对称性：

$$W = (A^T V^{-1} A)^{-1} A^T V^{-1} V V^{-1} A (A^T V^{-1} A)^{-1}$$

由于 $V^{-1} V = I$：

$$W = (A^T V^{-1} A)^{-1} (A^T V^{-1} A) (A^T V^{-1} A)^{-1}$$

最终化简得到 **WLS 参数估计协方差矩阵**：

$$W = \text{Cov}(\hat{x}) = (A^T V^{-1} A)^{-1}$$

##### 🤖 在 AI / ML 中的对应应用：
极大似然估计是损失函数设计的基石。当假设模型预测残差服从非同方差高斯分布时，直接导出了加权 MSE 损失函数（Weighted MSE Loss）。

---

#### 与普通最小二乘 (OLS) 的退化关系与权重作用机制

##### 1. 退化为 OLS：
当观测噪声相互独立且同方差，即 $V = \sigma^2 I$ 时，其逆矩阵为 $V^{-1} = \frac{1}{\sigma^2} I$。将 $V^{-1}$ 代入 WLS 参数公式：

$$\hat{x}_{WLS} = \left( A^T \left( \frac{1}{\sigma^2} I \right) A \right)^{-1} A^T \left( \frac{1}{\sigma^2} I \right) b = \left( \frac{1}{\sigma^2} A^T A \right)^{-1} \frac{1}{\sigma^2} A^T b$$

标量因子 $\sigma^2$ 完全约去：

$$\hat{x}_{WLS} = (A^T A)^{-1} A^T b = \hat{x}_{OLS}$$

此时 WLS 退化为经典 OLS 正态方程。

##### 2. 对角 $V$ 矩阵下的权重作用物理机制：
若观测噪声相互独立但存在异方差（Heteroscedasticity），协方差矩阵为对角阵：

$$V = \text{diag}(\sigma_1^2, \sigma_2^2, \dots, \sigma_m^2)$$

其逆矩阵为权重对角阵：

$$V^{-1} = \text{diag}\left( \frac{1}{\sigma_1^2}, \frac{1}{\sigma_2^2}, \dots, \frac{1}{\sigma_m^2} \right) = \text{diag}(w_1, w_2, \dots, w_m)$$

损失函数变为独立的样本加权平方和：

$$J(x) = \frac{1}{2} \sum_{i=1}^m w_i (b_i - a_i^T x)^2 = \frac{1}{2} \sum_{i=1}^m \frac{1}{\sigma_i^2} (b_i - a_i^T x)^2$$

**重要作用机制**：样本权重 $w_i = \frac{1}{\sigma_i^2}$ 与噪声方差成反比。**噪声方差越大（不确定性越高/测量品质越差）的样本，其权重 $w_i$ 越小**；反之，精度极高、方差极小的样本将主导拟合过程。

##### 🤖 在 AI / ML 中的对应应用：
- **异方差处理与样本重加权（Sample Reweighting）**：针对包含噪声标签（Noisy Labels）或异常值的数据集进行健壮拟合。
- **不确定性感知损失（Uncertainty-weighted Loss）**：多任务学习（Multi-task Learning）中，根据各任务输出不确定性（方差 $\sigma_i^2$）动态自动调整各任务 Loss 的权重。

---

#### 具体计算示例：非同方差噪声下的 2D 拟合

已知拟合模型为一维常数参数估计 $b = A x$（对应拟合平移线），拟合 3 个数据点：
设计矩阵 $A = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}$，观测向量 $b = \begin{bmatrix} 1 \\ 2 \\ 9 \end{bmatrix}$。

假设观测噪声相互独立，其协方差矩阵为：

$$V = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 16 \end{bmatrix}$$

前两个观测点精度较高（$\sigma_1^2 = \sigma_2^2 = 1$），第 3 个观测点噪声极高（$\sigma_3^2 = 16$，属于显著野值/高噪声点）。

##### 1. 普通最小二乘（OLS）计算：
$$\hat{x}_{OLS} = (A^T A)^{-1} A^T b = \left( \begin{bmatrix} 1 & 1 & 1 \end{bmatrix} \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix} \right)^{-1} \begin{bmatrix} 1 & 1 & 1 \end{bmatrix} \begin{bmatrix} 1 \\ 2 \\ 9 \end{bmatrix}$$

$$\hat{x}_{OLS} = \frac{1}{3} (1 + 2 + 9) = \frac{12}{3} = 4$$

OLS 估计值被高噪声异常点 $b_3 = 9$ 严重拉偏。

##### 2. 加权最小二乘（WLS）计算：
计算权重矩阵 $V^{-1} = \text{diag}\left(1, 1, \frac{1}{16}\right)$。

计算 $A^T V^{-1} A$：

$$A^T V^{-1} A = \begin{bmatrix} 1 & 1 & 1 \end{bmatrix} \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1/16 \end{bmatrix} \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix} = 1 \cdot 1 + 1 \cdot 1 + 1 \cdot \frac{1}{16} = 2 + \frac{1}{16} = \frac{33}{16}$$

计算 $A^T V^{-1} b$：

$$A^T V^{-1} b = \begin{bmatrix} 1 & 1 & 1 \end{bmatrix} \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1/16 \end{bmatrix} \begin{bmatrix} 1 \\ 2 \\ 9 \end{bmatrix} = 1 \cdot 1 + 1 \cdot 2 + 9 \cdot \frac{1}{16} = 3 + \frac{9}{16} = \frac{57}{16}$$

计算 WLS 估计值 $\hat{x}_{WLS}$：

$$\hat{x}_{WLS} = \left( \frac{33}{16} \right)^{-1} \left( \frac{57}{16} \right) = \frac{57}{33} = \frac{19}{11} \approx 1.727$$

##### 对比与结论：
真实的高精度数据集中在 1 和 2 附近（均值 1.5）。
- OLS 解为 $4.000$（严重失真）。
- WLS 解为 $1.727$（大幅修正）。

WLS 机制通过把第 3 个点的权重自动降为 $1/16$，极其成功地抑制了高噪声样本对拟合模型的干扰。

### 3.5 延伸联系：广义最小二乘 (GLS)、卡尔曼滤波与 AI 全景

```
                    高维高斯分布与估计理论全景图
                                 │
     ┌───────────────────────────┼───────────────────────────┐
     ▼                           ▼                           ▼
[广义最小二乘 GLS]        [卡尔曼滤波 Kalman]       [现代生成模型 AI]
  │- 非对角协方差 V         │- 状态与观测高斯融合       │- 高斯过程 (GP)
  │- Cholesky 分解 V^(-1)   │- 动态递归 WLS            │- 扩散模型 (DDPM)
  │- 解耦自相关噪声          │- 卡尔曼增益 K 权衡       │- 高斯先验 Ridge 正则化
```

#### 广义最小二乘 (GLS)

当观测噪声矩阵 $V$ 为非对角矩阵时（意味着不同样本间存在显著的线性相关性或时间序列自相关性），加权最小二乘求解方法上升为**广义最小二乘**（Generalized Least Squares, GLS）。

##### Cholesky 解耦机制：
因为 $V^{-1}$ 正定，应用 Cholesky 下三角分解：

$$V^{-1} = C^T C$$

对原线性方程两边同时左乘常数转换矩阵 $C$：

$$C b = C A x + C e \implies b^* = A^* x + e^*$$

其中新噪声项 $e^* = C e$ 的协方差矩阵为：

$$\text{Cov}(e^*) = C \text{Cov}(e) C^T = C V C^T$$

由 $V^{-1} = C^T C \implies V = (C^T C)^{-1} = C^{-1} (C^T)^{-1}$，代入得：

$$\text{Cov}(e^*) = C \left( C^{-1} (C^T)^{-1} \right) C^T = I$$

通过 Cholesky 分解矩阵 $C$ 的空间变换，将复杂的空间相关/自相关噪声转换为了标准各向同性噪声 $e^* \sim \mathcal{N}(0, I)$，完美将非独立观测求解转换为标准 OLS 问题。

---

#### 卡尔曼滤波 (Kalman Filter)

卡尔曼滤波（Kalman Filter）是针对时域动态系统的最优状态估计器。其核心“测量更新（Measurement Update）”步骤在数学本质上即为**时序递归形式的加权最小二乘/高斯贝叶斯更新**。

##### 卡尔曼增益的 WLS 本质：
系统将状态预测分布 $\mathcal{N}(\hat{x}^-, P^-)$ 与高斯观测信号 $\mathcal{N}(z, R)$ 融合。更新公式为：

$$\hat{x} = \hat{x}^- + K (z - H \hat{x}^-)$$

其卡尔曼增益（Kalman Gain）矩阵表达为：

$$K = P^- H^T (H P^- H^T + R)^{-1}$$

卡尔曼增益 $K$ 在数学上充当了 WLS 权重配比器的角色：
- 若测量噪声方差 $R \to 0$（观测极度精确），则 $K \to H^{-1}$，系统置信完全倾斜于测量值 $z$。
- 若预测方差 $P^- \to 0$（先验模型极度精确），则 $K \to 0$，系统忽略观测噪声，完全保留预测状态。

---

#### 在现代机器学习中的图谱定位

多元高斯分布与加权最小二乘公式是现代 AI 多大前沿领域的基石：

1. **高斯过程（Gaussian Processes, GP）**：
   将多元高斯分布扩展至无限维函数空间。任意有限个点的函数值采样均服从多元高斯分布，其核函数矩阵（Kernel Matrix）直接作为高斯分布的协方差矩阵 $\Sigma$。

2. **扩散模型（Diffusion Models / DDPM）**：
   前向加噪过程（Forward Process）与反向去噪过程（Reverse Process）在本质上是一系列连续多元高斯分布的 Markov 变换。去噪网络通过预测高斯噪声的均值与方差，迭代完成图像生成。

3. **极大似然估计与 Ridge 正则化（$L_2$ Regularization）**：
   在 WLS 或 OLS 优化目标中，若假设参数 $x$ 本身服从零均值高斯先验 $x \sim \mathcal{N}(0, \tau^2 I)$，根据最大后验估计（MAP），优化目标将导出带有 $L_2$ 范数惩罚项的岭回归（Ridge Regression）：

   $$J(x)_{MAP} = \frac{1}{2}\|b - Ax\|^2_2 + \frac{\sigma^2}{2\tau^2} \|x\|^2_2$$

### 3.7 易错点

#### 易错点 1：混淆马氏距离与欧氏距离

- **错误做法**：在维度方差不一致或特征间存在强相关的特征空间中，直接使用欧氏二范数 $\|x - \mu\|^2$ 计算高斯概率密度或评估距离。
- **正确做法**：采用马氏距离二次型 $(x-\mu)^T \Sigma^{-1} (x-\mu)$。
- **原因分析**：欧氏距离隐式假设了数据在各维度上独立且方差齐次（等价于 $\Sigma = I$）。忽视协方差矩阵会导致椭圆主轴方向与斜率的几何扭曲。

#### 易错点 2：误以为任何协方差矩阵都可直接求逆

- **错误做法**：对任意样本计算出的样本协方差矩阵 $\Sigma$，直接在代码中调用 `np.linalg.inv(Sigma)` 计算 $\Sigma^{-1}$。
- **正确做法**：先检查条件数或行列式；若奇异或高度病态，采用伪逆（Pseudo-inverse）或进行协方差收缩正则化 $\Sigma + \epsilon I$。
- **原因分析**：当数据维度大于样本数（$n > m$）或存在冗余特征时，$|\Sigma| = 0$。直接求逆会触发数值溢出或报出 `Singular Matrix` 错误。

#### 易错点 3：WLS 权重系数与方差的关系搞反

- **错误做法**：在构建 WLS 加权对角阵时，将样本的观测方差 $\sigma_i^2$ 直接当作权重值 $w_i = \sigma_i^2$ 代入算法。
- **正确做法**：权重系数必须取为方差的倒数，即 $w_i = \frac{1}{\sigma_i^2}$。
- **原因分析**：方差代表测量不确定性与噪声强度。不确定性越大（$\sigma_i^2$ 越大）的样本，对其信任度越低，赋予的权重应该越小。

#### 易错点 4：混淆概率密度函数（PDF）值与概率值

- **错误做法**：计算出高斯 PDF 在某点的值为 $p(x_0) = 2.5$，得出“在该点发生的概率为 250%”的错误结论，认为程序出 Bug。
- **正确做法**：明确连续分布在单点处的概率永远严格为 0，密度函数 $p(x)$ 在局部完全可以大于 1。
- **原因分析**：概率密度代表的是“概率变化的微商速率”。真实的概率值只能通过对区域微元积分获取：$P(x \in \Delta) = \int_{\Delta} p(x) dx \le 1$。

#### 易错点 5：误认为白化变换会消除数据间的非线性相关结构

- **错误做法**：以为施加白化变换 $z = \Sigma^{-1/2}(x-\mu)$ 之后，随机变量之间变得完全独立。
- **正确做法**：白化变换仅仅消除了变量间的**一阶与二阶线性相关性**（线性协方差为 0）。
- **原因分析**：白化是线性坐标旋转与缩放。对于非高斯分布（如环形或 S 型弯曲分布），变量间依然可能留存极强的非线性依赖关系（高阶矩相关）。

<details>
<summary>查看解析与答案</summary>

**解析与答案**：
1. **线性变换与体积伸缩**：协方差矩阵 $\Sigma$ 可以看作是将标准各向同性空间拉伸变换为高斯数据散布空间的线性算子。其行列式 $|\Sigma|$ 代表 $n$ 维高维超平行多面体的**体积变化率**。

3. **归一化约束**：因为指数核在全空间上的体积扩展倍率恰好为 $|\Sigma|^{1/2}$，为保证全空间累积概率积分为 1，必须乘以其倒数进行归一化，因此系数必然为 $|\Sigma|^{-1/2}$。

<details>
<summary>查看解析与答案</summary>

**解析与答案**：
1. **写出协方差逆矩阵 $V^{-1}$**：

#### 题目 5（综合推导）
**问**：在加权最小二乘求解中，推导证明当观测噪声协方差矩阵 $V \to \infty \cdot I$（即所有观测噪声方差趋于无穷大）时，估算参数的置信度降为 0（残差协方差矩阵 $W \to \infty \cdot I$）的渐进行为。

<details>
<summary>查看解析与答案</summary>

**解析与答案**：
1. **代入极限协方差矩阵**：设 $V = k \cdot I$，其中标量 $k \to \infty$。
2. **计算逆矩阵 $V^{-1}$**：
   $$V^{-1} = \lim_{k \to \infty} \frac{1}{k} I = 0_{m \times m}$$

   $$W = \lim_{k \to \infty} k (A^T A)^{-1} \to \infty \cdot I$$
5. **结论**：估计参数 $\hat{x}$ 的方差趋近于无穷大。这表明当输入观测噪声极大时，基于数据得出的估计参数完全不可靠，参数估计的置信度降为零。
</details>

### 4.2 易错点解析

1. **样本方差计算时分母误用 $N$ 而非 $N-1$**
   * *错误做法*：在已知 $N$ 个采样点时，直接按经验公式计算 $S^2 = \frac{1}{N}\sum_{i=1}^N (x_i - m)^2$。
   * *正确做法*：样本无偏方差必须除以自由度 $N-1$。
   * *原因剖析*：由于公式中的样本平均值 $m$ 本身是由这 $N$ 个数据计算出来的，这占用掉了 $1$ 个独立自由度，若除以 $N$ 会系统性低估总体方差（产生 $\frac{N-1}{N}$ 的有偏缩放）。

2. **混淆“无关（Uncorrelated）”与“独立（Independent）”**
   * *错误做法*：算得协方差 $\sigma_{12} = 0$，就断定两随机变量完全独立。
   * *正确做法*：协方差为 $0$ 仅代表两变量间不存在**线性**相关性；而独立需要满足更强的非线性条件：对任意 $(i, j)$ 均有 $p_{ij} = p_i P_j$。例如 $X \sim U(-1, 1)$，$Y = X^2$，两变量高度非线性相关，但协方差计算结果严格为 $0$。

3. **误认为协方差矩阵 $V$ 永远严格正定**
   * *错误做法*：在求逆或分析子空间时，盲目假设协方差矩阵 $V$ 永远可逆（$\det(V) > 0$）。
   * *正确做法*：协方差矩阵在一般情况下仅保证正半定（$V \ge 0$）。当变量间存在确定性线性约束（如粘合硬币，或 $c x + d y + e z = 0$）或样本数 $N < M$ 时，$\det(V) = 0$，$V$ 退化为奇异矩阵。

4. **混淆单个变量常数倍的方差与独立变量求和的方差**
   * *错误做法*：认为 $\text{Var}(X + X) = 2 \text{Var}(X)$。
   * *正确做法*：$\text{Var}(X + X) = \text{Var}(2X) = 2^2 \text{Var}(X) = 4\text{Var}(X)$；而对于两个**独立同分布**的变量 $X_1, X_2$，才有 $\text{Var}(X_1 + X_2) = \text{Var}(X_1) + \text{Var}(X_2) = 2\text{Var}(X)$。

5. **误将连续概率密度函数 $p(x)$ 的函数值当做概率**
   * *错误做法*：认为连续分布中 $p(x_0)$ 的大小就是变量恰好等于 $x_0$ 的概率。
   * *正确做法*：对于连续型随机变量，单点概率 $P(X = x_0) = 0$。密度值 $p(x)$ 可以大于 $1$（例如 $U(0, 0.1)$ 的密度 $p(x) = 10$），只有在区间上的定积分 $\int_a^b p(x) dx$ 才代表概率。

6. **在计算外积矩阵与内积标量时混淆 $\boldsymbol{U}\boldsymbol{U}^T$ 与 $\boldsymbol{U}^T \boldsymbol{U}$**
   * *错误做法*：在构造协方差矩阵时写成 $\boldsymbol{U}^T \boldsymbol{U}$。
   * *正确做法*：$\boldsymbol{U}$ 为 $M \times 1$ 列向量，外积 $\boldsymbol{U}\boldsymbol{U}^T$ 才能得到 $M \times M$ 的正半定矩阵；而内积 $\boldsymbol{U}^T \boldsymbol{U}$ 得到的是一个标量（向量模长的平方）。

7. **忽略连续分布方差积分平移技巧导致的计算繁琐**
   * *错误做法*：在计算区间 $[17, 20]$ 上的均匀分布方差时，直接展开定积分 $\int_{17}^{20} \frac{1}{3} (x - 18.5)^2 dx$ 进行硬算。
   * *正确做法*：引入变量代换 $u = x - 17$，将区间平移至 $[0, 3]$，均值平移至 $1.5$，化简为 $\int_0^3 \frac{1}{3} (u - 1.5)^2 du = \frac{3^2}{12} = \frac{3}{4}$。

8. **标准化（Standardization）与归一化（Normalization）混淆**
   * *错误做法*：认为减去任意常数或除以最大值都是标准化。
   * *正确做法*：减去**均值 $m$** 并除以**标准差 $\sigma$** 得到的是零均值单位方差分布（Standardization）；而归一化（Min-Max Normalization）是指将数据线性缩放到 $[0, 1]$ 区间。

### 4.3 自测题

1. **样本均值与样本协方差矩阵计算**：
   给定 $4$ 个二维样本点：$\boldsymbol{X}_1 = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$, $\boldsymbol{X}_2 = \begin{bmatrix} 3 \\ 4 \end{bmatrix}$, $\boldsymbol{X}_3 = \begin{bmatrix} 2 \\ 1 \end{bmatrix}$, $\boldsymbol{X}_4 = \begin{bmatrix} 2 \\ 5 \end{bmatrix}$。求样本均值向量 $\bar{\boldsymbol{X}}$ 与 $2 \times 2$ 样本无偏协方差矩阵 $S$。
   <details><summary>查看解析与答案</summary>

   * **样本均值向量**：
     $$\bar{\boldsymbol{X}} = \frac{1}{4}\left( \begin{bmatrix} 1 \\ 2 \end{bmatrix} + \begin{bmatrix} 3 \\ 4 \end{bmatrix} + \begin{bmatrix} 2 \\ 1 \end{bmatrix} + \begin{bmatrix} 2 \\ 5 \end{bmatrix} \right) = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$$

     $$\boldsymbol{U}_1 = \begin{bmatrix} -1 \\ -1 \end{bmatrix}, \quad \boldsymbol{U}_2 = \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \quad \boldsymbol{U}_3 = \begin{bmatrix} 0 \\ -2 \end{bmatrix}, \quad \boldsymbol{U}_4 = \begin{bmatrix} 0 \\ 2 \end{bmatrix}$$
   * **外积矩阵求和 $\sum \boldsymbol{U}_k \boldsymbol{U}_k^T$**：
     $$\boldsymbol{U}_1 \boldsymbol{U}_1^T = \begin{bmatrix} 1 & 1 \\ 1 & 1 \end{bmatrix}, \quad \boldsymbol{U}_2 \boldsymbol{U}_2^T = \begin{bmatrix} 1 & 1 \\ 1 & 1 \end{bmatrix}, \quad \boldsymbol{U}_3 \boldsymbol{U}_3^T = \begin{bmatrix} 0 & 0 \\ 0 & 4 \end{bmatrix}, \quad \boldsymbol{U}_4 \boldsymbol{U}_4^T = \begin{bmatrix} 0 & 0 \\ 0 & 4 \end{bmatrix}$$
     $$\sum_{k=1}^4 \boldsymbol{U}_k \boldsymbol{U}_k^T = \begin{bmatrix} 2 & 2 \\ 2 & 10 \end{bmatrix}$$
   * **样本无偏协方差矩阵 $S$（除以 $N-1 = 3$）**：
     $$S = \frac{1}{3}\begin{bmatrix} 2 & 2 \\ 2 & 10 \end{bmatrix} = \begin{bmatrix} 2/3 & 2/3 \\ 2/3 & 10/3 \end{bmatrix}$$
   </details>

2. **均匀分布统计量**：
   已知随机变量 $X \sim U(2, 8)$，求 $E[X]$、$\text{Var}(X)$ 以及概率 $P(3 \le X \le 5)$。
   <details><summary>查看解析与答案</summary>

   将区间 $[2, 8]$ 平移至 $[0, 6]$（长度 $a = 6$）：
   * 期望值：$E[X] = \frac{2 + 8}{2} = 5$。
   * 方差：$\text{Var}(X) = \frac{a^2}{12} = \frac{6^2}{12} = 3$。
   * 概率：$p(x) = \frac{1}{6}$，故 $P(3 \le X \le 5) = \int_3^5 \frac{1}{6} dx = \frac{5 - 3}{6} = \frac{1}{3}$。
   </details>

3. **联合概率矩阵与独立性判别**：
   给定联合概率矩阵 $P = \begin{bmatrix} 1/6 & 1/3 \\ 1/3 & 1/6 \end{bmatrix}$（对应 $x \in \{0, 1\}, y \in \{0, 1\}$）。计算边际概率，判断 $x$ 与 $y$ 是否独立，并计算协方差 $\sigma_{12}$。
   <details><summary>查看解析与答案</summary>

   * **边际概率**：
     * 行和：$p_1 = 1/6 + 1/3 = 1/2$，$p_2 = 1/3 + 1/6 = 1/2$。
     * 列和：$P_1 = 1/6 + 1/3 = 1/2$，$P_2 = 1/3 + 1/6 = 1/2$。
   * **独立性检验**：
     由于 $p_{11} = 1/6 \neq p_1 \cdot P_1 = (1/2)(1/2) = 1/4$，两变量**不独立**。
   * **期望与协方差**：
     * $m_1 = E[x] = 1/2$，$m_2 = E[y] = 1/2$。
     * $\sigma_{12} = \sum p_{ij} (x_i - 1/2)(y_j - 1/2)$：
       $$\sigma_{12} = \frac{1}{6}\left(-\frac{1}{2}\right)\left(-\frac{1}{2}\right) + \frac{1}{3}\left(-\frac{1}{2}\right)\left(\frac{1}{2}\right) + \frac{1}{3}\left(\frac{1}{2}\right)\left(-\frac{1}{2}\right) + \frac{1}{6}\left(\frac{1}{2}\right)\left(\frac{1}{2}\right) = \frac{1}{24} - \frac{1}{12} - \frac{1}{12} + \frac{1}{24} = -\frac{1}{12}$$
   </details>

4. **正态分布线性变换**：
   设 $X \sim N(3, 16)$，构造 $Y = 2X + 5$。求 $Y$ 的分布类型、均值与方差。
   <details><summary>查看解析与答案</summary>

   * **分布类型**：正态分布的线性变换依然服从正态分布。
   * **均值**：$m_Y = 2 m_X + 5 = 2(3) + 5 = 11$。
   * **方差**：$\sigma_Y^2 = 2^2 \sigma_X^2 = 4(16) = 64$。
   * 结论：$Y \sim N(11, 64)$。
   </details>

5. **二项分布与 CLT 近似**：
   抛掷公平硬币 $100$ 次，使用中央极限定理估计正面出现次数在 $45$ 至 $55$ 次之间的概率。
   <details><summary>查看解析与答案</summary>

   * 均值 $m = N/2 = 50$，方差 $\sigma_N^2 = N/4 = 25 \implies \sigma_N = 5$。
   * 标准化变量：$X = \frac{x - 50}{5}$。
   * 当 $x = 45$ 时，$X = -1$；当 $x = 55$ 时，$X = 1$。
   * 未做连续性修正的正态近似：$P(45 \le x \le 55) \approx P(-1 \le X \le 1) \approx 68.3\%$。
   * 加上连续性修正（$x$ 是整数，端点应扩展到 $44.5 \sim 55.5$）：$z = \pm 1.1$，得 $\approx 72.9\%$——精确二项概率为 $0.7287$。可见 $n=100$ 时**必须做连续性修正**，68.3% 低估了约 4.6 个百分点。
   </details>

6. **二次型正半定证明**：
   已知总体协方差矩阵 $V = E[(\boldsymbol{X}-\bar{\boldsymbol{X}})(\boldsymbol{X}-\bar{\boldsymbol{X}})^T]$。证明对任意实常数向量 $\boldsymbol{c}$，均有 $\boldsymbol{c}^T V \boldsymbol{c} \ge 0$。
   <details><summary>查看解析与答案</summary>

   证明：
   $$\begin{aligned}
   \boldsymbol{c}^T V \boldsymbol{c} &= \boldsymbol{c}^T E\left[ (\boldsymbol{X}-\bar{\boldsymbol{X}})(\boldsymbol{X}-\bar{\boldsymbol{X}})^T \right] \boldsymbol{c} \\
   &= E\left[ \boldsymbol{c}^T (\boldsymbol{X}-\bar{\boldsymbol{X}})(\boldsymbol{X}-\bar{\boldsymbol{X}})^T \boldsymbol{c} \right] \\
   &= E\left[ \left( \boldsymbol{c}^T (\boldsymbol{X}-\bar{\boldsymbol{X}}) \right) \left( \boldsymbol{c}^T (\boldsymbol{X}-\bar{\boldsymbol{X}}) \right)^T \right] \\
   &= E\left[ \left( \boldsymbol{c}^T (\boldsymbol{X}-\bar{\boldsymbol{X}}) \right)^2 \right]
   \end{aligned}$$
   由于实数平方的期望值恒大于等于 $0$，故对任意向量 $\boldsymbol{c}$，二次型 $\boldsymbol{c}^T V \boldsymbol{c} \ge 0$ 恒成立。证毕。
   </details>

7. **退化协方差矩阵分析**：
   设 $x$ 为随机变量，$\text{Var}(x) = 1$；设 $y = 2x + 1$。构造随机向量 $\boldsymbol{X} = [x, y]^T$，求其协方差矩阵 $V$ 的行列式 $\det(V)$，并解释其几何意义。
   <details><summary>查看解析与答案</summary>

   * $\text{Var}(x) = 1$。
   * $\text{Var}(y) = \text{Var}(2x + 1) = 4 \text{Var}(x) = 4$。
   * 协方差 $\sigma_{xy} = E[(x - m_x)(2x + 1 - (2m_x + 1))] = 2 \text{Var}(x) = 2$。
   * 协方差矩阵：$V = \begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix}$。
   * 行列式：$\det(V) = (1)(4) - (2)(2) = 0$。
   * 几何意义：$\det(V) = 0$ 说明矩阵奇异，变量之间存在确定性的完全线性依赖，二维空间中的随机概率分布退化压扁至一维直线上。
   </details>

8. **蒙特卡罗误差与 MLMC 优化**：
   若要将标准蒙特卡罗估计的标准差缩小为原来的 $1/10$，样本量 $N$ 需要扩大多少倍？在 2-Level MLMC 中，若粗糙模拟单次成本 $C = 1$，方差 $\sigma = 2$；精细残差模拟单次成本 $C^* = 9$，残差方差 $\sigma^* = 0.3$，求最佳采样比率 $N / N^*$。
   <details><summary>查看解析与答案</summary>

   * 第一问：标准差阶数为 $O(1/\sqrt{N})$。要使标准差缩小为 $1/10$，样本量 $N$ 必须扩大 **$100$ 倍**。
   * 第二问：应用拉格朗日乘子法优化的最佳比率公式：
     $$\frac{N}{N^*} = \frac{\sigma}{\sigma^*} \sqrt{\frac{C^*}{C}} = \frac{2}{0.3} \sqrt{\frac{9}{1}} = \frac{20}{3} \times 3 = 20$$
     即低成本粗糙模拟的采样数应为高成本残差模拟采样数的 $20$ 倍。
   </details>

9. **协方差矩阵正交对角化（谱分解）**：
   已知协方差矩阵 $V = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix}$，求其特征值与特征向量，并写出谱分解形式 $Q \Lambda Q^T$。
   <details><summary>查看解析与答案</summary>

   * **求解特征值**：
     $$\det(V - \lambda I) = (2-\lambda)^2 - 1 = 0 \implies \lambda_1 = 3, \quad \lambda_2 = 1$$
   * **求解特征向量**：
     * 对 $\lambda_1 = 3$：$(V - 3I)\boldsymbol{x} = \mathbf{0} \implies \begin{bmatrix} -1 & 1 \\ 1 & -1 \end{bmatrix}\boldsymbol{x} = \mathbf{0} \implies \boldsymbol{q}_1 = \frac{1}{\sqrt{2}}\begin{bmatrix} 1 \\ 1 \end{bmatrix}$
     * 对 $\lambda_2 = 1$：$(V - I)\boldsymbol{x} = \mathbf{0} \implies \begin{bmatrix} 1 & 1 \\ 1 & 1 \end{bmatrix}\boldsymbol{x} = \mathbf{0} \implies \boldsymbol{q}_2 = \frac{1}{\sqrt{2}}\begin{bmatrix} -1 \\ 1 \end{bmatrix}$
   * **谱分解形式 $V = Q \Lambda Q^T$**：
     $$V = \begin{bmatrix} \frac{1}{\sqrt{2}} & -\frac{1}{\sqrt{2}} \\ \frac{1}{\sqrt{2}} & \frac{1}{\sqrt{2}} \end{bmatrix} \begin{bmatrix} 3 & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} \frac{1}{\sqrt{2}} & \frac{1}{\sqrt{2}} \\ -\frac{1}{\sqrt{2}} & \frac{1}{\sqrt{2}} \end{bmatrix}$$
   </details>

10. **样本均值与残差协方差为零严密证明**：
    设 $X_1, X_2, \dots, X_N$ 为独立同分布随机变量，总体均值为 $\mu$，总体方差为 $\sigma^2$。设样本均值为 $\bar{X} = \frac{1}{N}\sum_{j=1}^N X_j$。证明对任意样本 $X_i$，样本均值 $\bar{X}$ 与残差项 $X_i - \bar{X}$ 的协方差严格为零（即 $\text{Cov}(\bar{X}, X_i - \bar{X}) = 0$）。
    <details><summary>查看解析与答案</summary>

    证明：
    根据协方差的双线性性质：
    $$\text{Cov}(\bar{X}, X_i - \bar{X}) = \text{Cov}(\bar{X}, X_i) - \text{Cov}(\bar{X}, \bar{X}) = \text{Cov}(\bar{X}, X_i) - \text{Var}(\bar{X})$$

    1. 计算第一项 $\text{Cov}(\bar{X}, X_i)$：
       $$\text{Cov}(\bar{X}, X_i) = \text{Cov}\left( \frac{1}{N}\sum_{j=1}^N X_j, X_i \right) = \frac{1}{N} \sum_{j=1}^N \text{Cov}(X_j, X_i)$$
       由于 $X_1, \dots, X_N$ 相互独立，当 $j \neq i$ 时 $\text{Cov}(X_j, X_i) = 0$；当 $j = i$ 时 $\text{Cov}(X_i, X_i) = \text{Var}(X_i) = \sigma^2$。
       因此：
       $$\text{Cov}(\bar{X}, X_i) = \frac{1}{N} \sigma^2$$

    2. 计算第二项 $\text{Var}(\bar{X})$：
       $$\text{Var}(\bar{X}) = \text{Var}\left( \frac{1}{N}\sum_{j=1}^N X_j \right) = \frac{1}{N^2} \sum_{j=1}^N \text{Var}(X_j) = \frac{N \sigma^2}{N^2} = \frac{\sigma^2}{N}$$

    代入原式得出结果：
    $$\text{Cov}(\bar{X}, X_i - \bar{X}) = \frac{\sigma^2}{N} - \frac{\sigma^2}{N} = 0$$
    证毕。注意这里证明的只是 $\mathrm{Cov}(\bar X,\, X_i - \bar X) = 0$，也就是"**不相关**"（几何上即 $\bar X$ 与残差子空间正交）。由协方差为零**推不出独立**——这正是本节前面强调过的易错点。正态样本下 $\bar X$ 与 $S^2$ 的独立性还需要用到正态性本身，可由 Cochran 定理（正交分解下二次型相互独立）或 Basu 定理给出。
    </details>

#### 前置知识调用（已学 1–5 章）

1. **第 1 章（向量与线性组合）**：随机变量的线性组合 $\boldsymbol{c}^T \boldsymbol{X} = c_1 X_1 + \dots + c_M X_M$ 直接套用了第一章的向量内积；期望算子的加性 $E[\boldsymbol{c}^T \boldsymbol{X}] = \boldsymbol{c}^T E[\boldsymbol{X}]$ 是向量线性变换性质在概率空间上的自然延伸。
2. **第 2 章（消元法与矩阵求逆）**：计算多元高斯分布指数项中的马氏距离及统计推断时，必须对协方差矩阵 $V$ 进行求逆（$V^{-1}$），第 2 章的 $LU$ 分解与对称正定矩阵的 Cholesky 分解（$A = L L^T$）为快速求解高斯分布提供了直接的算法实现。
3. **第 3 章（四个基本子空间与秩）**：每个输出状态的单项外积矩阵 $\boldsymbol{U} \boldsymbol{U}^T$ 均为秩 $1$ 矩阵；当协方差矩阵退化（$\det(V) = 0$）时，其零空间（Nullspace）精确刻画了数据方差为 $0$ 的确定性线性约束方向。
4. **第 4 章（正交性、二次型与最小二乘）**：通过二次型 $\boldsymbol{c}^T V \boldsymbol{c} \ge 0$ 证明协方差矩阵的正半定性，与第 4 章正交投影及能量极小化框架完全一致。此外，高斯分布下的最大似然估计（MLE）在代数上与最小二乘法严格等价。
5. **第 5 章（行列式与谱分解）**：多元高斯分布归一化因子中的 $\det(V)^{1/2}$ 代表高斯分布概率密度在 $M$ 维空间中的几何体积缩放因子；实对称协方差矩阵的正交对角化 $V = Q \Lambda Q^T$ 则是第 5 章谱定理在数据去相关（PCA）上的经典应用。

#### 后向延伸铺路（机器学习与数据科学）

1. **主成分分析（PCA）与奇异值分解（SVD）**：本章推导的协方差矩阵谱分解 $V = Q \Lambda Q^T$ 是无监督降维算法 PCA 的直接理论基础。在实际数据科学中，通常直接对中心化数据矩阵进行 SVD 分解，以避免显式计算协方差矩阵。
2. **高斯混合模型（GMM）与 EM 算法**：本章的多元高斯分布与联合/边际概率是 GMM 聚类算法的核心。EM 算法通过交替更新隐变量的后验概率与高斯分量的均值向量及协方差矩阵，实现复杂分布的密度估计。
3. **线性判别分析（LDA）与核方法（Kernel Methods）**：LDA 依靠计算类内协方差矩阵与类间协方差矩阵寻找最佳投影方向；核方法（Kernel PCA / SVM）则将本章的内积与协方差结构推广至无限维再生核希尔伯特空间（RKHS）。
4. **信息论基础（Entropy / KL 散度）**：正态分布在固定方差条件下具有**最大熵（Maximum Entropy）**性质，这解释了高斯噪声假设在自然界中的普遍性；变分推断（VI）与扩散模型则通过极小化 KL 散度调控复杂高维概率分布。
