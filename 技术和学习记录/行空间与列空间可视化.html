行空间 & 列空间

名字即来源：用"行"搭出来的空间 → 行空间，用"列"搭出来的空间 → 列空间

矩阵 A（3×2）
→ 1 0 行₁
→ 2 0 行₂
→ 0 0 行₃
材料来源
行空间 ← 用每一行做材料
列空间 ← 用每一列做材料
● 行向量在 ℝ²（每行2个数字）   ● 列向量在 ℝ³（每列3个数字）

■ 行空间 ℝ² dim = 1

材料：行₁ = (1,0) 行₂ = (2,0) 行₃ = (0,0) → 都在 x 轴上
a = 1.0 b = 0.5

拖动滑块 → 移动黄色点：这就是"组合行向量"到达的位置

■ 列空间 ℝ³ dim = 1

材料：列₁ = (1,2,0) 列₂ = (0,0,0) → 方向 (1,2,0) 上的直线
c = 0.7 列₂恒为零，不影响

拖动滑块 → 黄色点在列空间直线上滑动

🔑 一句话理解

行空间（Row Space）

Row Space = span{行₁, 行₂, …, 行m}
名字由来：拿矩阵的每一行做材料，所有线性组合搭出来的空间。
在哪儿：ℝⁿ = ℝ²（每行有 n=2 个数字）
维度：秩 r = 1（只有第1列有主元）
本例子：行向量 (1,0) 和 (2,0) 都在 x 轴上 → 行空间 = x 轴

列空间（Column Space）

Column Space = span{列₁, 列₂, …, 列n}
名字由来：拿矩阵的每一列做材料，所有线性组合搭出来的空间。
在哪儿：ℝᵐ = ℝ³（每列有 m=3 个数字）
维度：秩 r = 1（只有第1行有主元）
本例子：列向量 (1,2,0) 张成一条直线 → 列空间 = 方向 (1,2,0) 的直线
行空间 ⊆ ℝ² ← 两个不同的"宇宙" → 列空间 ⊆ ℝ³
名字就是按行/列来的，没有深奥的秘密。就像面包糠是用面包做的。
💡 拖动滑块可交互体验"组合行/列向量"的效果
