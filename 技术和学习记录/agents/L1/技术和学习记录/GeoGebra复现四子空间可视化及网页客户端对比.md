## Turn 1：GeoGebra 能否画 HTML 可视化
- 判断：**可以**，核心数学 100% 可还原，UI 布局 1:1 复现约 60%（单窗口限制）。
- HTML 数学内核：$A=[[0.7,0,0],[0,0.491,0],[0,0.344,0]]$（0.6·cos35°/sin35°），rank=2；Row(A)=xy 平面、N(A)=z 轴、Col(A) 由两列张成、N(Aᵀ) 方向 (0,−sin35°,cos35°)。
- 提供可直接粘贴到 geogebra.org/3d 的命令序列（滑块 a/b/c + 点 X/Y/Z + 向量 + Polygon 行空间 + Line 零空间 + ApplyMatrix 算 b + Plane 列空间 + Line 左零空间）。
- 三种取舍：(1) 简化版单 3D 视图叠加（推荐，教学更直观）；(2) GeoGebra Notes/嵌入 iframe 逼近原版双视图；(3) 保留 HTML 仅追加截图/链接。

## Turn 2-4：网页版 vs 客户端版
- 联网核对官方文档。功能几乎一致，差异在"是否离线、文件存哪、UI 细节、考试模式"。
- 客户端分三种：**Calculator Suite**（新一代 HTML5，官方推荐日常教学）、**Classic 6**（HTML5，UI 与网页版一致）、**Classic 5**（Java 老桌面版，UI 与网页版差异最大，仍在维护）。
- 官方建议：学生跨场景用同一 App；推荐 Chrome 浏览器。
- 极简核心区别只有两条：(1) 联网——网页版必须联网，客户端可离线；(2) 文件位置——网页版存云端需登录，客户端存本地 .ggb。**能离线、能存本地是客户端的唯一实质优势**。
- 命令语法通用，作品可互通。
