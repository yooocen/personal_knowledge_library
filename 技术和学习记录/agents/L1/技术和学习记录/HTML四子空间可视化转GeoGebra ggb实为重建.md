## 关键结论
- HTML 可视化对象：3×3 秩2矩阵 $A=[[0.7,0,0],[0,0.491,0],[0,0.344,0]]$ 的**四个基本子空间**交互式 SVG 可视化。输入空间（行空间 z=0 平面 + 零空间 z 轴）、输出空间（列空间 + 左零空间），含滑动条 x₁/x₂/x₃、轨道相机、沿 N(A) 动画。
- **.ggb 本质是 zip 包**（内含 `geogebra.xml`），GeoGebra **无 HTML 导入功能**，故"转换"实为"重建"。
- 列空间法向量 = col1×col2 = (0, -0.2408, 0.3437)。

## 三种方案对比
- **方案 A（推荐）**：在 GeoGebra 3D Calculator 逐条粘贴命令脚本重建，另存为 .ggb。已附精校过语法的命令脚本（Plane/Line/Vector/ApplyMatrix 等）。
- **方案 B**：Python 拼 XML+zip 打包 .ggb（风险中等）。
- **方案 C**：Obsidian GeoGebra 插件直接嵌 HTML/iframe。

## 风险/未知
- HTML 双视图无法 1:1 还原（GeoGebra 单窗口布局限制）。
- 滑动条需右键启用动画。
- ApplyMatrix 跨版本兼容性需验证。
- 叉积数值（列空间法向量）需在 GeoGebra 内复核。
