### Assistant final
核心论点：零空间度量「可区分性」——哪些输入在 A 眼中彼此无法区分、哪些信息被压碎为零。

五个理解层次：
1. 方程视角：零空间是 Ax=b 解集的「形状骨架」，非齐次解集 = 特解位置 + 零空间形状的平移（连接笔记 3.3 x_p + x_n 与 3.4 的 y''=2 例子）。
2. 变换视角（核心直觉）：x−y ∈ N(A) ⟹ Ax=Ay，A 无法区分。例：A=[1 1] 求和器，(3,5)/(4,4)/(5,3) 同得 8，差 (1,−1) 落在零空间；投影的零空间 = 法线方向（影子看不见高度）；入射矩阵零空间 = 常值向量（只测电位差，绝对电位是规范自由度）。
3. 判据视角：N(A)={0} ⟺ 列无关 ⟺ 解唯一；矮宽矩阵定理 =「压缩必然丢信息」。
4. 计数视角：dim N(A) = n−r，行空间 r 维存活 + 零空间 n−r 维湮灭，维度守恒；第 4 章将升级为正交补分解 ℝⁿ = 行空间 ⊕ N(A)。
5. 推广视角：零空间 = 线性算子的核。D 的核 = 常数函数（积分 +C），D²+1 的核 = span{sin, cos}（笔记 3.4 微分方程表），完整解 = 特解 + 核是线性世界普适规律。

常见误区：零空间 ≠ 空间 Z；零空间在输入端 ℝⁿ 而非 ℝᵐ；零空间非平凡 ≠ A 无用。

建议：学第 4 章正交补时回看 3.5；动手算小图的 N(A) 与 N(Aᵀ) 验证图论对偶（连通分量数 = dim N(A)，独立回路数 = dim N(Aᵀ)）；自测「为何 Ax=b 解集不是子空间却与零空间同形」。

### Assistant final
定义：N(A) = {x ∈ ℝⁿ : Ax = 0}——把 A 当机器，零空间是所有被它变成零向量的输入凑成的集合。三要件：装输入 x（n 个分量）不装输出 b；准入条件 Ax=0；自动构成 ℝⁿ 的子空间（零解在内、加法数乘封闭）。例子 A=[1 2 3]：x+2y+3z=0 是 ℝ³ 过原点平面，N(A)=span{(−2,1,0),(−3,0,1)}，维度 2 = n−r = 3−1。一句话总结：零空间 = 齐次方程 Ax=0 全体解构成的 ℝⁿ 子空间。计算方法见第3章 3.2，意义见 [[零空间.md]]。
