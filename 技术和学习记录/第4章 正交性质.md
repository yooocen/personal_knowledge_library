# 第四章 正交性质（Orthogonality）

> 本章完成从「求解精确解」到「寻找最佳近似解」的飞跃。当 $Ax = b$ **无解**时（方程数多于未知数的超定系统），不再死磕精确解，而是用**投影**和**最小二乘法**找到最佳近似解。本章揭示了矩阵四个基础子空间不仅在维度上互补，在几何上也呈现完美的**正交**关系——这是线性代数基础定理的第二部分。最后用**格莱姆-施密特正交化**把计算建立在正交单位基底之上，为后续特征值、SVD 打下基础。

## 4.1 四个子空间的正交性质

### 正交向量与正交子空间

**正交向量**：若两个向量的点积为零（$v^T w = 0$），则它们互相正交。

- 零向量与任何向量都正交；$v^T w = 0$ 是判断正交的唯一标准。
- 几何直觉：在 $\mathbb{R}^2$ 中，正交即垂直；零向量「与所有向量垂直」。

**正交子空间**：若子空间 $V$ 中的每个向量都与子空间 $W$ 中的每个向量垂直，则 $V$ 与 $W$ 正交。

> 注意：正交子空间可以相交于非零向量吗？不能——若 $x$ 同时属于 $V$ 与 $W$，则 $x^T x = 0$，只能 $x = 0$。所以正交子空间**只交于零向量**。

**正交补（Orthogonal Complement）**：子空间 $V$ 的正交补 $V^{\perp}$ 包含**所有**与 $V$ 垂直的向量。

$$
V^{\perp} = \{\text{与 } V \text{ 中每个向量都垂直的所有向量}\}
$$

### 基础定理（第二部分）：四个子空间的正交补

$$
\boxed{\text{在 } \mathbb{R}^n：\quad C(A^T) \perp N(A)，\quad C(A^T) \oplus N(A) = \mathbb{R}^n}
$$

$$
\boxed{\text{在 } \mathbb{R}^m：\quad C(A) \perp N(A^T)，\quad C(A) \oplus N(A^T) = \mathbb{R}^m}
$$

| 子空间 | 它的正交补 | 所在空间 | 维度关系 |
|--------|-----------|---------|---------|
| 行空间 $C(A^T)$ | 零空间 $N(A)$ | $\mathbb{R}^n$ | $r + (n-r) = n$ |
| 列空间 $C(A)$ | 左零空间 $N(A^T)$ | $\mathbb{R}^m$ | $r + (m-r) = m$ |

- **行空间与零空间正交**：$A$ 的每一行都与 $Ax = 0$ 的解垂直（行乘 $x$ 得 0），所以行空间 ⊥ 零空间。
- 维度互补：$R^n$ 中行空间维度 $r$ + 零空间维度 $n-r = n$，二者正是**正交补**（不仅正交，还维度互补）。
- 这是线性代数基础定理的**第二部分**（第一部分是维度：秩 $r$ 决定四个子空间维度；第二部分是几何：正交补关系）。

> **关键洞察**：$\mathbb{R}^n$ 中的任意向量 $x$ 都能唯一分解为「行空间分量 + 零空间分量」；$\mathbb{R}^m$ 中任意 $b$ 都能唯一分解为「列空间分量 + 左零空间分量」。这正是下一节投影的理论依据。

## 4.2 投影（Projection）

投影解决一个问题：给定向量 $b$ 和一个子空间，如何在子空间中找到「离 $b$ 最近」的向量 $p$？这个 $p$ 就是 $b$ 的投影。

### 投影到直线

把 $b$ 投影到由向量 $a$ 张成的直线上，投影点 $p$ 是 $a$ 的倍数 $p = \hat{x}a$，且误差 $e = b - p$ 与 $a$ 垂直：

$$
e \perp a \quad\Longrightarrow\quad a^T(b - \hat{x}a) = 0
$$

$$
\boxed{p = a\,\frac{a^T b}{a^T a}}
$$

- 系数 $\hat{x} = \dfrac{a^T b}{a^T a}$ 是「$b$ 在 $a$ 方向上的坐标」。
- 投影后误差 $e = b - p$ 与直线垂直。

### 投影到子空间与投影矩阵

把 $b$ 投影到由 A 的列张成的子空间 $C(A)$ 上，投影点 $p = A\hat{x}$。误差 $e = b - A\hat{x}$ 必须与 $C(A)$ 正交，即与 A 的每列正交：

$$
A^T(b - A\hat{x}) = 0 \quad\Longrightarrow\quad A^T A \hat{x} = A^T b
$$

当 A 的列线性无关（$A^T A$ 可逆）时：

$$
\boxed{\hat{x} = (A^T A)^{-1} A^T b, \qquad p = A(A^T A)^{-1} A^T b = Pb}
$$

$$
\boxed{P = A(A^T A)^{-1} A^T \quad (\text{投影矩阵})}
$$

**投影矩阵的两个基本性质**：

- $P^2 = P$（投影两次还是投影本身）
- $P^T = P$（对称矩阵）

> 投影到**一维直线**时公式退化：$P = \dfrac{a a^T}{a^T a}$（分母是数量，不是矩阵）。投影到 $C(A)$ 的标准做法是解正态方程，而不是直接算 $P$。

## 4.3 最小二乘近似（Least Squares Approximation）

当 $Ax = b$ **无解**（$b$ 不在列空间 $C(A)$ 中）时，最小二乘法给出「最佳近似解」 $\hat{x}$：让 $b$ 到 $C(A)$ 的距离 $||b - A\hat{x}||$ 最小。

### 核心思想

- 把 $b$ 投影到 $C(A)$ 得到 $p$（$b$ 在列空间中最接近的向量）。
- 解 $A\hat{x} = p$（有解，因为 $p \in C(A)$），$\hat{x}$ 就是最小二乘解。
- 误差 $e = b - p = b - A\hat{x}$ 垂直于 $C(A)$，即 $e \in N(A^T)$。

### 正态方程（Normal Equations）

$$
\boxed{A^T A \hat{x} = A^T b}
$$

- 当 $A^T A$ 可逆时，$\hat{x} = (A^T A)^{-1} A^T b$。
- 最小二乘解 $\hat{x}$ 使残差平方和 $||A\hat{x} - b||^2$ 最小，故得名「最小二乘」。

### 最小二乘的几何意义

- 残差向量 $e = b - A\hat{x}$ 与 **列空间 $C(A)$ 正交**（投影的误差性质）。
- 完美的分解：$b = p + e$，其中 $p \in C(A)$（可解部分），$e \in N(A^T)$（不可解部分）。
- 这正是 4.1 节「$\mathbb{R}^m$ 分解为列空间 ⊕ 左零空间」的实际应用。

### 典型应用场景

- **数据拟合**：用直线 $y = C + Dt$ 拟合多个数据点，方程数多于未知数时超定。
- **任何 m > n 的过定系统**：测量值多于未知量，无法精确满足所有方程，退而求最小二乘。

> 关键矩阵 $A^T A$：对称、半正定；当 A 列满秩时 $A^T A$ 可逆（正定）。后续特征值一章会再遇到它。

## 4.4 正交单位基底与格莱姆-施密特（Gram-Schmidt）

### 正交（单位）基底

**正交基底**：一组两两正交的非零向量。

**正交单位基底（orthonormal basis）**：两两正交且长度都为 1 的基底，常记为 $q_1, q_2, \ldots, q_n$。

- 正交单位向量的好处：$q_i^T q_j = 0 \ (i \ne j)$，$q_i^T q_i = 1$。
- 用正交单位基底表示向量极简单：每个坐标就是内积 $x_i = q_i^T b$。

### 正交矩阵 $Q$

**正交矩阵**：列向量为两两正交的单位向量的方阵。满足：

$$
\boxed{Q^T Q = I}
$$

- 若 $Q$ 是方阵，则 $Q^T = Q^{-1}$（转置 = 逆），这是正交矩阵最漂亮的性质。
- 正交矩阵保长度、保角度：$||Qx|| = ||x||$（旋转/反射不改变长度）。
- 例：旋转矩阵、反射矩阵、置换矩阵都是正交矩阵。

### 格莱姆-施密特正交化过程

目标：把一组线性**无关**基底 $a, b, c$ 转换为**正交**基底 $A, B, C$（再归一化得正交单位基底 $q_1, q_2, q_3$）。

**算法**（逐向量减去在已有正交方向上的投影）：

$$
A = a
$$

$$
B = b - \frac{A^T b}{A^T A} A
$$

$$
C = c - \frac{A^T c}{A^T A} A - \frac{B^T c}{B^T B} B
$$

- 每个新向量都减去它在**前面所有已正交化向量方向**上的投影，剩下的部分与前面的都正交。
- 最后归一化：$q_1 = A/||A||$，$q_2 = B/||B||$，$q_3 = C/||C||$，得到正交单位基底。

### A = QR 分解

格莱姆-施密特正交化把 A 分解为：

$$
\boxed{A = QR}
$$

- $Q$：正交矩阵（A 的列经正交化+归一化）；$R$：上三角矩阵（记录正交化系数）。
- $QR$ 分解的价值：把 $Ax = b$ 的求解简化为 $Rx = Q^T b$（因为 $Q^T Q = I$），数值稳定。
- 最小二乘也受益：$Rx = Q^T b$ 比直接解 $A^T A x = A^T b$ 更稳定（避免 $A^T A$ 的条件数变差）。

> **数值意义**：正交单位基底让计算既稳定又简洁——不放大舍入误差，坐标获取只需内积。这是本章在理论之外的核心实用价值。

## 全章要点复习

1. **正交向量**：$v^T w = 0$；**正交子空间**：一个子空间的所有向量与另一个的所有向量垂直。
2. **正交补**：$V^{\perp}$ 是所有与 V 垂直的向量；维度互补。
3. **基础定理（第二部分）**：行空间 ⊥ 零空间（$\mathbb{R}^n$），列空间 ⊥ 左零空间（$\mathbb{R}^m$），且互为补空间。
4. **投影到直线**：$p = a\,\dfrac{a^T b}{a^T a}$；**投影到子空间**：$p = A\hat{x}$，解 $A^T A \hat{x} = A^T b$。
5. **投影矩阵**：$P = A(A^T A)^{-1} A^T$，满足 $P^2 = P$、$P^T = P$。
6. **最小二乘**：$Ax = b$ 无解时解正态方程 $A^T A \hat{x} = A^T b$，残差 $e = b - A\hat{x} \perp C(A)$。
7. **正交矩阵**：$Q^T Q = I$，方阵时 $Q^T = Q^{-1}$，保长度与角度。
8. **格莱姆-施密特**：$B = b - \dfrac{A^T b}{A^T A}A$——减掉已有方向的投影，留下正交分量。
9. **A = QR**：正交基底带来数值稳定、计算简洁的矩阵分解。

## 记忆卡片

```
正交看内积           ← v^T w = 0 即垂直
正交补维度互补       ← C(A^T)+N(A)=R^n，C(A)+N(A^T)=R^m
投影误差垂直         ← e = b - p 与子空间正交
投影矩阵双性质       ← P²=P，P^T=P
最小二乘解正态方程   ← A^T A x̂ = A^T b，残差⊥C(A)
最佳近似即投影       ← p 是 b 在 C(A) 里最近的向量
正交矩阵转置即逆     ← Q^T Q = I，Q^T = Q^{-1}
格莱姆减投影         ← 每步减去前面方向的投影
QR 分解数值稳        ← 用 Q 转置代替求逆，避免条件数恶化
```
