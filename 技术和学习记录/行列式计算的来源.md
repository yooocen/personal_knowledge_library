# 行列式计算的来源

> [[第5章 行列式]] 走的是"**用三条性质定义对象**"的路线：先立 $\det I = 1$、换行变号、单行线性三条公理，再推出规则 1–10、大公式、余子式、克拉默规则。这条路线很干净，但它默认了两件事，没有交代：
>
> 1. **历史上这个量是怎么被发现的**？为什么一个方阵会被压成一个数？
> 2. **为什么偏偏是这三条性质、偏偏是这个公式**？换一组公理行不行？
>
> 这张卡片补的就是这两层"地基"：行列式**不是被设计出来的公式，而是解线性方程组时被迫出现的分母**；而大公式只是"体积"这个概念唯一可能的代数展开式。顺带澄清一个最初级的疑惑——**行列式并不限于 $2 \times 2$**。

## 一句话核心

$$
\boxed{\text{行列式} = \text{解方程组时漏出来的分母} = \text{满足三条体积公理的唯一函数}}
$$

- 从**历史**看：它来自消元法，不是来自矩阵。
- 从**逻辑**看：三条公理唯一确定它，所以公式无可选择。

---

## 零、前置澄清：$2 \times 2$ 不是行列式的全部

最初的疑惑是"行列式一定是 $2 \times 2$ 吗"。答案：**不是，$2 \times 2$ 只是最常先学到的特例**。真正的前提不是阶数，而是**方阵**。

| 阶数 | 有行列式？ | 形态 |
| :--- | :--- | :--- |
| $1 \times 1$ | ✅ | $\det[a] = a$ |
| $2 \times 2$ | ✅ | $ad - bc$，中学就见过 |
| $3 \times 3$ | ✅ | Sarrus 对角线法则（**仅此一阶可用**） |
| $4 \times 4$ 及以上 | ✅ | 只能靠余子式展开 / 行变换 / 大公式 |
| $n \times n$ | ✅ | 通用定义，$n!$ 项 |
| $2 \times 3$、$3 \times 5$ 等 | ❌ | **非方阵没有行列式**（"子式""雅可比行列式"是另外的概念） |

**为什么课本总从 $2 \times 2$ 开始**：它是唯一能一眼算完、又恰好包含"乘法抵消 + 符号"全部信息的最小阶数。

- $1 \times 1$ 太平凡，看不出结构；
- $3 \times 3$ 就已经够复杂，而且会诱导人误以为"对角线法则"是普遍规律——[[第5章 行列式]] 特意警示过：$4 \times 4$ 若套斜线法则只能得到 8 项，会漏掉 16 项。

## 一、来源之一：它是解方程组时"漏"出来的分母

### 1.1 $2 \times 2$：$ad - bc$ 是消元的副产品

$$
\begin{cases}
ax + by = e \\
cx + dy = f
\end{cases}
$$

消元解一遍（第一式 $\times c$、第二式 $\times a$，相减消 $x$）：

$$
(ad - bc)\,y = af - ce
$$

同理消 $y$：

$$
(ad - bc)\,x = de - bf
$$

注意：**$ad - bc$ 是自己冒出来的，没有人设计它**。而它的功能极其明确：

- $ad - bc \neq 0$ → 分母非零，解存在且唯一，可直接写出公式；
- $ad - bc = 0$ → 分母消失，要么无解，要么无穷多解。

于是这个量"**判定**"了方程组的解的情况。这就是 determinant 一词的本义——**判定式**。

$$
\det A \neq 0 \iff A \text{ 可逆} \iff Ax = b \text{ 有唯一解}
$$

[[第5章 行列式]] 里的"金标准"，最初的身份就是这个分母。

### 1.2 $3 \times 3$：克拉默规则的分母

$3 \times 3$ 完全同理。用克拉默规则解出来，每个未知数都是"两个同款式子的商"，其**分母就是 $3$ 阶行列式**，也就是 Sarrus 法则展开的那个式子。所以对角线法则不是"为了算行列式而发明的算法"，而是**解方程组的副产物**。

### 1.3 一个反直觉的事实：行列式比矩阵早约 150 年

行列式最早是**系数阵列的性质**，不是**矩阵的性质**。1851 年 Sylvester 才造出 "matrix" 一词，本义是"母体"——指"行列式（子式）从中诞生的那个数组"。

| 年份 | 人 | 贡献 |
| :--- | :--- | :--- |
| ~1683 | 关孝和 | 独立得到行列式与符号规则 |
| 1693 | Leibniz | 在与 l'Hôpital 的通信中，用系数阵列判定方程组 |
| 1750 | Cramer | 克拉默规则，行列式作为公式的分母 |
| 1772 | Laplace | 按子式展开（Laplace 展开） |
| 1773 | Vandermonde | 首次把行列式当作**独立对象**研究 |
| 1812 | Cauchy | 命名 "déterminant"，证明乘法定理 |
| 1841 | Jacobi | 伴随矩阵、雅可比行列式 |
| 1851 | Sylvester | 造词 "matrix" |
| 1858 | Cayley | 矩阵代数、$\det(AB)=\det A\det B$ 的矩阵版 |

## 二、来源之二：为什么偏偏是这个公式

历史能解释"它是怎么出现的"，但解释不了"**凭什么就是这个式子**"。$n$ 阶有 $n!$ 项，靠消元硬推是不可能的，必须换一个视角：

> 不问"怎么算"，而先问"**我希望 det 具备什么性质**"。

### 2.1 三条公理

| 编号 | 性质 | 内容 | 为什么合理 |
| :--- | :--- | :--- | :--- |
| **D1** | 多重线性 | 某一行拆成两向量之和时 det 可拆；某一行乘 $t$ 时 det 乘 $t$ | 想要一个"逐行线性"的退化度量 |
| **D2** | 行相关归零 | 两行相同 ⇒ $\det = 0$ | 两行相同意味着线性相关，希望 det 报告"退化" |
| **D3** | 归一化 | $\det I = 1$ | 单位立方体体积定为 1 |

这正是 [[第5章 行列式]] 中的规则 3、规则 4、规则 1——**唯一性定理说明：这三条不多不少，恰好够用**。

### 2.2 交错性（换行变号）不是额外假设，是推论

$$
0 = f(\dots, r+s, \dots, r+s, \dots) = f(r,r) + f(r,s) + f(s,r) + f(s,s) = f(r,s) + f(s,r)
$$

（第一个等号来自 D2，中间两个 $f(r,r)=f(s,s)=0$ 也来自 D2。）

于是

$$
f(s,r) = -f(r,s)
$$

即**交换两行变号是"多重线性 + 行相关归零"被逼出来的结果**，不需要单独规定。

### 2.3 唯一性定理：只剩 $n!$ 项

满足 D1 + D2 + D3 的函数**有且只有一个**，它必须是

$$
\det A = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma) \prod_{i=1}^{n} a_{i,\sigma(i)}
$$

**证明只有三步**（对比 [[第5章 行列式]] 的"大公式"推导，这里是把它升级成一个"唯一性"结论）：

1. 把每一行写成基向量组合 $a_i = \sum_j a_{ij} e_j$，用 **D1 多重线性**展开，共 $n^n$ 项：

   $$f(A) = \sum_{j_1,\dots,j_n} a_{1j_1} \cdots a_{nj_n}\, f(e_{j_1}, \dots, e_{j_n})$$

2. 只要有**两个下标相同**，就有两行相同 → 由 **D2** 该项为 $0$。于是只有 $(j_1,\dots,j_n)$ 是 $1..n$ 的一个**排列** $\sigma$ 的项能存活，剩 $n!$ 项。

3. 排列可由对换搭成，每次对换变一次号（2.2 节），所以

   $$f(e_{\sigma(1)}, \dots, e_{\sigma(n)}) = \operatorname{sgn}(\sigma) \cdot f(e_1, \dots, e_n) = \operatorname{sgn}(\sigma)$$

   （最后一步用了 **D3**。）

代回即得大公式。$\blacksquare$

> **所以"排列 + 符号"不是玄学**：$\operatorname{sgn}(\sigma)$ 就是"把这个排列用对换排回原序所需的奇偶次数"，而"对换变号"正是交错性。

### 2.4 $3 \times 3$ 的六项就是 $\mathrm{S}_3$ 的奇偶分类

| 排列 | 奇偶 | 乘积 | 项 |
| :--- | :--- | :--- | :--- |
| $\mathrm{id}$ | 偶 | $a_{11}a_{22}a_{33}$ | $+aei$ |
| $(123)$ | 偶 | $a_{12}a_{23}a_{31}$ | $+bfg$ |
| $(132)$ | 偶 | $a_{13}a_{21}a_{32}$ | $+cdh$ |
| $(23)$ | 奇 | $a_{11}a_{23}a_{32}$ | $-afh$ |
| $(13)$ | 奇 | $a_{13}a_{22}a_{31}$ | $-ceg$ |
| $(12)$ | 奇 | $a_{12}a_{21}a_{33}$ | $-bdi$ |

3 个正项对应"右斜对角线方向"，3 个负项对应"左斜对角线方向"——[[第5章 行列式]] 里那张展开式表格，本质就是这张奇偶表。

## 三、为什么这三条公理"自然"：因为它就是体积

三条公理不是从天上挑的，它们就是**平行体体积**的三条性质：

| 体积的性质 | 对应公理 |
| :--- | :--- |
| 一条边拉长 $t$ 倍，体积变 $t$ 倍 | D1 多重线性 |
| 两条边重合，体积退化为 $0$ | D2 行相关归零 |
| 单位立方体体积为 $1$ | D3 归一化 |

由唯一性定理：

$$
\det A = \text{列向量张成的 } n \text{ 维有向体积}
$$

- $2 \times 2$ → 平行四边形**面积**
- $3 \times 3$ → 平行六面体**体积**
- 符号 → 定向（手系）是否被翻转

这与 [[第5章 行列式]] 5.3 的"$|\det A|$ 就是体积"是同一条结论，但方向反过来：那边是"**先有 det，再解释成体积**"；这边是"**先承认体积，det 就唯一确定**"。

> **这就是"来源"的最终答案**：行列式的代数公式，就是"体积"这个概念在坐标下的展开式。任何关于体积的直觉（厘米³ 缩放、压扁成 0、翻转带负号）都能直接翻译成行列式定理。

## 四、来源之三：所有计算路线都是这三条的推论

一旦接受唯一性定理，[[第5章 行列式]] 里那张"三种计算路线对比表"就不再是三条并列的记忆项，而是**同一个对象的三种执行方式**：

| 计算路线 | 复杂度 | 它其实用的是哪一条公理 |
| :--- | :--- | :--- |
| 主元法（$O(n^3)$） | 最快，数值首选 | D1 + 交错性：行加倍数不变，三角阵 = 对角线乘积 |
| 大公式（$O(n \cdot n!)$） | 理论全貌 | 唯一性定理的**定义式**本身 |
| 余子式法（视稀疏度） | 稀疏矩阵最快 | D1 只对"第一行"展开 |

逐条推导：

**① 按行展开 / 余子式（D1 的直接后果）**

只用多重线性，把第一行拆开 $a_1 = \sum_j a_{1j} e_j$：

$$
\det A = \sum_{j} a_{1j} \det(e_j, a_2, \dots, a_n) = \sum_{j} (-1)^{1+j} a_{1j} M_{1j}
$$

把 $e_j$ 挪到第一位要 $j-1$ 次对换，所以符号是 $(-1)^{j-1} = (-1)^{j+1}$——**棋盘符号阵不是规定，是数对换次数的结果**。

**② 行变换三规则**

- 某行乘 $\lambda$ → det 乘 $\lambda$（D1）
- 交换两行 → 变号（2.2 节推论）
- **一行加上另一行的 $k$ 倍 → det 不变**：

  $$\det(r_1 + kr_2,\ r_2, \dots) = \det(r_1, r_2, \dots) + k\underbrace{\det(r_2, r_2, \dots)}_{=\,0}$$

**③ 三角矩阵 det = 对角线乘积**：单位阵各行分别拉伸即得（D1 + D3）。

**④ 高斯消元法为什么对**：把 ② ③ 串起来——用"行加倍数"化三角阵，再用交换凑符号，$\det = \pm$ 主元乘积。**这就是唯一实用的手算方法，它不是另起炉灶，只是三条公理的执行流程。**

**⑤ $\det(AB) = \det A \det B$**：体积语言——先做 $B$ 把体积放大 $\det B$ 倍，再做 $A$ 放大 $\det A$ 倍，共 $\det A \det B$ 倍。Cauchy 1812 年证明的就是这条。

**⑥ $\det A^{\mathsf T} = \det A$**：$n$ 维平行体转置后体积不变，所以"行"与"列"完全对称，按行按列展开随你。

## 五、这张卡与 [[第5章 行列式]] 的分工

| | [[第5章 行列式]] | 本卡 |
| :--- | :--- | :--- |
| 回答的问题 | 行列式**是什么**、**怎么算**、**有什么用** | 它**从哪来**、为什么**只能长这样** |
| 起点 | 三条性质（公理） | 解方程组的消元过程 |
| 逻辑方向 | 公理 → 规则 1–10 → 三种算法 | 历史发生 → 三条性质 → 唯一性 → 算法 |
| 关键结论 | $\det A \neq 0 \iff$ 可逆、$|\det A|$ = 体积 | 三条性质**唯一**确定 det，因此公式无可选择 |

一句话：**第 5 章告诉你"三条性质定乾坤"，本卡告诉你"为什么可以这样定，以及人类当初是怎么摸到这三条的"**。

### 常见误解清单

| 说法 | 对错 |
| :--- | :--- |
| 行列式一定是 $2 \times 2$ | ❌ |
| 行列式只对**方阵**有定义 | ✅ |
| $3 \times 3$ 可以用对角线法则 | ✅（仅 $3$ 阶） |
| $4 \times 4$ 也能用对角线法则 | ❌（$4! = 24$ 项，斜线只得 8 项） |
| 行列式是"人为规定的公式" | ❌（三条公理下唯一） |
| 行列式比矩阵晚出现 | ❌（早约 150 年） |
